STILLVEIL — ルネット必殺技 5秒試作 v1
720×1280 / 30fps / 5秒 / 2案 / BGM・追加の声なし。

A_Electric：電撃寄りの射撃。
B_Pressure：低中域に厚みがある圧力砲寄りの射撃。
映像は同一。音声だけ異なり、どちらも-16 LUFS / -1.5 dBTPに合わせて比較。

演出：巻き鍵の合図 → 大小と前後差のある4体展開 → 4巡の連射 → 短い間 → 集中射撃 → ホワイトアウト → 敵の後退と合計ダメージ。
各発のタイミングに敵イラストの受け身と明るさを連動。カメラ相当の拡大は敵イラストだけに適用し、HPやコマンドは固定。
ダメージ表示とHPは最後の集中射撃（正規タイムライン3200ms）まで待つ。戦闘のダメージ判定を増やしていません。
既存の覚醒ルネット透過ボディと巻き鍵を重ね、鍵を動かした2D演出。新しいキャラ画像・Runway動画は生成していません。通常ルネットは元の衣装を維持します。
音は発射・短い飛翔・着弾・締めの爆発と残響を分けて合成。buff/confirm/select/tap音、BGMはありません。

実際のゲームを独立した撮影用デモセーブで動かして収録。
moonshield-rehearsal、味方覚醒ルネット、敵セレネ。HP・攻撃・素早さ・クールダウン・ゲージを撮影用に調整。
画像とシンセを読み込んだ後、ブラウザの時間を1/30秒ずつ進めて150コマ撮影。演出や敵の反応を動画編集で後付けしたものではありません。
最後の1コマだけ次の敵のカットインが入るため、直前のコマを1コマ保持して5秒化。映像内のゲーム状態・ダメージを捏造したものではありません。
撮影時はミュートし、ゲームと同じ合成コードから作った効果音を合わせています。Aがゲーム側の標準、Bは比較案。
H.264 Constrained Baseline / AAC-LC / yuv420p / faststart。フルデコードとChromium再生を確認。iPhone実機は未確認。
