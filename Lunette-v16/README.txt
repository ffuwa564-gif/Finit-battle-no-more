STILLVEIL — 星時計・ルネット PV v16
縦型23秒 / Twinkle Soda / FUJINEQo / 追加ナレーションなし。

射撃演出の研究をゲームへ実装し、実際の戦闘画面を撮り直してPVへ反映。
・各うさぎの原画の胸時計を発射口とし、画像の中央から線が出る形を撤去。
・銃口の小さい発光 → 短い光弾が飛翔 → 着弾の方向へ散る破片。
・通常弾は75ms飛んでからHP・数字・赤い被弾・反動・着弾音が発生。
・最後は4つの大きな光弾が180ms飛んで一点へ集まり、圧縮された光が広がって白化。
・最終着弾を表示するフレームで描画を更新し、飛翔中なのに大ダメージ数字が出るズレも修正。

豪華な背景付きの共通カットイン、1・2・3・Fire!、約8.2秒のプレイ部分、最後の白化からルネットへの接続を維持。砲撃のディレイと残響はルネットの場面へ残す。
原画には物理的な銃身がないため、胸時計をエネルギーの射出口として扱う。新しい銃を生成したものではありません。

ゲーム実装とPVの効果音は同じ合成音源。射撃・飛翔・命中を別の時刻へ配置し、音程や各発の立ち上がりは伸ばしていません。最終弾の発射・飛翔・着弾を別カットとして同期。BGMは効果音が聞こえるよう抑制。タップ・決定・選択音の追加なし。

撮影元：lunette-ultimate-study-v8。独立した撮影用セーブでHPなどを調整した実ゲーム。16射＋最後の一撃でHP1200→763、計437を確認。最初の弾の飛翔は125フレーム目、最初のHP更新は128フレーム目。大ダメージ表示時は飛翔中の最終弾が残っていないことを検証済み。全17段階のHP減少と白化も確認。
参考：公式トリビーPVの弾を見せる構成、RiotのVFXと音の制作資料、GDQuestの予備動作／軌跡／反応の解説。第三者の映像・音は本PVへ組み込んでいません。詳細は前版Lunette-v15/shooting-research.txt。
