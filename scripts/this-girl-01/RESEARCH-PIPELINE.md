# Native research pipeline (restored study; prior lost observations excluded)

Run from the repository root with Node/tsx and Python 3. The before engine is the immutable `src/` tree from commit `f6595da6c5f4bd3950e412d92e3e08f3529e0706`, restored to `artifacts/this-girl-01/baseline/src`. The after engine is the opt-in research content; normal released content remains separate.

1. Restore dependencies and baseline. Run a bank legality/native adapter smoke check; verify the non-S invariance proof from `capture/check-no-sakuya.mts` and save `artifacts/this-girl-01/research/non-s-invariance.json` with `passed: true` only when all comparisons pass.
2. `python3 scripts/this-girl-01/pipeline.py search` runs before and after finite-budget optimization and broad global candidates. Maximum two workers. Raw train/selection rows are gzip files. No held-out battle occurs here. Alternative healers use before results as after results only with the separate no-S invariance proof. S is reoptimized after the change with the same per-form budget.
3. Optionally run `node --import tsx scripts/this-girl-01/exploratory.mts landscape` and `... roster` for the 24-stage difficulty overview and equal-budget all-75 exploratory audit. Four-seed screens do not establish practical role loss, superiority or character certification.
4. Commit frozen source. `python3 scripts/this-girl-01/pipeline.py lock` writes the complete build/seed/source/family lock. Review and commit that exact lock before opening any confirmation combat. Confirm statistical-source hashes and all 12 case/72 main comparison identities with the critic.
5. `python3 scripts/this-girl-01/pipeline.py confirm --reviewed-lock-sha <SHA256 of confirmation-lock.json>` runs all main arms on all 256 common confirmation rows. It fails if any locked source differs. Cases are independent jobs (at most two concurrent). E preserves paid action, CD, AI, shield reduction and mark transitions and changes only payoutPercent to zero. Duplicate arms may alias identical results explicitly.
6. Using the same reviewed lock SHA, run `node --import tsx scripts/this-girl-01/supplementary.mts <SHA> growth`, then `... stress` and `... hidden`. Growth is 12 controlled tier pairs of the identical T6-selected template. Stress is fixed-build HP/ATK/DEF perturbation of party SSR/XR, with speed/leader rules unchanged; enemy sensitivity changes HP/ATK each wave. All stress C/E conditions, including zero, use the same 950 panel. Hidden stages only receive transferred frozen builds.
7. `python3 scripts/this-girl-01/analyze-study.py` validates and analyzes 288 main hypotheses and a separate 48 growth family using the frozen simultaneous-CI count 516. Recording examples are chosen by the preregistered ascending first common A/C victory with actual capture/consume/positive return damage. They are mechanism illustrations; the whole panel supports performance summaries.

## Limits and interpretation

- This is bounded deterministic heuristic search, not exhaustive global optimization or a proof of universal dominance.
- Every replacement healer gets 64 configurations x4 train rows, six selected configurations x100 selection rows; T6 additionally gets 24 local stone mutations x4 train rows and three new selection candidates x100 rows. The existing winner is retained. Each candidate has the same opportunity for fast/safe/frugal ranking and all four leader choices.
- Main F1/F4 cores include currently inaccessible XR Astraea. All three equipment tiers are hypothetical full-ownership comparisons, not current acquisition/entry recommendations.
- Equal-tier budget means four legal max-roll stones of that tier; fixed-roll stones keep their fixed rolls. Mercy and bulwark are different effects; bulwark creates a temporary barrier after a stone action and is not a permanent HP statistic. `gemPowerMultiplier` remains the native `1+power*.015`.
- Paired rows share pre-departure and native departure seeds. After action divergence the consumed RNG streams may diverge. The precommitted SHA256 panel is not exhaustive over 2^32 states and not a guarantee for future player policies.
- Win, failure-capped rounds, potions and all-four survival are separate endpoints. Do not relabel sign-test frequency evidence as proof of a mean reduction. Family-corrected CI/p-values are not decoration. A one-battle victory cannot certify a causal skill contribution.
- `actualRedirects` means the selected target UID actually changed at action selection. Guard redirection can still make the final damaged recipient the same. Net command value needs the no-command paired outcome comparison.
- Frozen-build stress tests cannot certify future reoptimized endgame adoption. Unknown/unverified forms must not be marked failed or obsolete.
- Source/report work must remain separate from game deployment. A video using research content carries `研究版・未公開仕様`.
