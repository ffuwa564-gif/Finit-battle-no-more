# 研究独白02・改訂版 — 実装を終えてから動画を作る

## 目的と状態

ミエットの障壁消費と通常回復の機会費用を改善する。研究版のみ、公開版/敵/基礎能力値/LS/石/必殺は変更しない。初案から第4案までの有効障壁の直接借用は、守りを削り生還が悪化する条件が残ったため、attempt-01〜04へ全開発データと差分を保存して未採用。これらの案で確認乱数は使用していない。

最終候補は失効した障壁を有限な修繕糸へ移す共通規則。ミエットの技能データに契約がある場合だけ、同陣営の失効残量を各自の最大HPまで3ラウンド保持。Wave/死亡で消え、同じ障壁を二度採取しない。自動回復や追加行動はない。技能は糸を先に使い、不足分は対象本人の有効な障壁だけから払う。他の味方の有効盾は絶対に削らない。最大総消費は対象最大HPの15%、基礎倍率3倍、宝石色の通常補正は別。通常の1行動とCD3を支払う。自動で小さすぎる変換を避け、通常回復が2倍以上回復できる場合は既存の回復判断へ戻す。緊急時以外は従来の盾持ち対象を優先する。

修繕糸は実際のUnit状態として保存/リプレイ/UIへ反映する。準備画面の選択肢は可視の失効・糸だけを読み、私的な仲間予定や未来乱数を見ない。全キャラ定義で変更するのはミエットだけ。共通の失効処理にはデータで参加し、敵IDや特定ステージIDで強化しない。

## 探索

既存の塔10層と葛葉覚醒級。旧回と同じ二つのコア、T3/T4/T6の12条件。全所持を仮定、同family同時編成不可、最大4石、薬5。各ヒーラー全17形態（コアと重複するものを除く）と改修前ミエットへ同数18候補を与える。3石配分×2リーダー×3操作。8開発入力から速さ・生還・薬の3候補を選び、別16選抜入力で比較。主の方針は勝利→4人生還→薬→失敗cap120込みラウンドの辞書式。有限の最良既知で、大域最適ではない。失敗低消費を節約と評価しない。

## 採用基準（確認前に固定）

改善の採用と、全体の最終盤認定を分ける。

1. 事前に列挙した12条件のC-Bについて、勝率が5ポイントを超えて低下した条件がないこと（観測上の安全条件。非劣性の統計的証明とは呼ばない）。
2. 少なくとも一つの既存条件で、4人生還率が5ポイント以上改善、または勝利率を維持し薬が0.15個以上減少、または失敗cap込み平均Rが1以上減少。この改善の対応bootstrap区間と多重比較を確認し、勝率だけを根拠にしない。
3. 同方針Xと因果対照E/Nから、何が改善に寄与したかを調べる。新技能の他者供給による正の実回復を実ログで確認。全部を新技能だけの効果としない。
4. 同予算代替A、T3/T4/T6、二つの仲間組とカテゴリ、未達の条件をすべて保存して開示。全体認定はendgame-invariance-v03の別基準に従い、今回の局所採用で代用しない。
5. 既存戦闘・セーブ・乱数・型/コンテンツ/UI/英語/ブラウザを検証。全キャラ定義の差分監査と、Miette不在編成の対照一致を確認。全キャラ外側最適化は未検証と明示する。

基準未達ならここで動画を完成させず、開発へ戻る。確認結果を調整に使った回は確認済みと明記して、新しい確認乱数へ切り替える。
