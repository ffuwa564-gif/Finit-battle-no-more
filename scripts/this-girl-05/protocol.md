# THIS-GIRL-005 — リゼット、弔鐘の返し刃

研究改修：dispelの個人技能契約 `dispelStrikePercent=100`。有効な攻撃強化/再生を1つ以上解除した時のみ、同じ対象へ攻撃力100%基準の1斬撃。防御/かばう/障壁/被弾ゲージを通常適用、追加行動・追加の本人ゲージ・追撃由来の再発動を作らない。基礎定数・LS・石・敵は変更しない。通常3R待ち。

開発：最初の既存Kuzuha覚醒級/塔10層、2コア×T3/T4/T6を16開発+別32選抜で探索。解除の機会が少ない条件を観測したため、既存塔4/8/20と女神試練の開発用プローブを保存。自然な敵強化がある塔4を確認セットに追加。元の12条件は削除せず、合計18条件。プローブは確認結果ではない。別種の敵や接待ステージは作らない。

各本人/各代替に18合法候補（3作戦×3石配置×2リーダー）、16開発で速さ・節薬・生還の3候補以内を選び32選抜で勝率→失敗120のラウンド→薬→全員生還を辞書式選抜。全所持・4石まで・薬5、未入手XRを含む仮想飽和ストレスであり、通常入手案内ではない。候補6代替（coreと同family禁止）は同じ探索予算。大域最適とは呼ばない。

凍結後の未使用256確認入力。C=改修後再探索、B=前再探索、X=Cの構成のまま契約だけ無効、E=Xと同一の機構無効対照、A=有限代替、L=リーダーを切替、K0=全石を外す。T6に同構成T3/T4。乱数の消費が変わるため同じ入力でも同じイベント列とは限らない。

主要C-B/C-X×18条件×4指標（勝率・失敗120ラウンド・薬・全員生還）をHolm144補正。対応符号反転検定（決定的10000draw）/二値McNemar、記述的bootstrap95%。局所採用は、同一事前条件で両比較に、ラウンド平均-.25以上または薬-.15以上または生還+.05以上の改善と補正p<.05。勝率差>=-.02、生還差>=-.05、速度改善時の薬増<=.2、節薬/生還改善時ラウンド増<=.5。因果対照で実斬撃が必要。閾値は確認前に固定。どの条件のどの指標が達したかを明記し、観測差を母集団下限と混同しない。

その他の条件の悪化・全敗・不発を全て報告。全18条件での非劣性、全キャラ採用価値、無限将来の保証、専用接待なしの最終盤認定は別物で、今回の局所採用から認定しない。弱い条件を消したり、確認を開いた後で閾値/構成/候補を選び直さない。未達の場合は研究を再設計し、次の新規パネルを固定してから再確認。
