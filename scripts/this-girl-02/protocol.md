# Episode02研究プロトコル・開発段階

対象は公開版1.12のミエット。先に既存能力を測る。専用強化・敵の変更・未公開能力を使わない。以下は開発stage探査のみ。確認seedはまだ開かない。

候補の作戦は全キャラ所持・合法な4石・薬5個。同一family同時編成禁止。各差替え候補に同数の構成案・同じ開発seedを与える。勝率→失敗cap込みラウンド→薬→4人生還の既知最良を記録し、最強の証明とはしない。

開発seed：SHA32("STILLVEIL:this-girl-02:development:v1:"+0..7)。選抜seed：同"selection:"+0..15。確認seed：同"heldout:"+0..255（候補固定まで使用禁止）。統計は対応ある差とseed単位bootstrap。勝率は二項Wilson、複数の事前比較はHolmを併記。

主に見るのは実用、差替えとのトレードオフ、石の成長、障壁→HPの実消費、LSと指揮の機会費用。因果対照を行わない項目は未検証。対照の方法は開発後・確認前に固定する。全キャラの採用価値の維持は今回の局所実験だけで認定しない。

現時点で合格を予定しない。必要条件が残れば研究中。研究結果と動画の同期合否は別に検査する。

## 確認前の最終固定

探索の18候補から、速さ・生還・薬の3観点の候補を同じ予算で選抜。各候補16選抜seed。主比較M/A、同じM編成から副技能のみを除くE、同勝率候補内の節約MF/AFを各256確認seedで測る。3候補の選抜は開発データ段階で修正し、確認データを見る前に固定した。既存共通ステージは塔10層と葛葉覚醒、2コア、T3/T4/T6の12条件。勝率が上限へ飽和する条件は、勝率では見分けられないと明示する。

新能力は今回は追加しない。公開技能の仕事と費用を測り、改修案は未実装として分ける。全キャラ再評価・全コア・全石の大域最適・指揮を含む再最適化は未完なので、局所結果だけで全体認定を行わない。
