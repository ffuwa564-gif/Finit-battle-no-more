# ルカ「残り糸・留め縫い」ビルドの研究

2026-11-02 / STILLVEIL v1.10.0を基にした研究。**新技・新石・新ステージは研究用の試作であり、配信中のゲームには未実装。動画制作はしていない。**

## 結論

選ぶキャラクターは、**ルカ〈夜継ぎの仕立て屋〉**。

既存の「使われずに自然失効した味方の障壁を、残り糸に変える」能力を、新しい**回復阻害**へつなぐ。ルカが敵の回復を止めると、仲間の攻撃が通る時間が生まれる。ルカ自身の攻撃力を伸ばすだけでなく、仲間の火力を成立させるビルドにする。

この仕組みと専用の任意試練を合わせれば、**「この構造のビルドでしか攻略できないステージが少なくとも一つある」ことを、提案ルール上で構成的に示せる。** 既存ステージでの排他性を証明したという意味ではない。

ここでいうビルドは「ルカ＋自然失効する障壁の供給＋残り糸を留め縫いに使う」という構造。残り3人と装備の組み合わせには幅を持たせる。4人・4個の完全固定セットを唯一解にすることは狙わない。

## 1. 現行ルカのままでは、命題を満たしたと言えない

現行のルカは、残り糸で「夜継ぎの鋏」を強化し、リーダーなら条件付きで小回復する。固有の資源はあるが、出力の中心はダメージ増加と回復である。他の攻撃役で置き換えられる可能性が大きい。

実エンジンで、ルカ／ノクス／アテナ／弁財天の先頭1枠を入れ替えた。可変石の威力・特性をT4上限139に揃え、白亜の塔第1層と第3層を各20個のseedで比較した。

| 条件 | ルカの勝利 | ルカ以外にも勝利があった候補数 |
|---|---:|---:|
| 第1層 | 14/20 | 70体 |
| 第3層 | 18/20 | 70体 |

計2,840戦。固定された操作方針・仮想所持条件での置換比較であり、全100層・全操作の網羅ではない。少なくともこの条件では「ルカで勝てた」を「ルカだけが勝てる」とは言えなかった。

さらに、現行の白亜の塔100層を、ルカ編成とエオスへの置換編成・各5seed・T6上限で調べた（1,000戦）。第20・30層では、ルカに勝利があり、エオスには勝利がなかった。しかし、候補を増やして各20seedで再検証すると、次の反例が出た。

| 現行の層 | ルカ | 覚醒セリスへの置換 | 覚醒エレインへの置換 |
|---|---:|---:|---:|
| 第20層 | 6/20 | 3/20 | 11/20 |
| 第30層 | 8/20 | 2/20 | 11/20 |

この追加検証は9候補×2層×20seed＝360戦。「片方で0勝」という初期比較だけで排他性を認めると誤る具体例になった。ルカ編成で勝利を見た20層は、ここまでの比較で全て別キャラ入りの勝利も確認された。ただし、100層の全編成・全装備・全操作を網羅したわけではない。

**現行能力で既存ステージの唯一解になることは、今回確認できていない。新技だけを追加して既存ステージの排他性を作れることも、まだ証明していない。以降は、新しい任意試練まで含めた構成的な提案である。**


候補も比較した。ノエルの号令は行動の宛先を変える固有性があるが、単体の先頭操作・範囲攻撃・高火力という代替への上界が必要になる。ネリの軽減、フィオの余剰回復障壁も、耐久や通常障壁による代替を排除しにくい。ルカの残り糸は、資源の発生条件そのものが独特で、変換先を設計する余地が大きかった。

## 2. 提案するビルド

### 新しい通常技「留め縫い」

- ルカ本人の通常技。敵1体が対象。
- 残り糸1個と通常行動1回を使う。攻撃ダメージは与えない。
- 対象へ、使用ラウンドと次ラウンドの終了まで「縫い傷」を付ける。
- 縫い傷の間は、対象のHP回復を100%止める。通常回復・吸収回復・今回の周期回復が対象。
- 再使用3R。残り糸がない時は使えない仕様にする。
- 石の威力やT6特性で、阻害率・効果時間・糸の発生数を増やさない。

通常攻撃・従来の夜継ぎの鋏・留め縫いのどれに一手と残り糸を使うかが判断になる。従来の鋏へ糸を使えば、同じ糸で留め縫いはできない。

### 新石案「仮縫いの糸巻き」

- 誰でも装備できる、固定T3の製作品を想定。
- 装備者自身へ障壁60、次ラウンド終了まで。再使用3R。
- 自分を指定する石なので、攻撃されにくい仲間へ資源の発生場所を用意できる。
- 固定効果で倍率を掛けない。糸を直接配る効果はない。
- 障壁が攻撃で消えたり、砕盾石などで消費されたら残り糸にはならない。
- 新石は入門用。既存の障壁・タンク必殺などでも自然失効を作れるため、必須アイテムにはしない。

第4案では、回復役に使わせる際、深い傷があり通常回復を使える場合は治療を優先するよう試作方針も直した。資源を作るために回復役が治療を放棄し続ける仕様にはしない。

### リーダースキルは現行を維持する

最初は「残り糸を2個まで期限なしで保管」という新LSも試した。しかし、今回の成立に必須ではなかった。変更を増やす根拠が薄いため、最終案では新LSを採用しない。

LSへ回復阻害まで自動で載せる案も、リーダー枠を固定し、通常行動の代償を薄めるため優先しない。まず新通常技1つで役割を作る。

### 編成例

| 仲間 | このビルドでの仕事 |
|---|---|
| ルカ | 自然失効した障壁から糸を得て、敵へ縫い傷を付ける |
| フィオ＋仮縫いの糸巻き | 回復と、余らせて期限を迎える障壁の供給 |
| アテナ／覚醒リオラなど | 攻撃を受け持ち、障壁を余らせたい仲間とルカを守る |
| ノクス／覚醒セリスなど | 縫い傷によって開いた時間に、実際のHPを削る |

```mermaid
flowchart LR
  A[仲間が障壁を張る] --> B[受ける役を分けて障壁を残す]
  B --> C[正の残量のまま自然失効]
  C --> D[ルカが残り糸を得る]
  D --> E[一手を使って留め縫い]
  E --> F[敵のHP回復を止める]
  F --> G[仲間全員の火力が活きる]
```

ルカを選ぶ理由は、別の剣士より高いダメージを出すからではない。**余った守りを、仲間が攻められる条件へ変換できるから。**

## 3. 命題を成立させる任意試練「ほどける回廊」

研究用の敵「ほどける回廊の織機」を置いた。

| ルール | 最終試作値 |
|---|---|
| 敵HP | 4,800 |
| 敵攻撃力 | 160 |
| 通常時の性質 | ボスが受けるHPダメージは、全ての発生源を合算して1Rあたり最大300 |
| 回復周期 | R4・8・12…の終了時にHPを全回復 |
| 縫い傷の間 | HP回復が止まり、ダメージ上限も解除される |
| 制限 | 40R・1ウェーブ |
| 勝利 | 敵のHPを0にする。キャラ名による入場・勝利判定は使わない |

連鎖・残響・花・必殺も共通の上限を使う。多段演出や追加攻撃で上限をすり抜けない。周期回復は織機がいる回廊の作用であり、敵の通常行動や技のCDとは別。睡眠・麻痺・魅了・封印で周期自体は遅れない。この違いは敵説明と予告に明示する必要がある。

世界観上は、傷をほどいて元の形へ戻ろうとする織機を、ルカが「今ついた変化」のまま縫い留めるイメージ。元へ戻すことと、帰った跡を残すことを対置できる。

### 必須性の証明

縫い傷がなければ、次の全回復までに与えられるHPダメージの上界は、

**4R × 300 = 1,200 < 4,800HP。**

敵は最低でも3,600HP残った状態で全回復する。次の4Rも同じになる。攻撃力・レアリティ・石の威力・行動数を増やしても、この総量上限を越えられない。味方を無敵にし、毎ラウンド任意の0〜300ダメージを選べる、実際の全編成より強い相手を仮定しても倒せない。

独立した状態列挙でも、0〜300の全ダメージ量を許すHP状態を40R分マージして調べ、0HPへ到達しないことを確認した。

一方、提案された仕様では縫い傷を付けられるのはルカの留め縫いだけであり、糸には味方の障壁の自然失効が必要になる。したがって勝利には「ルカ＋障壁を自然失効させる供給＋留め縫い」の構造が必要になる。seed1の実エンジン試作ログにも勝利例があるため、必要条件だけでなく到達例も存在する。

これは**明示した提案ルールと、監査したHP変動経路に対する証明**。現在の配信版や将来の別仕様に自動で適用される証明ではない。新しい回復阻害、最大HP減少、ダメージ経路、ボスの自傷などを追加したら再確認する。

## 4. 最終試作の結果

同じターン順・通常技・必殺・再使用待ち・石・薬・妖精・花を使う実エンジンを、`/tmp`へコピーして拡張した。以下は本体のプレイ実績ではなく、**提案した追加ルールの試作結果**である。

- 固定seed1〜100。各条件100戦。
- 装備は仮想的に所持。Tier比較では可変石の威力・特性を各帯の上限に揃える。新石は固定T3。
- 基本編成はルカ／ノクス／アテナ／フィオ。新LSは使わない。
- 通常の操作は固定コントローラ。糸を得るために待つ場合も、公開された障壁の残量と期限から判断する。未来の乱数や相手の非公開行動を読まない。

@@MAIN_TABLE@@

T3からT6への強化で、平均攻略Rは@@TIER_GAIN@@%短縮した。上限解除中に高い火力が活きる。これは指定した石・編成・操作の比較であり、Tier以外を含む一般的な勝率や厳選時間の説明ではない。

@@VARIATION_TABLE@@

他の3人を全員替えた編成でも勝利を確認した。ルカ以外まで一式固定にする必要はない。ただし、ネリへの置換のように成績が落ちる組み合わせもあり、「同じ役割なら全員同等」とは扱わない。

追加の置換研究では、ルカの枠を別の70体へ替え、各20seed・可変石T6上限の条件で試した。計1,400戦、ルカ抜きの勝利は0。これだけで全編成の不可能性を主張せず、上の総量上界を根拠にする。

制御実験として、周期回復を無効にした耐久編成は100/100で勝利した。上限だけの敵を倒すことはでき、回復との組み合わせが障害になる。上限を事実上解除したT6火力編成も100/100で勝利した。

## 5. 不採用案・反省

1. **最初の常時ダメージ上限案は、そのまま採用しない。** HP1,800・常時上限300ではT3/T6とも平均6.38Rになった。排他性を作れても装備更新の価値が薄かった。縫い傷中は上限が外れる構造へ改めた。
2. **新LSを足せば深くなる、とは限らない。** 保管能力を外しても成立したので、最終案から外した。変更点を必要な部分へ絞った。
3. **必殺を開放時間まで一律に温存する案も、今回の実測では改善しなかった。** 第3案のT6条件では通常予約8.93R、温存9.66R。ゲージ上限・CD・窓以外の削りもある。見た目の綺麗な連携説明だけで、温存を最適解とは推奨しない。細かい原因の寄与は未分解。
4. **石の使用を優先しすぎるAIも直した。** 最終試作は回復役の治療を優先できる。資源生成と生存の両立が必要で、初期の数値をそのまま最終値として使っていない。

## 6. この設計の厳しい問題点

**これは意図的なキャラクター接待であり、所持条件への圧力は残る。** キャラ名の直接判定をなくしても、現時点でその効果を持つ1体が必要になる事実は同じ。数学的に排他性を作れたことと、楽しいステージであることは別である。

そのため、まず次の条件を推す。

- 通常の進行や重要な装備解禁へ置かず、任意の「ルカの試練」として使う。
- ルカは第7章「ふたりの署名」の確定素材1個で迎えられる。ガチャ所持チェックにしない。
- 留め縫いの習得と新石の入手は、試練の初回勝利より前に用意する。攻略に必要な物が攻略後にしか手に入らない循環を作らない。
- 初回報酬は称号・物語などを中心にし、全員の必須成長をここへ集中させない。
- 「4R後の回復」「自然失効する障壁」「縫い傷中の上限解除」を出発前に説明する。見えない専用解法へ誘導しない。
- 同じ完全回復阻害を別キャラや汎用石へ配る場合、ルカの必須性は再検討する。未来の追加を無視して永久保証とは言わない。

ルカが全ての回復敵の唯一解になるのも避ける必要がある。ほかの敵では縫い傷を解除できる、敵の回復が勝敗の中心ではない、別の仕事が要求される、といった相手の幅を残す。解除との関係は、本体への実装時に通常の状態管理へ統合する課題である。

## 7. 表示と、実装前に残る課題

- ルカの顔グラに小さい糸アイコンと残数。敵側に周期と縫い傷・上限解除のアイコン。詳細はタップで開く。
- 戦闘操作パネルへ長い説明を再追加しない。既存AGENTS.mdの最小表示方針を守る。
- 自然失効による糸の発生を、行動選択前の公開状態へ正しく反映する。試作は既知の残量と期限から次の開始処理を見込んで操作している。
- 試作では40R制限を既存処理から借りるために研究用ステージへ`towerFloor:999`を仮置きしている。正式な試練には独立したラウンド制限を用意する。
- 新通常技の契約、使用可否、AI、セーブ／ロード、解除、波の切替、説明表示を正式に統合する。
- 敵ダメージ上限は直接攻撃と残響の両方へ適用した。花も通常のダメージ経路へ入る。ボスにHP自傷技は持たせていない。新しい経路が増えた場合は監査をやり直す。
- 100/100は、指定seedとコントローラでの成績。全乱数での勝率100%や、人間の初見難易度を保証しない。
- 操作・編成の網羅探索はしていない。不可能性は探索で0勝だったことではなく、提案ルールの上界から示す。
- 本体のバランス、解除持ちの既存敵との相性、入手までの実プレイ時間、楽しさは、まだプレイヤーテストが必要。
