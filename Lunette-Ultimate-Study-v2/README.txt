STILLVEIL — ルネット必殺技 試作 v2（バフ音多め）
720×1280 / 30fps / 5秒 / BGMなし。

鍵を回すアニメーションを撤去し、キャラクターの持つ鍵は静止しています。
既存の戦闘バフ音の上昇フレーズを基に、1オクターブ高い、丸い倍音の専用音を作成。
召喚前・展開・連射の区切り・最後の溜めに8回、締め撃ちの白化時にもう1回の明るいフレーズを重ねました。
低音の射撃は音量を下げ、バフ音の中高域が聞き取れるバランスに変更。
バフ効果や状態変化を増やしたものではありません。合計ダメージを最後に表示する仕組み、各射撃の受け身、ホワイトアウトは維持。
確認・タップ操作の効果音やBGMは追加していません。

実際のゲームを独立デモセーブで動かし、ブラウザ時間を1/30秒ずつ進めて150コマ撮影。
覚醒ルネット対セレネ。HP・攻撃・素早さ・クールダウン・ゲージを撮影向けに調整。
最後の1コマは次の敵カットインを除くため直前フレームを保持。
音声はゲームと同じrenderRabbitUltimateから出力し、元映像の開始位置に1/60秒を合わせて配置。
-16 LUFS / -1.5 dBTPで書き出し。ゲームでは一つの音声として管理し、速度変更で現在の位置から追従、スキップですべてのフレーズを停止。
音声準備が遅れた場合も、映像の現在位置から開始して導入を遅れて繰り返さないようにしています。
