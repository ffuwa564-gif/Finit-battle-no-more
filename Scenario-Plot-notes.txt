STILLVEIL ver1.00 シナリオ座談会：反省と今後のプロット
現行OP・第1〜4章の重要なネタバレを含みます。
基準：ver1.0 dbd3da0／参照ソース616a074（2026-10-31）。
この動画は音声キャラクターによる創作座談会です。冥鳴ひまりは「執筆担当役」。実在のご本人の意見・制作参加の表明ではありません。
ゲームソースの変更やitch.ioの更新は含みません。新章・新技は未実装の検討案です。

【現行の軸】
OP：扉の争いから、庭園で「何を望むのか」と問われる主人公へ。
第1章：庭園の女の指示でリオラに同行し、ギルドの仕事と旅へ。
第2章：荊の魔女との恋愛。炉は新しい命ではなく記憶を複製・維持していた。主人公も停止を先延ばしにする。個体は生まれず、魔女は主人公を認識できない。
第3章：街の封印と避難。療養と見舞いは朝が来ても続き、過去と同じ関係への即座の回復では終わらない。
第4章：リオラと契生石を探す。ザクロは内側には細やかな世話を行い、外から来た者へは容赦しない。儀式完了や誕生は、この章では確定していない。

【反省・読み方】
・冒頭の事件の強さを、その後の小さな行動へつなぐ。
・恋愛、信仰、療養の変化を急がず、主人公が来ない日の生活も描く。
・荊の魔女の病気と、炉の機構、主人公の先延ばしを混同しない。
・少女だけの世界でも、個人ごとの意見・役目・文化は異なる。
・管理者を全善／全悪へ即座にまとめず、世話と支配の両面を場面で示す。

【まだ決めていないこと】
誕生の普遍法則、寿命・人口と資源、庭ごとの制度の全体像、新章の正式な順番と結末。
タイトルの光輪は、新たな正史の結末や全員共通の誕生法則の証拠とは扱わない。
第2章の炉と第4章の契生石を、説明なしに同じ装置へ統合しない。
新しい個体を迎えない未来も、関係の失敗と決めつけない。

【定数と遊びを結ぶ時の原則】
キャラのstrengthと、敵編成・補正・WAVE等から算出されるダンジョン難度を区別する。
定数を愛情・人格の点数にしない。心の病状を戦闘の状態異常と同一視しない。
物語の事情は、障壁で道を塞ぐ、役割を分ける、大技に備える、といった戦闘条件へ接続する案。
提案スキル：リオラ「帰還の合図」、ノエル「余白の星図」、記憶石「空席の灯」。名称・効果・上限・再使用・入手先は未確定。
リーダー案：異なる役割を置いた最初の連携を支援。既存の号令・共鳴と差を設計する。
新しい章の常設分岐や探索中の選択肢を実装した、という意味ではない。


【各章の要点と今後の案】

少女だけの世界、物語のこれから／座談会／第1〜4章のネタバレあり
・ゲスト：執筆担当役：冥鳴ひまり
・振り返るもの：現行OP・第1〜4章・人物の記憶
・考えるもの：個体管理・文化・恋愛・今後の章
・遊びとの接続：定数・スキル・リーダー・記憶石
流れ：現行を読む → 暮らしを考える → 遊びへつなぐ

01　OPの強さと、残った問い／現行の内容／読み解き
・扉の前：願いを求める少女たちの争い
・庭園の女：可能性を観測し、主人公を旅へ送る
・主人公：何を望むのか、まだ分からない
・反省点：事件の強さを、その後の行動へつなぐ
流れ：争いを生き残る → 望みを問われる → 誰かと帰る
台詞例（現行OPより）：それで。あなたは、何を望むの？ ［庭園の女］

02　リオラは、急に優しくしない／現行第1〜2章／関係の変化
・出発時：庭園の女の命令で主人公に同行
・第1章：報告・護衛・包帯という小さな行動
・第2章：「今、私が決めた」と盾を取る
・反省点：信仰と親しさを、簡単に置き換えない
流れ：命令で守る → 話を先に聞く → 自分で決める
台詞例（現行第2章「最後の安全鍵」より）：今、私が決めた ［リオラ］

03　第2章の痛みを、雑に説明しない／現行第2章／重要な結末に言及
・恋愛の日常：食事・手紙・隣の椅子・ふたつの茶碗
・炉の問題：新しい個体ではなく、記憶の複製と維持
・主人公の過ち：止める約束を、先延ばしにした
・残したい余韻：恋愛や病気を、破局の単純な原因にしない
流れ：ふたりで暮らす → 止める約束 → 返事を失う
台詞例（現行第2章の結末より）：どなたですか ［荊の魔女］

04　少女だけでも、考えは揃わない／現行第3〜4章／反省と強み
・第3章：避難・合図・退路で意見が衝突する
・エレイン：世話をする時間も、無限ではない
・ザクロ：内側への細やかな世話と外への排除
・反省点：全員を同じ正しさの代弁者にしない
流れ：それぞれの事情 → 答えの衝突 → 後に残る関係
台詞例（現行第4章のザクロより）：あなたはどこで寝たい？ ［ザクロ］

05　個体管理は、帳簿と本人の間にある／世界観の拡張案／未確定
・記録するもの：名前・所在・休息・世話の引き継ぎ
・便利さ：災害時に探す／ケアを途切れさせない
・怖さ：古い役目や登録が、本人を縛る
・描きたい対立：安全のための把握と、変わる自由
流れ：記録を作る → 本人が変わる → 記録は追いつく？
台詞例（今後の場面案／未実装）：名簿は合っています。／でも、私はそこには帰りたくない。 ［新しく出会う少女・仮］

06　文化は、食事と休み方から作る／世界観の拡張案／現行の日常を種に
・命名：自分で名乗る日／昔の名前の残し方
・休息：会わない日の印／世話の交代
・食卓：茶碗を残す／空席を埋めない作法
・弔い：本人の声を残すか、再生を止めるか
流れ：小さな習慣 → 地域で違う → 衝突が起きる
台詞例（今後の会話案／未実装）：その椅子は、空けておくの？／うん。今日は、まだ。 ［主人公と街の少女・仮］

07　誕生の仕組みは、まだ答えを急がない／現行と拡張案を区別
・現行：第2章の炉は失敗／第4章は契生石を探す
・タイトル映像：光輪は印象的な象徴／普遍法則は未確定
・考える問い：誰が迎える？／名前と役目を誰が決める？
・筋の中心：新しい子を、ふたりの代用品にしない
流れ：迎えたい願い → 世話の準備 → その子自身の先
台詞例（今後の場面案／未実装）：私たちと違うものを好きになっても、／ここにいていい。 ［儀式の準備中の会話・仮］

08　恋愛は、三つの関係を並走させる／今後の関係の描き方／案
・荊の魔女：昔を取り戻すより、今の返事を聞く
・リオラ：崇拝を抱えたまま、自分の望みを探す
・庭園の女：救命・観測・親しさが混ざる関係
・避けたい近道：記憶回復で解決／全員が主人公を好きになる
流れ：親しくなる → 同じには望めない → 関係を結び直す
台詞例（今後の見舞いの場面案／未実装）：今日は、お茶はいい。／土を運ぶのを手伝って。 ［荊の魔女・仮］

09　第5章案「空欄の名簿」／新規プロット案／未実装
・発端：世話の引き継ぎ先がない少女を、街で預かる
・対立：名簿の返還先と、本人の望む場所が違う
・山場：保護の結界が、街からの退去も塞ぐ
・余韻：一人は移れる。ほかの子の空欄は残る
流れ：預かる → 守りが檻になる → 一人の行き先を選ぶ
台詞例（第5章案の場面／未実装）：帰還を確認するまで、／この門は開けられない。 ［引き継ぎ役の管理者・仮］

10　第6章案「灯を返す夜」／新規プロット案／未実装
・発端：役目と祈りを一晩だけ預ける、灯の祭り
・対立：休みたい人と、代わりがいない人
・山場：古い記録が祭りを維持し、帰り道を止める
・余韻：祭りは続く。空の灯も一つ残る
流れ：休みを預ける → 代役が足りない → 灯を返す
台詞例（第6章案のリオラ／未実装）：あの方への祈りは、私がする。／今夜の見張りは、代わってくれ。 ［リオラ・仮］

11　第7章案「ふたりの署名」／新規プロット案／未実装
・発端：リオラと、儀式の世話人の欄を埋め直す
・対立：崇拝の願い・ふたりの願い・迎える子の先
・山場：主人公が、昔の記録を使う誘惑に向き合う
・余韻：止める選択も含め、今度は一緒に決める
流れ：準備をする → 違う望みを知る → 今夜を決める
台詞例（第7章案の会話／未実装）：今日は、止めよう。／今度は、明日にしない。 ［主人公とリオラ・仮］

12　定数は、人格や愛情の点数にしない／現行の仕組み／今後の設計案
・キャラの定数：基礎能力などの計算に使う値
・ダンジョン難度：敵編成・補正・WAVE等から算出
・物語との接続：強さより、役割と危険の意味を変える
・避けたい設計：恋愛の成功で数値上昇／病状＝デバフ
流れ：物語の事情 → 戦闘の条件 → 対策を選ぶ
台詞例（設計方針の提案）：強いから正しいのではない。／弱いから、守られるだけでもない。 ［座談会の整理］

13　関係から、技と石を考える／新規スキル・記憶石案／未実装
・リオラ「帰還の合図」：一度の大技に備える／仲間を守る理由
・ノエル「余白の星図」：次の支援につなぐ印／観測の限界も描く
・記憶石「空席の灯」：行動を見送る代わりに、次の守りを準備
・共通の制限：一人へ負担集中させない／上限・再使用
流れ：関係の変化 → 技の条件 → 戦闘で実感
台詞例（新しい技の方向性／未実装）：守りたい相手がいる。／でも、自分の休みも必要だ。 ［技と物語をつなぐ案］

14　反省を、次の執筆で確かめる／執筆と実装への提案
・場面の確認：各人に、主人公と別の用事があるか
・時間の確認：恋愛・信仰・回復が急に進んでいないか
・遊びの確認：章の意味と敵の行動・対策が結び付くか
・公開の確認：あらすじと実装を区別／ネタバレの導線
流れ：一場面を書く → 物語と戦闘で読む → 次を直す
台詞例（この座談会の軸）：その子は、主人公が来ない日も／暮らしている。 ［執筆の確認項目］

少女たちは、明日も同じとは限らない／まとめ／今後の案への感想募集
・反省の中心：衝撃の後の日常／関係を急がない
・世界の厚み：管理と文化を、一人の暮らしから描く
・今後の章案：空欄の名簿／灯を返す夜／ふたりの署名
・遊びとの接続：役割と対策に、物語の理由を持たせる
流れ：名前を呼ぶ → 返事を聞く → 一緒に決める
