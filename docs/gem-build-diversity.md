# 石・能力配分の改修（1.29 / combat rule 4）

目的は、全所持・高Tier装備でも低レアを選ぶ理由を残し、高レアの価値はリーダー能力に置くこと。既存の連続討伐100手、Bからの早期ボス移行、収穫の暫定報酬を前提に実装する。キャラ専用ステージや敵判定は追加していない。

## 共通のキャラクター定義

敵・味方で別の基礎能力表を持たない。同じ `baseStats` を使い、敵には `encounterStats` が出現倍率・既存ボス倍率・既存ステージ倍率を適用する。出現倍率は `min(1, strength / 24)`。導入区間の弱い敵を維持し、24を超える個人定数を敵だけの恒久的な基礎能力優位として復活させない。素早さには出現・ボス倍率を掛けない。

役割ごとの共通基準は旧定数2.4相当。通常技も強度18へ統一し、ID・再使用待ち・固有契約は保持する。固有の回復、返礼、妨害、研究技能を他キャラへ複製していない。定数は既存リーダー補正・出現設計の指標として残す。レアリティを変更しただけでは本人の基礎能力・通常技強度は増えない。

|配分|HP|攻撃|防御|素早さの差|
|---|---:|---:|---:|---:|
|均衡|100%|100%|100%|0|
|機敏|90%|100%|90%|+2|
|鋭撃|95%|110%|95%|0|
|重撃|105%|110%|105%|-2|
|堅守|110%|90%|110%|-1|
|持久|115%|90%|105%|-1|

HP・攻撃・防御の百分率の和＋素早さ差×10を300に揃えた**設計用の名目予算**。各能力の実戦価値が数学的に同じという意味ではない。防御の閾値や行動順があるため戦闘測定は別に行う。52人物・75形態に手動の配分と得意石2個を登録。

## 石の適性

|レアリティ|技効力への倍率|
|---|---:|
|R|1.25|
|SR|1.15|
|SSR|1.05|
|XR|1.00|

得意石はさらに×1.12。通常の覚醒・イベント覚醒は元の高い適性を保持し、衣装違いへ無条件に継承しない。石の基礎ロールとは区別し、装備者の最終効力を装備画面に表示する。追加特性値を一括で再乗算しない。固定回復の「摘まない白花」には適性倍率もかからない。巻戻し・睡眠・星炉など既存の上限を守る。

## 6つの追加石

すべて装備枠・通常の一手・共通の石再使用待ちを消費する。既存の香・ランタン・研磨・収穫ソケットとは別の、キャラ装備の技。

|石|仕事|代価・制約|系統|
|---|---|---|---|
|掃討晶石|敵全体を削る|敵2体以上、CD4。単体には使えない|機巧|
|残火石|撃破時の余剰火力を別の敵へ|実際の主攻撃による撃破が必要。転送半分、攻撃×石効力×1.2上限。再連鎖しない、CD4|黄昏|
|野営灯石|3討伐後の全体回復|準備に一手、5ラウンド以内の味方主攻撃3討伐。5%HP×石効力、35%上限、CD5|聖域|
|共鳴標石|2人の主攻撃をまとめる追撃|標に一手、4ラウンド。異なる2人の実HPダメージ。追撃では進まず、付与者が生存している必要、CD4|機巧|
|破調印石|ボス予告を崩す貫通攻撃|ボス限定、予告準備中1.75倍。無条件の行動停止ではない、CD4|聖域|
|戦果の備え石|狩りの討伐をボス用のゲージ・障壁へ|道中で準備に一手。主攻撃討伐12体まで。本人へ一度だけ変換。ゲージ35・障壁40%HP上限、CD6|黄昏|

上記は通常石として各系統の実在する入手プールへ追加。新しい専用ドロップステージはない。製作は既存の欠片6個。T6への調律昇格はなく、高い技効力Tierは既存の対応ダンジョンで新しい原石を探す。石の種類が増えるため、特定の既存通常石の抽選比率は変わる。総ドロップ率や既存のT6確率を上げたという意味ではない。

## 高レアだけのリーダー効果

- アストレア（XR）「終天の裁定」：味方の主攻撃による予告崩しから、同ラウンドの次の味方主攻撃を35%強化。各ラウンド1回、追撃や持ち越し不可。
- セレネ（SSR）「月宴の救命」：致死被弾に本人の必殺ゲージ100を支払って味方をHP1で残す。同じゲージなので本人の必殺と競合し、残量不足・死亡・非リーダーでは救えない。
- フォルトゥーナ（SSR）「幸運の隊商」：連続討伐のB/A/S/SS初到達で生存味方へゲージ15。各ランク1回。討伐数やドロップを捏造しない。

いずれも編成に入れるだけでは発動しない。Rノエルの号令、サクヤの花宴など別の王冠を選ぶ機会費用が残る。号令を石・必殺・回復・障壁の直接操作へ拡張しない。

## セーブと再現

進行・装備・所持・既存原石の封入結果を維持。旧rule 2および公開済みrule 3の戦闘は、そのルール・イベント・乱数・報酬を保持して最後まで再開する。旧戦闘では追加石を抽選しない。出発し直すとrule 4へ移行する。新しい印・準備・王冠状態は型と参照先を検証して保存する。

## 検証範囲

`npx tsx scripts/balance-gem-diversity.ts`：既存の早期ボス移行、100手の継続討伐、白亜の塔第1層で比較。T3=80/T4=130/T6=230、各4石・追加特性なし・薬5個、結晶・妖精・収穫援護は使わない。候補9編成×4リーダー×2石組×3作戦（216候補）。Rを含む群とRなし群を、編成ごとに同じ探索量で評価し、開発用8シードで選んだ候補を未使用200シードで測る。群の候補数は120対96で同数ではなく、Rなし群にはSR入り候補も含む。最強の全探索や特定キャラ固有能力の因果的認定ではない。

`npx tsx scripts/audit-gem-roles.ts`：75形態・52人物の共通能力、通常技契約、T6石効力を一覧化。同人物の覚醒違いを除く特徴被覆候補は1組（フォルトゥーナ→ウカノミタマ衣装）。王冠や実戦連鎖は含めないスクリーニングなので、上位互換の証明ではない。フォルトゥーナには固有の討伐ランク王冠があるが、メンバー採用の独自性は別途観察が必要。

**全52人物が最終盤で実用的、厳密な上位互換ゼロ、何体まで無制限に設計可能、と認定していない。** 固有技・役割・配分・得意石・王冠という設計軸は実装したが、全人物の公平な置換探索は未検証。実装した構造、有限候補で得た攻略例、未検証の全体最適を区別する。

実測表・全シード・構造監査は同ディレクトリの `gem-build-diversity-data/`。勝率100%も200回での観測であり、母勝率の確実な100%を意味しない。200/200のWilson95%下限は約98.1%。異なるTierで編成を再探索しており、Tierの純粋な因果効果とは解釈しない。石や能力を変えて確認シードへ繰り返し適合させていない。

## 不採用案

共通能力の基準18で先に測定したところ、塔第1層の有限候補がT6でも両群0/200になった。既存攻略への影響も確認し、この基準値を不採用とした。`rejected-reference18/` はこの失敗を残したもの。採用候補は基準24で再計測し、採用表と混ぜない。通常技強度は両案とも18。基準24は全員のHP・攻撃・防御の共通水準を上げ、出現倍率の分母も同じ24へ変える。敵だけに別の基礎値を与えていない。

最初の8編成探索に範囲役を含むSSR編成が不足していたため、ノクス・アステリア・セレネ・アテナを候補へ加え、全4リーダー・3作戦で探索し直す。失敗を見て確認用シードに強化値を適合させた認定とは区別し、全体最適や固有キャラの不可代替性は認定しない。
