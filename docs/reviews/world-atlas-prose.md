# 世界地図・道中の文章の改稿記録

対象は1.20の地図、既存7章の接続、本編・幕間の地図導線、地図専用の短編。IDや既存ページの順番は維持する。章の進行条件、戦闘難易度、獲得物は変えない。

## 初稿を批判して直した点

| 指摘 | 修正 |
| --- | --- |
| 「ザクロの庭から戻ったギルドに」ではギルド自体が帰ってきたように読める。 | 主人公たちがギルドへ戻り、そこで依頼書を見つける順にした。 |
| 「名簿の返還先」は、本の届け先なのか人の帰還先なのか曖昧。 | 名簿に記された帰還先、と参照関係を明示した。 |
| 「名簿の綴じ目を渡す」は、物として何を渡したのか成立しない。 | 持ち歩く名簿を渡す動作に置き換えた。 |
| ルカの章導入では主人公の袖を見ているのに、直後の幕間ではリオラ自身の袖になる。 | リオラが自分の袖口を差し出す場面に揃えた。 |
| 「私の背丈に合う場所」は、夜番のどの仕事に必要か分からない。 | 合図の紐を手の届く高さへ結ぶ行動に具体化した。 |
| 「その一言が、紙の空欄を守った」「一人の役目が終わっても街は終わらない」は、地の文が人物より先に教訓を言う。 | 迎えの列が待つ、交代した人の声を聞いてネリが食事を取る、といった観測できる結果に替えた。 |
| 主人公が他人の返事を代弁しないテーマを、毎回ほぼ同じ説明で結んでいた。 | 椀を取り分けずに待つ、宛先を朝に聞く、封筒を別々に置くなど、場面ごとに違う行動へ分けた。 |
| 足跡の向きと「戻りの足跡」の説明が噛み合っていない。 | 聖堂から戻った仲間の跡であることを明示した。 |
| ギルドで登録を済ませたあとに「名前はまだ聞いていない」と言うと、前の場面を忘れたように見える。 | 記録上の名前ではなく、呼んでほしい名前を尋ねる会話にした。 |
| 紐の位置だけで「負傷者を助けた」と断定している。 | 実際に枝を持ち上げ、腕を吊った仲間を支えている少女を先に見せる。リオラは見えたことと直前の戦いから危険を説明する。 |
| 「裂け目を残して服を直す」「帰ってきた服を一緒に持ち帰る」は、修理内容も時系列も不自然。 | 残すのは古い縫い目。同行したい理由は、旅先でもほつれを直せること、とした。 |
| 避難・放流・封印解除の相談が「まだ決まらない」だけで終わり、次の探索へ何を試すのか見えない。 | 避難列の最後が通る場所に、セリスから見える合図の灯を置く案を出した。作戦の成功までは保証しない。 |

| ザクロ戦の前に解放される短編で、すでに森の外へ逃げたように見える。 | 解放条件とIDは変えず、倒木の陰で一息つき、包囲を突破する細道を探す場面に直した。 |

## 改稿後の二度目の見直し

新しい短編3件を通読し、次も修正した。

- 糸を勝手に主人公の袋から抜く動作は、ルカが用意した糸を取り出す動作へ変更。
- 暗がりで赤い糸が見えるという断定は、「灯を向ければ見える」へ変更。
- ネリの話に出る「器」が食卓の椀か供物の灯か曖昧だったため、供物棚の位置と椀へ汁を注ぐ動作を分けた。
- 既存の短編・章内の修正は30箇所以上。追加3編は各6ページ。テーマの説明を増やすためではなく、書記・夜番・仕立て屋それぞれの仕事と会話で人物を見せる。

## 地図との対応

全7章の68地点、本編・幕間・地図短編の30場面、追憶5地点、イベント13地点、腕試し9地点を地図と索引へ接続。白亜の塔は入口から既存の階層選択へ進む。未解放の物語タイトルは出さず、既存の探索条件を満たしたときだけ場面のピンを追加する。序章の読み返しを、初回探索の目標として勧めない。

これは地図周辺と接続する本文を中心とした改稿であり、全本文の全面書き換えではない。校正テストは文章の自然さそのものを保証しないため、上記の指摘と修正内容を別に残す。
