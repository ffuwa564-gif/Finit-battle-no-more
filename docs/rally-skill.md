# 軍神の号令

アテナの通常版（SR）と和装版（SSR）に、共通アクティブスキル `rally` を追加する。各キャラの2スキル・強さ予算の契約を保つため、通常版の障壁破壊、和装版の貫通攻撃を号令へ置き換える。「かばう」とリーダー効果は維持する。旧スキル定義・IDは残し、保存済みの戦闘イベントを再生できる。

生存中の自陣全員（自分を含む）へ、発動ラウンドと次ラウンドの攻撃強化を付与する。単体の攻撃強化と同じ計算式・状態欄を使う。倍率は `1.15 + strength / 200` で、通常アテナは24%、和装アテナは26.5%上昇。加速と併用した場合は既存の乗算に従う。回復などに対する攻撃強化の既存ルールも共通。

攻撃強化は加算しない。既に有効な強化がある場合は強度・有効期限それぞれ大きい値を維持し、強い強化を弱い号令で上書きしない。敵への強化はない。ただし敵として登場するアテナも同じスキル選択を使い、自陣の生存者が2人以上なら味方を強化できる。

再使用は4ラウンド後（1ラウンド目発動なら次は5ラウンド目）。通常の行動を1回消費し、追加行動は発生しない。リーダーである必要はない。既存のかばうや緊急回復・浄化・有効な戦術カウンターを優先し、その後に強化可能な味方がいる場合に使用する。全員に同等以上の強化が有効な場合や単独生存時には使用しない。睡眠・麻痺・混乱・魅了は既存の行動制御を先に適用する。

状態は既存の `buffStrength` / `buffUntil` に保存する。Wave移行時の解除、再読み込み、強化解除、リプレイのスナップショット、味方顔グラの「攻撃↑」、全員対象の強化演出・効果音を共用する。音は既存buffと同じスコアを参照し、新しい音源は追加しない。日英のスキル説明と再使用間隔を表示する。

検証は `tests/rally.test.ts`（実キャラ両形態、非リーダー、対象、ダメージ、強化の競合、クールダウン、期限、状態異常、かばう優先）と `e2e/skills.spec.ts`（詳細表示と再読み込み後の全員の状態表示）。
