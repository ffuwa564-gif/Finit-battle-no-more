# 1.10 — 試走後の準備導線改善

2026-11-01。ローカル開発のみ。PR・マージ・ゲーム配信は行わない。

## 試走で確認できたこと

固定乱数20261101の新規セーブによる921操作で、通常探索10勝、白亜の塔1層2敗。塔は両編成とも3ラウンドで全滅した。通常探索で集めた17個の記憶石の用途や、製作してから戦闘で試すまでの導線、号令の代償、敗戦後の準備先に改善の余地があった。

この試走は人間によるユーザビリティ調査ではなく、塔全体の難易度や勝率の根拠にもならない。今回は進行・戦闘・報酬の数値を変更せず、既存ルールで次の実験を選びやすくした。

## 実装

- カバンの道具タブ上部に「次の装備実験」。白花の防御後回復／灯芯の攻撃と追撃を選べる。
- 所持状態から「同系統の欠片を集める→製作→装備→通常探索で試す」を判定。実際の製作費6個を使用。通える同系統の通常探索を示し、踏破済みの道を優先する。道が未解放なら通常章の進行へ戻す。
- 石そのものが落ちると誤認させず、欠片を踏破報酬で集めて製作することを明示。未所持のキャラ・石の付与や自動分解・自動装備はしない。
- すでに所持している目標石は製作ボタンの代わりに装備確認へ誘導。ユーザーが確認ボタンを押した場合だけ共通InventorySectionの所持石区画を開く。通常の一覧・製作・入手先は初期折りたたみを維持する。
- 装備済み数は出発パーティのみを数える。控えの装備を準備完了と誤認しない。移動する場合は既存の確認処理を使う。
- 塔にも共通の装備実験を折りたたみで配置する。
- 敗戦画面に実測ラウンド・敵へのHP被害・回復と、帰還して装備／ビルドを確認するボタンを設置。帰還の保存成功後にだけ移動する。帰還は既存コマンドなので履歴は1件だけ確定する。
- 「記録から次に試すこと」は初期折りたたみ。時間切れ、行動不能、実際に持ち込んで未使用の薬、最大被害をもとに次の操作実験を示す。未記録の敗因は断定しない。
- 号令モーダル上部に本人の通常1手と追加リーダー効果の消費を表示。予約直前にも受領人数・宛先・一手消費を表示する。通常単体行動の宛先だけを合わせる点を明示する。
- 日本語・英語を対応。戦闘中の常設説明や独自UIの操作音を追加しない。
