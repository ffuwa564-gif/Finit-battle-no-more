## 戦闘と育成

- 白亜の塔を100層・100通りの最終編成へ再構築。公開されている75フォームを全て主役として配置し、単騎・護衛・複数体・連戦・ビット・時計で対処を変える。敵の通常回復は1体1ウェーブ3回、障壁は2回まで。旧到達記録を残し、新塔の解放記録と分ける。
- 未解放階を含め、準備画面で編成・技・対策を確認できる。偵察では出発・進行・資源消費は起きない。
- 通常ノエル、ティッカ、リュシエル、帳の巫女、通常ヘーベー、通常フローラに、本人の通常技能を支える固有効果を追加。強い既存の強化・障壁を弱いもので上書きしない処理も改善。
- 「灯芯の補助石」を機巧の欠片6個で確定製作。固定T3・再使用3ラウンド。低い攻撃参照値を補い、実ダメージの35%で一度だけ追撃する。全キャラが装備でき、覚醒で装備不能にならず、高攻撃では補助分が自然に減る。調律や上位Tier抽選はしない。
- 石の用途フィルター、用途・代償の説明、既存3ビルドの相性・代替・リーダー選択の解説を追加。長い説明は共通の折りたたみ区画へ置き、既存のスタック・検索・ロック・付け替えを維持する。

## 仲間・物語・導線

- イオネ（印の回収）、ネリ（予告大技への備え）、フィオ（余剰回復の障壁化）、ルカ（障壁の自然消滅から残り糸）の4人を追加。立ち絵・日英説明・状態詳細・リーダー効果を備える。
- 第5〜7章を各10ステージ追加。名簿、夜番の交代、二人の署名を通して、少女だけの世界の記録・文化・役割・関係を描く。リオラの信仰と段階的な関係変化、既存OP・第1〜4章の既読を保つ。
- 4人は該当章の確定素材から加入できる。素材獲得→発見→共通の加入操作→消費までを実際のコマンドで検証した。
- ホームに次の未踏破ステージと初回報酬を表示。タップ先は探索準備であり、自動出発はしない。通常章を全て終えると新塔の次層を案内する。

## 旧セーブ

対応する旧版 `0.1.0 / initial-r1 / rules1 / schema1` から明示移行する。所持・装備・ロック・編成・乱数・ガチャ履歴・既読・旧塔記録を保持し、移行前の原本は通常バックアップとは別に保存する。設定のバックアップ画面から原本を取得できる。

旧ルールの探索は新ルールで再生せず、安全に終了する。既に確保した素材を持ち帰り、勝利計算済みなら報酬を一度だけ精算する。新しい戦利品抽選や乱数消費は行わない。移行保存はIndexedDBの単一トランザクションで競合を検出する。未知・未来版や不正な保存を強制変換しない。

## 根拠と採用しなかった案

`STILLVEIL-ver1-ranking/artifacts` の character-spread / rescue-sequel / tower-redesign / tower-maximum / scenario-review-v1 / scout-conference-v1 / ver1-retrospective / tower1-minimum と対応表を参照した。役割間の連携、低めのキャラの仕事、敵の多様性、装備目標と物語の接続を主な改良軸とする。

未校正の塔100層275.3曲線、一律の薄い追加障壁、王冠4案の全員配布、研究用切替スイッチは採用しない。灯芯は研究の低レア限定案を調整し、覚醒の不利益を避ける。旧研究の改善率をそのまま新版の成績として扱わない。

初回時点で保留していた探索時間・収支の記録と戦闘全体の被害・回復・障壁の集計は、その後の追加改良で実装した。敵全員の個人必殺ゲージは未実装。装備目標と入手先の案内、塔の準備画面での対策説明は実装済みだが、これらの記録・分析機能を実装済みとは扱わない。石の取得から初装備・初使用までの専用チュートリアルも、ホームの次の探索目標とは別の保留項目とする。

## 検証と限界

詳細な受入記録は [v1.10-qa.md](../v1.10-qa.md)、塔の仕様・実戦試験は [ivory-tower-v110.md](../ivory-tower-v110.md) にある。

塔は4固定条件×100層×10seedの4,000戦を現行エンジンで確認した。前回のT6参照編成が一層から全seedで成功する区間は方針により16層・22層まで。100層は全条件0勝。ただし各層を独立に試した結果であり、全編成の最適解や人間の連続踏破記録ではない。

版移行・原本保持・加入・装備・報酬受取・次層解放を統合テストし、日英320/390pxの管理・詳細表示をブラウザで確認した。技能と状態は単体・エンジン統合でも検証する。ライフサイクル試験で攻撃力を上書きしたケースは難度の証拠に含めない。

全キャラの強さが均等になったこと、全ビルドの最適解、全100層の攻略可能性、実プレイヤーの継続時間は保証していない。敵全員への個人必殺ゲージの導入も今回の実装には含まない。

最終チェックは80ファイル・591テスト通過、型/content/UI/英語チェックと本番ビルド通過。ブラウザは新機能・旧塔・加速・状態表示・ネイティブ操作を合わせて30ケースを確認した。Chromium/WebKitのLinux上の検証であり、実機iPhoneでの視聴確認とは区別する。

ローカル確認は `npm run dev -- --host 0.0.0.0 --port 4194`。本番生成物は `dist/`。保存は配信元URLごとに独立するため、別の配信元から引き継ぐ際は設定のバックアップ保存・読込を利用する。

`npm run build:itch` も通過。最終ソースから `dist-itch/` と `artifacts/stillveil-itch-preview.zip` を再生成した。ZIPの作成のみで送信・公開はしていない。

追加章の難度定数は第5章20.7〜21.5、第6章21.7〜22.6、第7章22.7〜23.7。既存の通常ボス＋護衛2人までの制約を維持した。独立した30seedの代表編成試験では成熟T3の各章ボスが27/30・28/30・29/30勝。初期比較編成は後半で0勝となり、表示定数だけでなく編成・成長が必要になる。条件と限界は [物語・章の検証](../v1.10-story.md) に記録した。
