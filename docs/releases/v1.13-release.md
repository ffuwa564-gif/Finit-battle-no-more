# STILLVEIL 1.13

2026-11-04。ユーザーから「先ほどの最適化をver1.13としてitch.ioに反映、BGMの音量を下げ、そのうえで初期設定を50%」との公開指示を受けて準備する。

## 内容

- 背景の未発生イベント・透明粒子の計算を省略。通常の背景は15fps、攻撃などの演出時は30fps。共通の一時停止状態に合わせ、隠れた背景を休ませる。
- 顔グラのHQ動画、枠・結晶のアニメ素材と解像度を保持。
- BGMの全体出力係数を0.5（約−6dB）に変更。新規開始時のBGM設定は50%。この組み合わせで初期出力は元素材の0.25。旧初期設定0.4から見ると出力振幅は37.5%低下する。体感音量の割合や端末の音量設定とは区別する。
- 既存セーブの設定値・ミュートは上書きせず引き継ぐ。保存済み設定が同じ場合、BGM出力のみ半分になる。SEの設定・音量・操作音の所有権は維持。
- appVersion/画面表記を1.13へ更新。content/rules/schemaは維持し、1.10/1.11/1.12のセーブ・バックアップを戦闘途中のまま移行できるようにする。

## 検証と限界

`npm test`：92ファイル・727件成功。BGMの場面切替、ダッキング・ミュート、50%初期設定、旧セーブの戦闘・乱数・石・設定の引継ぎを含む。`npm run build:itch` 成功。

背景描画の同時刻比較21条件、停止・復帰・更新頻度の回帰試験は最適化PRに記録した。元の描画比較の結果とソースハッシュは `docs/performance/animation-optimization-20261104*` を参照。

ソフトウェア描画での待機画面CPU中央値は約5.23%低下したが、測定範囲は重なり、1組では悪化している。iPhone実機のGPU・発熱改善の保証はしない。DLSS、フレーム生成、顔グラの低解像度化は今回含まない。

公開は既存のitch.io HTML5ワークフローで実施し、配信先・価格・ページ本文は変更しない。配信の実行結果とコミットはGitHub Actionsの対象実行に記録する。
