# STILLVEIL 1.22

次の行動・目的・行き先を一致させる案内と、戦闘から独立した工業クラフトを追加する。

- 全7章の主会話に行動名と理由を付け、ホーム・目標アイコン・地図の小さな案内で同じ次の行動を表示する。案内は閉じられ、次の工程に進むと更新する。
- 11種類の原資源をダンジョンの踏破報酬で獲得。採掘・釣り採水・伐採採集の入手量を準備と報酬確認に表示する。失敗・撤退では得られず、報酬確定の二重実行でも増えない。腕試しは対象外。
- 51種類の品、44の製作図、11種類の装置。中間素材、手動加工、装置の設置、装置ごとの自動加工、生産停止・再開、保管箱、採集収量を上げる道具を用意。別の精錬炉で鉄と銅を並行生産できる。
- 自動加工は持ち帰った資源を消費する。材料切れ・保管上限で停止し、補充後に再開する。未起動期間は最大2時間分を処理し、同じ時刻や時計の巻戻しで生産が重複しない。踏破報酬は自動保管上限を超えても捨てない。
- 工房の目標から、足りない中間素材・装置・原資源を逆引きして次の一手を案内する。資源の入手先から地図のダンジョンを選択できる。未開放の資源は地図上の旅を先に進めるよう案内する。
- 各章で一つずつ物語の道具を製作。済んだ会話・章はやり直さず、更新前に開いていた会話も続行できる。道具は消耗しない。
- 戦闘能力・スキル・敵・戦闘乱数・敵素材・通貨・ガチャには工房を接続しない。採集道具は対応する資源収量だけを強化する。
- ダンジョンの準備前・踏破後の旧本文と自動割込みを撤去。短いフレーバーと資源情報を表示し、続きは地図の人物との会話で回収する。既存の読了記録と手動アーカイブは保持する。
- 地図ラベルを画面端へ押し戻す処理を撤去。縮尺補正とアンカー位置の計算順を修正し、拡大・移動しても地点からずれないようにする。通常の地図を約3割広く描画し、縮小すると以前と同じ全景まで見渡せる。目的地カードを小さくし、日常の吹き出しは選択時・拡大時に見せる。地図を広く表示する切替では下部ナビを畳む。

アプリ1.22.0、コンテンツv1.22-r1、ルール3、スキーマ1。1.21・1.20の所持品・地図・会話・進行中の戦闘を保持して移行し、1.10〜1.13の互換性も維持する。旧データに工房資源を遡って配布せず、次の踏破から獲得できる。動画制作物は含めない。
