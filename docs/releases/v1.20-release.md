# STILLVEIL 1.20

2026-11-05。地図・原石研磨・地図上の物語に、ビルド研究日誌／研究独白で実装した技能改修を統合する。ユーザーの依頼によりPRをマージする。**itch.ioへは配信しない。**

## ゲームの変更

- 探索の入口を、ドラッグ・ピンチ・拡大縮小できる世界地図に変更。通常探索・物語・イベント・塔・腕試しへ移動する。目的地まで6〜45秒のオートトラベルを行い、従来の一覧も残す。
- ダンジョンの記憶石は原石として持ち帰る。期待値の区分だけを先に表示し、カバンの時間制限付き研磨でTierを開示する。高期待値ほど狭い成功域になる。未研磨・失敗で原石や抽選結果を失わず、再試行で抽選し直さない。
- 地図上に6件の短い任意の物語を追加。新しい気配を目印に、人物との出会いから次の探索先につなげる。
- 研究独白の採用案を通常版へ統合。サクヤの障壁返礼、ミエットの失効障壁からの修繕、ティッカの封印成功後の通常攻撃減衰、ノエル回の資源を考慮した号令予約、リゼットの実際の強化解除後の返し刃。発動条件と有限の消費を保つ。
- ビルド研究日誌の5技能（ルカの留め縫い、ネリの休番、イオネの宛先、フィオの預かり箱、エレインの容量復元）を型付きエンジンへ移植。所持キャラ画面から出発前に個別切替でき、元の技能も選べる。
- 巻戻し・連続当番・最大HP容量を扱う3件の報酬なし研究試練を追加。条件を探索準備で確認できる。通常ダンジョンの敵を研究専用の条件へ置き換えない。

## 互換性

アプリ1.20.0、コンテンツv1.20-r1、ルール3、スキーマ1。1.10〜1.13のセーブとバックアップは設定・所持品・戦闘の乱数や再生位置を保持して移行する。進行中の旧探索には旧技能データとルール2を適用し、次の出発から新ルールを適用する。
