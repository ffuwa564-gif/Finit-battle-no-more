# ver1.25 — 勲章ツリー

図鑑に「勲章」を追加。工房・探索・連携・仲間の4系統31種類。高Tier製作、灯力網、章と塔の踏破、キャラクターの技能を活かした挑戦をツリーとして確認できる。

条件の確認、目標設定、関連する製作・編成・地図への移動、称号設定に対応。確定済みの工房・探索進捗を反映し、固有の戦闘条件は新しい探索から記録する。戦闘系は獲得確定で授与し、敗北・撤退や演出の再生で加算しない。能力値やガチャ率を変更しない。

1.24を含む対応済み旧版から、探索・会話・移動・工房の状態を保持して移行する。

直前の地図修正も含む：重なった地点の候補選択、祈願石などから旧ダンジョン一覧に戻る経路の廃止。ダンジョン画面は地図を維持し、塔や覚醒などは地図上のパネルで開く。

公開先はCloudflare。itch.ioへの反映は行わない。
