# 1.30 — 転生と、記録の裏側（未公開候補）

前提: 石・基礎能力のルール4更新（PR #174 / 1.29）。この変更は専用ブランチの追加PRで管理する。マージ・itch.io公開は別操作。

- 第7章と七管理者編の結末後、ホームからストーリー進行だけを巻き戻す転生を追加。
- 仲間・覚醒・記憶石・装備・所持品・工房・勲章・塔・生涯の初回報酬記録を引き継ぐ。
- 過去のクリアで新周の章を飛ばさず、初回報酬を再取得しない。再読了後は再び転生できる。
- 転生後にT7（技効力・特性280–299）、T6/T7製作、超絶難度の別ルート6区間を解放。
- 別ルートの導入と6本の記録で、欲望の扉・主人公の生還・七管理者の記録の裏側を描く。
- 上位製作の素材は最初の区間から取得可能。T7は途中回収では出ず、踏破宝箱と解放後の製作で得られる。
- 1.29の進行中戦闘のイベント・乱数・戦利品を保持して更新。旧ルール3戦闘の互換性を維持。

仕様・素材数・確率の解釈・ストーリーのネタバレは [転生仕様](../reincarnation.md)、実戦データは [難度検証](../research/reincarnation/README.md) を参照。
