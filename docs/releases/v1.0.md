# STILLVEIL ver1.0 — 機能の区切り

記録日：2026年10月31日。

この時点までの実装を、STILLVEILの **ver1.0** とする機能範囲として記録する。今後の追加・調整は、この区切りからの更新として扱う。

基準コミット：[dbd3da0724a34612ca3a3d16b4a3f4cd7f300223](https://github.com/ffuwa564-gif/Finit-battle-no-more/commit/dbd3da0724a34612ca3a3d16b4a3f4cd7f300223)。長押し対策、現在編成・先頭選択の改善、編成ボタンの縦伸び対策までを含む。

## ver1.0に含める内容

- **探索と戦闘**：最大4人のパーティ、先頭の操作役とリーダーの独立した指定、作戦・道具・自動スキル・必殺技、WAVE進行、戦利品の確定、全滅・撤退時の扱い。
- **攻略先と周回**：章立ての通常ダンジョン、白亜の塔、祈願石周回、常設イベントと腕試し、WAVE間の選択と蓄積による効果。
- **仲間と育成**：素材による仲間化、通常ガチャと10連演出、覚醒、人物の記憶、一部キャラクターのアニメーション。
- **装備厳選**：記憶石の装備・解除・保護、製作・調律、効力と特性のTier1〜6、上位Tierを目指す周回。
- **ビルドの道標**：目標の保存、所持キャラ・石による組み合わせの確認と編成、不足素材・品質・入手先の案内、見本装備による戦闘の実演。
- **物語と案内**：初回の妖精ガイド、全画面でフェードするビジュアルノベル、OPと章の物語、ログ・スキップ・読み返し。
- **画面と音**：現在の編成表示、先頭・リーダーの選択、スマホ用の操作配置、高解像度の顔グラ、BGMと効果音、個別音量、動き軽減、日本語／英語。
- **保存**：ブラウザーへの自動保存、バックアップの保存・復元、競合・破損・非互換データを上書きしない安全停止。
- **共通UIの契約**：画像・動画・ポータルの長押し対策、操作音の所有権、編成カードのボタン配置を共通部品に集約。型・ビルド検査とブラウザ検証で維持する。

## 未公開の内容

XRは、キャラクター「アストレア」、通常とは別の抽選、上位石、解放判定の仕組みを先行実装した状態。

- XRの設定排出率は0.1%。
- 解放条件は第10章までの踏破を判定する設計。
- 「星晶の祈願」は `published: false`。上位石の通常の入手先も用意しない。

これらはver1.0時点の準備済みデータであり、現在プレイヤーが利用できるガチャ・入手導線としては扱わない。
