# STILLVEIL 1.21

2026-11-05。少女たちとの日常会話、探索、大事件を一枚の地図でつなぐ全7章の物語を統合する。PR #151。

## 変更

- 地図の「少女たちと旅を始める」から、主人公の名前・話し方・好みを設定。56件の進行会話と11件の日常会話を、移動・依頼・探索で進める。
- 事件はホームと地図に告知し、解決後は日常に戻る。通知を閉じるだけでは事件は解決しない。
- 第1章を丘から白亜の塔を眺める場面、宝石を贈る少女たち、個体生成の庭、庭園の女の昼と夜から導入。帰還後のリオラの忠義と混乱、その療養も含める。理由はこの章では明かさない。
- 地図会話をOPと共通の全画面表示に変更。背景、台詞、前後送り、ログ、選択肢、途中再開を揃える。
- 原石研磨中も物語のオートトラベル経路を表示する。
- 初回案内も地図の自動移動と到着後の探索準備に対応。記憶石管理の検証は原石研磨と区別して正しい入口を操作する。
- Node.jsのブラウザ試験から会話JSONを読み込めるよう、JSON import属性を明示する。
- ブラウザ検証は設定済みのサーバーへ接続し、CIは4分割・各1ワーカーで全件を実行する。描画を競合させず、失敗時の再実行と各分割の検査画像を保持する。

## 互換性

アプリ1.21.0、コンテンツv1.21-r1、ルール3、スキーマ1。1.20の所持品・進行・設定・乱数・戦闘再生位置・移動・会話を保持して移行する。既存の1.10〜1.13からの移行も維持する。バックアップの読込も同じ移行を通す。ゲームの難易度や報酬は今回変更しない。

全7章の接続試験は探索踏破フィクスチャを使用しており、全戦闘の実攻略を保証するものではない。検証結果はこのPRの最終コミットに対するActionsを参照。動画制作の素材・ツールはゲームの配布に含めない。
