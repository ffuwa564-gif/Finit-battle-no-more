# STILLVEIL 1.24

工房にTier1〜5と「灯力」を追加し、採集した資源から部品・設備・上位の採集道具へつながる開発を拡張する。素材と動力は工房で管理し、戦闘の能力・スキル・乱数は維持する。

- 67種類の品、63種類の製作図、17種類の設置設備。原資源はTier0、製作はTier1〜5。上位の製作図には必ず下位Tierの材料が必要。Tierと系統名もカタログで定義する。
- 木炭を燃やす灯芯炉、燃料不要の月下の水車、蓄光結晶を使う月光共鳴炉。共通の灯力網へ供給し、蓄灯槽で容量を増やす。
- 第2章の灯力製材、第3章の灯力精密加工・結晶加工は、既存設備で動力を使って材料あたりの生産量を増やせる。
- 第4章以降は共鳴回路・導灯合金・共鳴組立機、第5〜6章は星紋回路・星灯工作機・自律核へ進む。共鳴式の採集道具は従来の機械道具、自律式は共鳴式を材料にする。採集量の増加は同系統の最大効果だけを適用する。
- 工房にTierフィルター、材料のつながり、必要灯力、発灯能力、自動設備の需要、燃料・停電・満蓄の状態を表示。長い一覧と材料のつながりは初期状態で折りたたむ。
- 停電中は自動加工の途中経過を保持する。限られた灯力は絶対時刻に基づく順番で分配し、保存・再開の間隔による結果の違いを防ぐ。
- 手動加工の灯力は開始時に確保し、蓄灯容量の内側に保持する。中止時は材料と灯力を一度だけ返し、完了時に利用量へ記録する。
- 満蓄時は発灯と燃焼を止める。1秒分の余剰灯力は設備内に残し、低負荷時にも燃料を無駄に消費しない。未起動中の進行は最大2時間。時計の巻戻しや再読み込みで生産・灯力を重複させない。
- 製作完了回数、生成・利用した灯力を今後の勲章向けに記録する。過去の製作を推測して実績を付与しない。勲章画面は本変更の対象外。
- 探索中に完成した採集道具を、報酬確定前の表示と実際の資源獲得へ反映する。

既存44レシピの材料・出力・時間・使用設備・章条件・自動化可否は維持する。既存の加工に後から灯力を要求せず、1.23までの加工途中・設備・在庫・地図・戦闘・乱数を引き継ぐ。アプリ1.24.0、コンテンツv1.24-r1、ルール3、スキーマ1。itch.io更新は行わない。
