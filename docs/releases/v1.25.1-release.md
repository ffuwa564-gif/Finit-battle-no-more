# ver1.25.1 — 地図のタッチ判定

第3章の城と星印の重なりで、指が8px動くと地図のドラッグと判断され、候補選択が発生しない問題を再現した。旧試験は指の動きがないタップだけであり、この条件を検出できなかった。

指の小さな揺れを12px未満まで許容し、タッチ終了時の座標から地点を判定する。Safariで後続のclickが発生しなくても候補を開く。描画がボタンの外へ出る回転アイコンと、指先の8px範囲も判定する。後続clickとの二重処理・二重SEを防ぎ、ドラッグ・ピンチ・取消は選択せず、キーボード操作も保持する。

目標は画像に写っていた第3章の「錆銀の地下墓所」と「銀灯の守門」の重なり。実際の地点・進行データを使い、移動するネイティブtouchをChromium CDPで、clickが出ないタッチ終了と座標によるPointerEventをWebKitで検証する。実機での全入力条件を保証するものではない。

設定画面の表示を1.25.1にし、更新されたクライアントを区別できるようにした。1.25.0からのセーブ移行はバージョン情報のみを変更し、探索・会話・移動・勲章を維持する。コンテンツと戦闘ルールはv1.25-r1／3のまま。itch.ioには反映しない。
