# STILLVEIL 1.23

最初の依頼を受けるまでに長い世界紹介が続いていたため、導入を2ページ、最初の依頼を3台詞に短縮する。すぐに聖堂を探索し、帰還時に次の依頼と世界の事情を知る流れにする。

- 第1章を「依頼→探索→短い報告→次の探索」に再構成。丘、広場、個体生成の庭は最初の3探索の帰りに読む。水路・橋にも調査報告を追加し、次に向かう理由を会話で示す。
- 庭園の日常巡りと夜の場面は任意の訪問へ。事件中は帰還者を迎える支度に切り替える。元の長い会話と旧OPは記録から読み返せる。
- 最初の3探索に関わる移動は最大8秒。画面の移動予告と実際の待ち時間を一致させる。
- 1.22の読了済み会話、途中の台詞・旧OPのページ、所持品・踏破履歴・戦闘を保持して更新する。旧前提条件は既存記録の検査にのみ使い、新しい依頼の解放には使わない。

アプリ1.23.0、コンテンツv1.23-r1、ルール3、スキーマ1。戦闘の数値・資源の報酬量・工房の製作コストは維持する。itch.io向けの更新は行わない。
