# 時計庭のうさぎ姫

オリジナルの発明家の少女「ルネット」が、多数の機械仕掛けのウサギを従える常設ボスイベント。紺・生成りの実用的な服と薄紫の髪で、既存女神とは別のキャラクターとして描く。開幕台詞は「ふふふっ、おねえさんよっわー」。日本語・英語の紹介文、台詞、ギミック説明を収録。

忘却の聖堂の踏破後に初級を解放。初級・中級・上級・超級・覚醒級の5難度を順番に踏破する。覚醒級は通常版の所有も必要。初級から超級は「うさぎの歯車」を2／3／4／6個、覚醒級のみ「星時計の心臓」を1個仮取得する。報酬確定で受け取り、各踏破で祈願石1個。撤退・敗北では未確定素材を失う。

- 歯車20個で通常版のルネット（SSR、強さ2.0）。
- 心臓3個で星時計・ルネット（SSR、強さ2.4）。
- 所有は別々。同じルネットの通常版と覚醒版は同時編成不可。ガチャには混入しない。
- 仲間としては全体攻撃と障壁を使用。ビットはイベントの敵ボス専用能力。

## ビットの周期

ボス戦のラウンド3、6、9……の通常行動終了後に展開。そのラウンド中には撃たず、翌ラウンドとその次のラウンドに、各ビットが生存中の味方1人を射撃する。初級〜上級は2機、超級・覚醒級は3機。例えばラウンド3展開→4射撃→5射撃・帰還→6再展開。

対象抽選は保存済み乱数を使い、射撃ごとに1つの戦闘イベントとHPスナップショットを記録する。かばう・障壁・リーダーの被ダメージ軽減を通常のダメージ処理で適用。ボス撃破または味方全滅で停止する。新しい敵枠や敵素材は増やさない。

`DungeonDef.bossBits` に周期・機数・稼働期間・威力、`Unit.bits` に機数と展開／期限ラウンドを保存する。旧セーブでこれらは省略可能。展開／射撃／帰還には `BattleEvent.bitAction`、射撃には `bitIndex` を付ける。再生と再読み込みは保存済みイベントを表示するだけで、再抽選・再ダメージを発生させない。

画面下部に展開予告と残りターンを表示し、展開中は機械ウサギのビットを重ねる。射撃は1機ずつ光線と被ダメージを表示する。動き軽減ではビットの浮遊と光線アニメーションを停止し、機数と説明は表示する。

## 原画と表示

今回使用したプロンプト全文と生成条件は[Runwayアニメーションの見本](lunette-animation-prompt.md)に保存している。

通常版は既存原画の静止画、覚醒版「星時計・ルネット」は、元の8秒と約2秒の復帰動作をつないだ約10秒の無音ループを表示する。覚醒後の既存原画 `public/art/event-lunette-awakened.png` をRunwayで動画化した。元8秒のタスクは `8359e9fb-8015-4c91-8232-8a937424eab2`、補間のタスクは `d57d4e7d-52e7-4cd7-a54a-0b29ff7580b2`。補間の生成条件と書き出し手順は[ループ補間の記録](lunette-loop-bridge.md)を参照。4秒の試作で確認したプロンプトの時間指定だけを8秒に変更し、首の小さな傾き・瞬き・笑顔と浮遊ウサギの上下動を指示している。

全身用 `public/video/lunette-awakened-loop.mp4` は720×960・24fps、顔枠用 `public/video/lunette-awakened-portrait-loop.mp4` は320×480・18fpsのH.264 Baseline。全身版は生成動画の3:4構図を保ち、顔枠版は中央の縦長範囲を切り出す。`motionId` と共通プレイヤーを通じてイベント紹介・ホーム・詳細・戦闘へ接続する。動き軽減・通信量節約・読み込みエラー時は既存の覚醒原画を表示し、画面外・別タブ・オーバーレイ表示中の停止も共通処理に従う。通常版とビットの戦闘演出は変更しない。

以前の不採用試作とは別の新動画を使用する。ゲーム原画を試作原画へ差し替えない。公開前の視聴確認ゲートは維持する。

## 検証

`tests/clockwork-bits.test.ts` は周期、展開中の予告、射撃対象、障壁・かばう、停止条件、保存と再生、専用素材の確定・交換、同時編成制約、不正な設定とセーブの拒否を検証する。`e2e/clockwork-event.spec.ts` はイベント紹介の分離と英語、実際の展開・射撃、再読み込み、動き軽減を検証する。

`docs/reports/lunette-balance.json` は各難度20シードずつの編成シミュレーション。均衡作戦、薬5個、HP65%未満で薬を使用。initialは初期4人・リオラリーダー、midはエレイン／リオラ／セリス／ルネット・リオラリーダー、ssrはコノハナサクヤヒメ／イザナミ／アマテラス／ルネット・イザナミリーダー。実機のiPhone検証を示すものではない。
