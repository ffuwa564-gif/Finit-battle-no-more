# 女神の試練

通常探索・イベント・祈願石イベントとは別の「腕試し」タブに、SSR女神との4連戦を追加する。忘却の聖堂の初踏破で解放。

1. セレネ（月白の振袖）
2. アテナ（知恵咲く羽織）
3. イザナミ（黄泉のフリル）
4. アマテラス（黒レースの暁光）

各Waveに女神1人をボスとして配置し、既存の原画・アニメーション・スキル・状態異常耐性・効果音・ボスBGMを共通処理で使用する。各女神には開幕・半減・撃破時の専用会話を用意。能力は既存のキャラ定義にボス倍率（HP300%、攻撃120%）だけを適用する。

入場時は全回復。HPと倒れた仲間は連戦中に引き継ぎ、Waveごとの状態異常・強化・スキル待機時間は通常探索と同じルールで解除する。薬の持込は最大5個、使った分だけ消費。退出後は戦闘状態を持ち帰らず、次回も全回復で開始する。

素材は一切落ちない。撃破ゴールド、クリア時の20G、初踏破・周回の祈願石、敵撃破による仲間候補の発見も付与しない。レア敵やイベント・追憶素材は出さない。ガチャSSRの入手経路は変えない。

4勝後は「試練踏破」「勝ち抜き4/4」を表示し、「踏破を記録して戻る」で踏破済み状態を保存する。戦利品一覧や獲得確定の表示は使わない。失敗・撤退時は勝ち抜き数を示して帰還。終了後の戻り先は腕試しタブ。

`DungeonDef.kind: trial`を追加し、共通のコンテンツ検証で1Wave1体の公開済みガチャSSRボスと、報酬・特殊遭遇が設定されていないことを確認する。通常ダンジョンの「ボスは最終Waveのみ」の制約は維持する。戦闘処理では試練の撃破を報酬生成から除外し、受取処理でも試練に仮取得素材や撃破ゴールドが混入していれば拒否する。既存セーブの形式は変えない。

均衡作戦、薬5個、HP65%未満で薬使用、シード1〜10の参考シミュレーションでは、初期4人（リオラリーダー）は2/10踏破、セレネ・アテナ・イザナミ・アマテラス（アテナリーダー）は10/10踏破。初期編成にはセレネの回復を越えられずラウンド上限に達するケースがある。全編成での成功率を保証する値ではない。

単体テストで解放条件、SSR構成・ボス倍率、4連戦の順番とHP引継ぎ、全報酬・発見の抑止、再踏破、薬・撤退・回復、保存互換、不正定義と報酬混入を確認する。ブラウザでは専用タブ、準備、実際のSSR動画と戦闘表示、戦利品のない踏破画面、記録後の帰還を確認する。ブラウザでのクリアまでの進行は時間短縮用の強化済みテスト編成で行い、上記バランス確認とは分ける。
