# 神話と物語から考える、次のスキル会議

ずんだもんと四国めたんによる長尺の企画動画。ゲームの既存ストーリーと神話資料を調べ、技能・リーダー効果・記憶石を提案し、反論と修正を経て比較する。

**全て未実装の企画案**。本編へ新効果を追加する変更ではなく、次期版の実装予定を告知する動画でもない。数字は仮定であり、勝率・最適解・最終性能を保証しない。ゲーム資料は `616a0747c4118a991770226d37347f34b31e2ec6` に固定している。

## 内容

22章で24の案を扱う。行動順、回復の配分、実HPの移転、次ラウンドへの預託、有限のうさぎ隊、宣告、操作範囲の拡張、離脱と経済への影響を比較する。似た機能の案は代替比較として扱い、24種の独立システムが完成したとは数えない。

研究は日本神話、ギリシア神話、その他神話と編集、原作と現行システム、厳格な批評、映像制作を分担し、複数回の修正を行った。提案の強さだけでなく、役割速度、予約時点、守る一手、対象死亡、過剰回復、敵の未公開情報、保存・UI・周回経済の費用も確認した。批評側のゲージ循環の断定も、予約タイミングを分けて訂正している。

最初の比較試作候補はリオラ、トヨタマヒメ、エレイン。これは模型で確かめる優先順位であり、実装決定ではない。

## 配布物

動画・字幕・チャプター・サムネイル・全台本・出典・24案の一覧・批評・算術モデル・再編集用の入力を、`downloads/myth-skill-conference` ブランチに配置する。ソースコードはこのブランチの `scripts/myth-lab/`。

`Sources.md` は29の出典レコードを収録する（ゲーム内11件、外部18件。同じ資料の別箇所を含むため、29冊を読破したという意味ではない）。日本側は國學院大學の学術DBの要約。翻訳、失われた作品の梗概、近代の再話は区別した。元資料全文のHTMLは配布しない。

`Worked-Examples.json` と `research/gauge-loop-*` は机上の算術模型。実ゲームの戦闘シミュレーションやバランス検証とは異なる。HP移転の総量保存、回復予定量と実効量の差、必殺の予約時点の影響を説明する。

## 再現・再編集

Python 3.12、FFmpeg 7.1系、Noto Sans CJK、VOICEVOX Engine 0.26.0を使用。`requirements.txt` は制作時のPython依存。Linuxでの制作を想定する。制作環境は4CPU・16GB RAM。再構成はworker.pyの標準の逐次処理を使う。

1. 固定ゲーム版の `public/` を用意し、この動画の `scripts/myth-lab/` を重ねる。ゲームの既存アートと音楽が必要。
2. 配布の `Production-Inputs.zip` をリポジトリのルートへ展開する。`content.json`、最終台本・音声時刻表、研究資料、FLAC音声、小さな編集用SEが復元される。
3. `python scripts/myth-lab/bootstrap.py` で公式立ち絵を取得し、利用規約を確認する。公式PNGや単独の音楽ファイルはアーカイブに再配布しない。
4. `python scripts/myth-lab/restore_audio.py` でFLACを24kHz・16bit・mono WAVへ戻す。内容はロスレス。Speech-Manifest.jsonでFLACと復元PCMのハッシュを確認できる（WAVのヘッダーは再生成時に異なる場合がある）。
5. `python scripts/myth-lab/worker.py` で全章を作り、連続BGMの最終MP4へ連結する。`python scripts/myth-lab/finish.py` で実際の章映像の尺に合わせた字幕等を出力する。
6. `python scripts/myth-lab/thumbnail.py` と `python scripts/myth-lab/worked_examples.py`、`python scripts/myth-lab/catalog.py` で付属資料を生成する。
7. `python scripts/myth-lab/validate.py` で全編デコード・尺・映像音声形式・章数・字幕参照・予定無言間隔・音量を検証する。
8. `python scripts/myth-lab/package.py` で入力アーカイブを作る。最終MP4は単独配布する。

音声を変更する場合はローカル `http://127.0.0.1:50021` にVOICEVOXを起動し、`synth.py` を実行する。最終入力から再構成する場合は音声エンジン不要。音声はずんだもん3、四国めたん2と6。`narration.json` が古い時は退避してから再合成する。workerは入力と描画コードのハッシュが一致する完了章だけ再利用する。

制作時に使用した録画抽出元は前作の `echo.mp4`。配布入力に抽出済みSEがあるため、その絶対パスは再編集時に不要。BGMは最終連結時に一度だけ加え、章単位で途切れない。字幕は画面下に別レンダリングし、説明図と重ならない領域を確保した。
