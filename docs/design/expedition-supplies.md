# 余剰素材を周回の便利さへ戻す

## 今回の対応

1. Bランク（12討伐）に到達すれば、100手を使い切らずボスへ進める。残存雑魚の撃破報酬は発生せず、回収品はボス撃破と獲得確定まで仮取得。消費した実際の手数を記録し、100手へ書き換えない。オート再生中の要求は次の指示待ちまで待ち、確認を出す。
2. 余剰の通常モンスター素材を研磨粉へ変換。common=1、rare=5、epic=25。合成してから粉へ変える操作を必須にせず、通常素材から先に使う。
3. 研磨布・連続研磨キットで、ミニゲームを省略できる。石1個につき道具1個。選択した最大100個を一括処理し、封印済みのresultをそのままコピーする。再抽選・Tier上昇・特性の付け直しはしない。手で磨く方法は無料のまま残る。
4. 回収用の灯・探索の香を、準備画面で選んで出発時だけ消費する。灯は素材か原石の1タップを一段階増やす。香は原石の出現枠率を12ポイント上げるか、その場所で出る指定資源の抽選を優遇する。無関係な地域の資源を呼び出さない。戦闘の能力値や装備した石を変更しない。
5. T1からT5の既存の工房・灯力・自動加工へ、消耗品の製法を追加。上位工房の継続的な用途を作る。

## 素材を残す

素材ごとの共通保持数は初期30。未加入の仲間化、未完了の覚醒に必要なコストも保護できる。保護量は複数の用途の必要数を合算し、共通保持数と比べて多い方。イベント・物語の専用素材は常に変換対象外。変換前に素材別の消費量と生成量をプレビューする。

自動補充は初期OFF。選んだ場合に限り、帰還時と工房の加工・更新時に研磨粉を約200まで補充する。粉や道具へ無条件に全素材を移し替えて、別の大量在庫を作らない。rare/epicを1個単位で使う場合は目標量をわずかに超えることがある。

## 製法

|Tier|製作物|主な材料|出力|設備|
|---|---|---|---:|---|
|T1|研磨布|研磨粉3・水草繊維1|1|作業台|
|T2|連続研磨キット|研磨布3・歯車1|8|織機|
|T2|回収用の灯|研磨粉8・ガラス2・銅線1|1|圧延機|
|T3|探索の香|研磨粉30・機械油2・蓄光結晶1|1|組立台|
|T4|キットの精密製法|研磨布2・合金1・共鳴回路1・研磨粉6|24|共鳴組立設備|
|T5|灯の星工製法|ガラス4・銅線2・星回路1・研磨粉24|8|星工組立設備|
|T5|香の星工製法|機械油3・共鳴回路1・自律核1・研磨粉60|6|星工組立設備|

名前・材料・加工時間・灯力は `industry.json` が正本。全製法は通常の自動加工にも設定可能。T4/T5を要求して便利さを奪うのではなく、下位製法も残したまま1個当たりの材料効率を改善する。クラフトTier自体の最大値は5から増やしていない。

## 入口

- カバン → 素材 →「余剰素材を遠征用品にする」→ クラフトの「遠征用品」。
- クラフト → 製作図を開く →「遠征用品」。製作一覧・変換プレビューは共通InventorySectionを通し、初期状態は折りたたむ。
- 原石研磨 → 上部の「道具で研磨」。普通の原石だけを道具の数まで選ぶこともできる。処理後は道具パネルを閉じ、石の結果へ戻す。
- 連続討伐の準備 → 持ち込む遠征用品。準備を閉じても消費しない。

## 検証と評価

初期4人・同じ5シードで、100手を使い切る場合とB到達直後にボスへ進む場合を比較した。装備・基礎能力は変更せず、任意の援護・薬・必殺予約は使わない。

- 100手探索：全5シード踏破。設定上の演出とオート待ちを足した概算323〜331秒。
- Bでボスへ：全5シード踏破。32〜36手でボスへ進行。概算117〜134秒。
- 概算は実際の収録時間やユーザーの操作時間ではない。計測条件・値は `supply-loop-timing.json`、再計測は `npx tsx scripts/audit-supply-loop.ts`。

既存の全体ブラウザCIはmainの直近実行でも全シャードが失敗していた。今回の機能のChromium/WebKit実画面テスト、単体・統合テスト、ビルドは別に検証する。既存CI全体が正常になったとは扱わない。

## 厳しい再評価

固定時間の周回から「短く資源を集める／上位ランクで質を狙う」という選択へ改善した。研磨は余った素材で省力化でき、希少部材にも次の探索で消費する用途ができた。通常素材の在庫をゼロにすること自体は目的にしない。

一方、装備した石をどう比較するか、十分な装備を持った後も欲しくなる新しいビルドの種類は、別の課題として残る。新しいユニーク石を今回増やしてはいない。消耗品を追加しただけで長期継続が実証できたとは言わない。

## 最終確認

- `npm test`：118ファイル・965件成功。並列の重いブラウザ検証と同時実行した最初の試行では、既存の音声合成テスト1件が5秒の上限を超えた。音声テスト単独、続いて他の重い検証を止めた全体再実行で成功。制限値やアサーションは緩めていない。
- `npm run build`：型・コンテンツ・UI契約・英語メッセージ・ビルド成功。
- Chromium：新機能4件＋既存の連続討伐4件成功。WebKit：新機能4件成功。
- 加速・操作音の所有権のブラウザ回帰6件成功。
