# STILLVEIL 15秒CM「あの日、忘れた約束を。」

2013年前後の日本のスマートフォンRPGのテレビCMをイメージした、日本語音声入りの15秒・16:9映像。夜道でスマホを見つめる実写風の女性、意味深な台詞、キャラと戦闘の連続カット、題字、検索窓で構成する。既存作品の映像・ロゴ・声優の声は使用しない。

| 時間 | 内容 |
| --- | --- |
| 0.0–2.8秒 | 雨上がりの夜道、スマホから青い光。「あの日、忘れた約束を。」 |
| 2.8–5.1秒 | 覚醒セリス。「来てくれたんだ。」 |
| 5.1–6.6秒 | 実際の戦闘画面。「戦う。」 |
| 6.6–7.5秒 | 九尾・葛葉。「出逢いが、」 |
| 7.5–8.4秒 | アマテラス。「運命を変える。」 |
| 8.4–10.2秒 | 覚醒セリス。「約束の、その先へ。」 |
| 10.2–15.0秒 | 題字、無料ブラウザプレイ、実際のitch.io URL、検索窓。「スティルヴェイルで、検索！」 |

## 素材と生成費用

新規生成はRunway接続を使い、冒頭動画5秒を50クレジット、日本語音声4本を各1クレジット、合計54クレジット。ユーザーが承認した上限200以内。キャラ動画・ゲームプレイは既存素材を再利用する。編集スクリプトは生成・課金・外部投稿を行わない。

## 再編集

ffmpeg/ffprobe、Python 3とNumPy、Noto CJKフォントが必要。既存のトレーラー素材 `artifacts/trailer/raw/battle/{video.mp4,audio.wav}` と、上記生成結果をダウンロードした以下の素材を配置する。

```
artifacts/heisei-cm/source/opening.mp4
artifacts/heisei-cm/source/intro.mp3
artifacts/heisei-cm/source/seris.mp3
artifacts/heisei-cm/source/title.mp3
artifacts/heisei-cm/source/cta.mp3
```

```sh
python scripts/edit-heisei-cm.py --preview
npm run edit:cm
```

出力はGit管理外の `artifacts/heisei-cm/`。720p確認版と1080p完成版、H.264/yuv420p・30fps・450フレーム、AAC・48kHz・ステレオ、先頭moov付きMP4。音声の前後の無音だけを削り、長いタイトルの音声は全文が枠に収まるよう速度を調整する。声に合わせて音楽を下げ、最終ミックスを-14 LUFS・最大真ピーク-1.5 dBの設定で処理する。

納品ZIPは完成映像・サムネイル・字幕・紹介文・制作記録のみ。生の音楽ファイルや認証付きダウンロードURLは含めない。完成動画の公開はユーザーが行う。

## 音声配置の修正（v2）

FFmpeg 7.1.5でloudnormの後にadelayを使ったところ、欠落・不連続な時刻を含むフレームが出力され、WAV化した際に意図した先頭無音が消えて4本の声が冒頭で重なっていた。音声・音楽・ゲームSEの配置を48kHzステレオPCMの実サンプルで行う方法に変更した。発声区間は0.100–2.340／2.980–4.232／8.450–12.158／12.380–14.046秒。各声が時間枠内に収まり、次の声まで最低0.1秒の間隔があることをスクリプト内で確認する。

修正版のファイル名は `stillveil-heisei-cm-v2-{720p,1080p}.mp4`。映像を再描画せず音声だけ直す場合は `--audio-only`（720pは `--preview --audio-only`）を使う。追加生成・追加クレジット消費はない。
