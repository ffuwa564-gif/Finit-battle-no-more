# ホームのキャラ選択

ホーム原画の左下に「ホームのキャラ」を置きます。所持している仲間だけを候補にし、名前と異名、アニメーション／イラストの区別を表示します。動画がある仲間はフルサイズ動画を、ない仲間は原画を使います。「いつものホーム」で従来の銀髪女性と白い狼の場面へ戻せます。

選択は任意の `settings.homeCharacterId` に保存します。古いセーブは未設定のまま従来のホームを表示し、`null`も従来の場面を表します。保存形式・ゲーム版は変更しません。所持していないIDは設定コマンドとセーブ検査で拒否します。選択は編成・リーダー・通貨・ガチャ・探索状態と独立しています。バックアップにも含まれます。

候補一覧は原画だけで表示し、一覧を開いている間はホーム動画を停止します。選んだ動画は既存の共通プレイヤーを使い、動き軽減・通信量節約では原画へ、読み込み失敗時もそのキャラの原画へ戻ります。動画変更時にプレイヤーを作り直し、前のキャラの動画や再生状態が残らないようにします。

従来のホーム動画は、利用者が指定した「白い狼と一緒の銀髪女性」の原画から再制作しました。髪全体の長さ・量・輪郭を保ち、数本の束と毛先だけを小さく動かす指示にしました。実写的な一本ごとの流れや強風で大きく膨らむ表現を抑えます。視線・瞬き・表情・狼の呼吸などは小さく動かし、固定カメラ・約10秒・無音の順再生を維持します。

公開前の既存の視聴承認チェックは維持します。

現在の既定動画は`public/video/home-portrait-anime.mp4`。生成元は`/workspace/generated_videos/home-anime/home-original.mp4`、Runwayタスクは`0340ee09-e6c0-4ad5-9bb1-c54236e5a0eb`です。原画は変更せず、配信ファイル名を切り替えて旧動画のキャッシュを避けます。
