# WAVE後の痕跡と共鳴

通常探索・追憶・イベントでは、各WAVEの撃破演出が全て終わった後に3択を出す。最終WAVEも報酬確定の前に選ぶ。腕試しは固定条件の戦闘検証を維持し、この仕組みの対象外とする。

選択肢は6種の行動文から重複なしで3つ。効果、数値、レア度、成立までの不足数は提示しない。単独の選択には効果がなく、探索中の選択履歴が特定の組み合わせを満たすと共鳴する。履歴は消費せず、順不同・同じ行動の重複選択も可能。同じ共鳴は1探索につき1回だけ発動する。

選択は探索単位。帰還・失敗で終了し、次の出発時にはリセットする。選択履歴は折り畳んで確認でき、成立済みの共鳴は初めて効果名と結果を表示する。

## 初期の組み合わせ（開発用）

実装の正本は `src/domain/omens.ts`。この表をゲーム内で事前表示しない。

| 必要な痕跡 | 共鳴 | 結果 |
| --- | --- | --- |
| 鈴・糸 | 帰り路の声 | 生存者の最大HPの25%を回復。蘇生なし、最大HPまで |
| 灰・鏡 | 映らない刃 | 探索中の攻撃力+12%。各仲間の現在値から切り捨て、最低+1 |
| 扉・羽根 | 翼のある扉 | 探索中の防御力+12%。各仲間の現在値から切り捨て、最低+1 |
| 鈴・鏡・扉 | 忘れられた供物 | そのルートの最初の敵の種族のcommon素材2個を仮取得 |

攻撃・防御は次のWAVEにも引き継ぎ、次の探索へ持ち越さない。素材は既存の仮取得へ加え、報酬確定でだけ所持数へ反映する。失敗・撤退で失い、通常石・星晶石・レアキャラは追加しない。最終WAVEでも同じ規則で発動するため、回復や戦闘能力上昇の実利はその探索の残りに限られる。

## 進行と保存

- `depart`で対象の新しいBattleに省略可能な`omens`を付ける。旧セーブの探索に後付けしない。
- `advanceReplay`は撃破演出完了時に、保存済みseedからFisher–Yatesで3択を作って保存し、選択を待つ。再読込では再抽選しない。
- `chooseOmen`だけが保留中の候補を選べる。選択・共鳴・次WAVE／報酬への遷移を1回のセーブにまとめる。
- 保留中はラウンド、回復薬、演出送り、報酬確定で迂回できない。バックアップ保存は可能。
- セーブ検証は候補の3件・重複・既知ID、WAVEと履歴件数、共鳴と履歴の整合を検査する。
- 3択画面は日英・キーボード・タップ操作に対応。効果は選択前の説明やボタンのラベルに含めない。

## 確認

`tests/omens.test.ts`で決定的抽選、単独選択の無効果、組み合わせの発動、同一共鳴の重複防止、WAVEをまたぐ能力、探索終了時のリセット、仮素材の確定・喪失、旧探索の再開と不正セーブの拒否を確認する。

`e2e/omens.spec.ts`で3択停止、効果を明かさない文言、リロード後の同じ候補、キーボード選択、共鳴結果、最終WAVEから報酬確定への進行を確認する。既存の探索シミュレーションと画面テストも選択を行って進むよう更新する。
