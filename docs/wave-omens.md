# 探索中の選択肢の撤去

Wave後に出していた「廃都の痕跡」の3択、履歴、共鳴結果の表示と、新たな組み合わせ効果の発生を撤去した。通常・追憶・イベントすべて、撃破演出から次Waveまたは報酬へ直接進む。必殺技の手動予約、作戦、回復薬、章の物語、報酬の確定方法は維持する。

新しい探索では `omens` を作らない。選択コマンドと抽選・組み合わせ適用コード、専用UI/CSSも削除した。

## 以前のセーブとの互換性

`src/domain/legacy-omens.ts` は旧保存データの形とIDを検証するためだけに残す。選択待ち・選択済みのセーブとバックアップは引き続き読み込める。次の操作時に旧メタデータを取り除き、選択待ちで演出が残っていない場合は自動的に次Wave・報酬へ進める。

既に保存されたHP・能力値・仮素材・確定所持品は巻き戻さず、その探索を続行する。旧共鳴を再適用しない。新しい出発では通常の能力値から開始する。壊れた旧レコードの検証は維持し、互換対応を理由に破損データを新規データ扱いしない。

`tests/exploration-flow.test.ts` と `e2e/exploration-flow.spec.ts` で、新規Wave進行・最終報酬・旧選択待ち保存・能力と素材の保持・再読み込みを確認する。
