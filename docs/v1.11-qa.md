# STILLVEIL 1.11 — portrait framing hotfix

The 75 published characters were reviewed together through the actual `PortraitArt` component. Ione, Neri, Fio and Ruka were showing the torso or clipping the face: their 16% object-position offset was being magnified again by a 2.8x transform around a 16% vertical origin.

Their full-resolution originals remain unchanged. The four portraits now use `createFacePortrait`, which retains top alignment and centers the reviewed normalized head rectangle. Recruitment IDs and head bounds share an exhaustive TypeScript mapping, so a new scout requires a reviewed entry. `check:content` rejects missing scout head bounds, out-of-image bounds and settings that clip the registered head in any supported portrait aspect ratio (.95, 1.05, 1.08, 1.15, 1.5).

Regression coverage:

- Unit tests restore the old 16% / 2.8x crop and require content validation to reject all four portraits.
- Browser tests project the reviewed head rectangle through the actual rendered image and assert that every edge stays within the battle tile at 320, 390 and 1024 pixels.
- Existing video-error / high-resolution-poster / reduced-motion coverage is retained.
- Chromium and WebKit cover the actual battle controls and reload behavior.

Versioning is deliberately cosmetic: app/package/display version is **1.11.0 / 1.11**, while gameplay `contentVersion: v1.10-r1`, rules version 2, save schema 1, and the tower record version 1.10 remain unchanged. No tower rebalance or progress reset is included.

The launcher accepts exactly the released 1.10 save contract for this hotfix. It validates the source against the identical gameplay definitions, clones it, and changes only appVersion and revision. This preserves the entire battle/replay cursor, RNG, equipment, tower record, farming history and rewards. Save plus boot metadata are upgraded in one compare-and-swap transaction; the original 1.10 record is retained separately without overwriting the permanent 1.0 backup. Unit tests cover backup import and unknown-version rejection; a browser test exercises the real boot and retained records.

Local evidence (ignored workspace artifacts): `artifacts/v1.11/gallery-before.png`, `gallery-after.png`, `unit.log`, `build.log`, `portrait-e2e.log`, `portrait-webkit.log`.

Verification completed: 718 unit tests passed; production build passed type/content/UI/locale gates; portrait quality plus real 1.10 boot upgrade passed all 5 tests in Chromium and all 5 in WebKit. The old 1.10 version-only expectation was updated to compare the package release, while tower migration contracts remain pinned to gameplay version 1.10.
