# 白亜の塔攻略日記 Part2 改良版

Part1.1の中央資料＋左右の実況キャラという構成を参考に、可愛いピンクのサムネイルに本編も合わせた再編集。ゲーム本体の変更はない。同じ検証済み第二層実戦を使用する。

## 編集

- 共通OP v4の23秒を先頭に維持。直後に40R時間切れのダイジェストを置き、「守りが厚いのに倒し切れない」を今回の問いにする。
- 重複する説明を整理。3人の掛け合い11行を新録し、素材が2個足りない小ネタ、ワンオペから役割分担への編成会議、うさぎの統率の小ネタを追加。
- ちびキャラの表情6種と、作戦会議／長いレシートのお買い物の挿絵2種を新作。生成のプロンプトとピクセルを制作ZIPへ保存。
- 敵の役割、かばうと全体攻撃、攻撃役1人／2人、素材カウンター、通常スキルCD、実戦の敵HPグラフを図解。HPは保存されたネイティブ戦闘結果から描画。
- 実戦中は左に486×864のゲーム画面、右にその場の要点。映像が終わった後は大きな図に切り替え、止まったゲーム画面を説明中ずっと残さない。
- 各イラストはcontainで配置。耳・帽子・髪を含む頭の余白を確保し、話者と表情の一致・字幕最大2行も検査。
- 必殺技と妖精は再掲を明記。実戦・SEは同じカットで速度変更し、着弾の反応は実際の白フラッシュから合わせる。

## 再現・検証

`scripts/diary-part2-v2/README.txt`を参照。制作ZIPのナレーションFLAC・新作イラストと、ピン留めされた元録画ZIP・共通OPから再構成できる。ゲーム画像・BGMは上記ゲームコミットのものを使う。再度TTSを生成する場合のみVOICEVOX0.26.0が必要。

中間カットは30fps・48kHz PCM、一フレーム1600サンプル。入力・編集条件・コードのハッシュ一致でキャッシュを再利用。OPを含む全音源を共通サンプル0へ一度に配置し、ゲーム音を会話中だけダッキング、可逆FLACから配布MP4で一度だけAAC変換する。

`audit.py`は配布ファイルの変化している実ゲームフレームと実SEを開始・中間・終了に分散して照合。全3話者と必殺リアクションも確認し、80ms超・相関不足・検査点不足なら停止する。`validate.mjs`は全体デコードとChromium/WebKit再生・シークを別検査する。頭の安全域と字幕・話者の回帰検査は`visual_qc.py`。`package.py`は全検査が同一完成SHAに合格した場合のみ実行可能。

## 完成版の検査結果

19分19.533秒、1920×1080、30fps、48kHz。完成SHA256: `7e100076b74c510752c40209c343cbb9f2172f62dc3628c2269ac91d1b9aba1e`。

実戦の映像・SEは18点、OPは3点、全3話者は9点、必殺反応は2点で合格。実戦SEの最大ズレ0.0ms、映像の最大ズレ0.0ms。似たフレームの静止区間を誤認しないよう9枚連続で照合する。必殺着弾の反応差0.0ms、妖精の登場反応差6.0ms。音の背景は元音源から独立に再構成し、完成ミックスから対象を引いて見かけの音源を作らない。

全体デコードとChromium/WebKit各3点の再生・シーク、見切れ・字幕・話者の377検査が合格。共通音声同期の回帰試験6件も合格。合成を疎なPNG入力から30fpsの連続入力へ変え、109秒の実戦パートを最大約687MiBの子プロセスRSSで完走した。
