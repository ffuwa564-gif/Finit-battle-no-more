## 制作と検証

制作コードは `scripts/diary-part2/`。実戦は `applyCommand` を用い、9戦の入力を再実行して保存結果一致を確認する。各行動の選択は毎回ネイティブ状態から考え直す。複数waveの宝箱処理はアプリ側で乱数を進めるため、ドメイン戦闘だけで全waveの未来を固定しない。

録画は450×800のゲームを別フレームに保持し、外側の24pxへ診断映像を出す。開始・途中・終了の16kHz音と映像で時計を測定し、最初のウォームアップパルスを除いた6点以上で検査する。元音の診断帯域を除去してから48kHzの区分時計補正を行い、診断帯のない30fps / PCM MOVへ書き出す。

編集は映像フレームと48kHzの1600サンプルを単位にAV同時処理。キャッシュは入力・編集条件・処理コードのハッシュで判断。最終ミックスは共通サンプル0に一度だけ配置し、AACは完成動画で一度だけ使う。

ルネットの最後の一撃への反応は、録画元の実際の白フラッシュを測定して配置する。配布する完成MP4で、序盤・中盤・終盤など16点以上の実フレーム／実SE、全3話者の開始・途中・終盤の音声を元データへ照合する。80ms超・相関不足・点数不足なら配布を止める。全体デコード、Chromium/WebKit再生・シークは別に確認する。

## 再制作

配布先READMEの手順で2つのZIPをリポジトリルートへ展開する。`bootstrap.py` は公式立ち絵の取得と可逆音声・映像の復元を担当。VOICEVOX 0.26.0をlocalhost:50021へ起動し、FFmpeg、numpy、Pillow、scipy、既存Node依存を用意する。権利元の規約リンクと音源表記は配布先Credits.mdを参照。キャラクター立ち絵や楽曲の単体再配布は含めない。

```sh
python scripts/diary-part2/bootstrap.py
python scripts/diary-part2/render.py
python scripts/diary-part2/audit.py
# 再生検証用Viteを別プロセスでport4328へ起動
node scripts/diary-part2/validate.mjs
python scripts/diary-part2/finish.py
```

## 共通OP v4とサムネイル

ユーザー指定により、[`017a0cc` の共通OP v4](https://github.com/ffuwa564-gif/Finit-battle-no-more/blob/017a0ccca241d1ec6a72b8a73f63188fc1043875/STILLVEIL-TowerDiary-Opening-v4-1080p.mp4)を冒頭23秒に全編収録。24fpsの元尺とOP専用音楽・タイトルコールを保って30fpsへ統一する。サムネイルはOPの濃紺・星空・軌道線・塔のシルエット・金／アイボリーの明朝文字へ合わせ、Part2とつむぎ参戦を表示する。

`audit.py` は本編の書き出し後に `prepend_op.py` を実行し、本編のPCMとOP音源を連結して完成MP4へ一度だけAACエンコードする。本編の一時AACは音源として再利用しない。全チャプター・ナレーション・実戦照合点も23秒移動し、OPの開始・途中・終了を完成ファイルで照合する。OP BGMは「Twinkle Soda / FUJINEQo」。配布Credits.mdと動画説明文へ元OP指定の表記とリンクを追加。

## 完成物の確認結果

- 共通OP23秒を含む23分48秒、1920×1080、30fps、48kHz。
- 実戦16点、OP3点、3話者の開始・途中・終盤9点、必殺反応2点を配布MP4へ照合して合格。実戦フレームの最大差33.34ms、実効果音の差0ms。最後の一撃の反応も実フラッシュへ一致。
- 効果音が重なる短い反応は、共通サンプル時計の他音源を引いて照合し、未分離の相関も報告する。閾値や時刻の許容幅は緩めない。
- 全体映像・音声のデコード合格。Chromium/WebKitとも3か所へシークし、実フレームの描画と時刻の進行を確認。ヘッドレスのブラウザ再生はミュートし、音声は完成ファイルの波形照合と全体デコードで別に検査。
