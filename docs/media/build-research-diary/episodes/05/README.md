## 認定の範囲

これは未配信で意図して設計した、容量を守る12Rの研究用護衛。CAREはbaseエレインだけの個人技で、失った最大HP容量を戻すが現在HPを増やさない。cleanse14を置換しheal14は維持する。覚醒エレインBD037へ能力・名前・検証済みを自動伝播しない。

必要性は「他の100試行が負けたから」ではない。現在catalogの能力/最大HP書込みを閉じ、最善の防御・かばう・休息や無制限の通常HP回復を許しても、容量は毎段階少なくとも元Hの1/10を失う。12×ceil(H/10)>Hなので、容量を増やせない攻略は12段階の護衛を完了できない。現在の宣言範囲でその正の容量復元を持つのがbaseエレインのみ、という条件付き証明。

実nativeの成功例と100固定seedの100勝で十分性を確認した。相方・石・タイミングの一意性や普遍的100%勝率は主張しない。別相方、旧フィオ、補助手段なしの成功例も保存する。別の容量復元能力や早期終了条件を追加した場合は再審する。

入れ替えの代償もある。別の既存状態異常戦では元cleanse構成100勝に対しCARE構成97勝、平均同士討ち50.2→86.51だった。万能な上位互換ではなく、能力枠の選択として扱う。
