# 図を中心に、視聴の負荷を下げる制作方針

2026-11-03のユーザー指示「視聴の負荷が高すぎるので、なるべく図を多用」を、Part5以降の標準とする。

## 基本

**説明を聞きながら長文や別の数字表まで読ませない。図だけでも因果の大筋を追え、声は問い・選択・発見を添える。** 図を増やすことは、一画面に情報を増やすことではない。

- 一場面一つの問い。短い見出しと、主役の人物・対象・変化だけを見せる。
- 同じ対象を同じ位置・色・アイコンで保ち、「前の状態 → 何を選ぶ → 後の状態」を順番に表示する。いきなり完成した複雑な図を出さない。
- 数字は判断に必要な2〜3個を優先。バー、残量、差分の色で先に意味を示し、細かな式や全比較表は資料へ。
- 音声と字幕は短く区切る。図を見せる瞬間には短い間を置けるが、意味のない停止画面や長い無言を作らない。
- 戦闘は、説明している一手と実際の場面を合わせる。回復・攻撃・追加効果・手番の増加を、同じ矢印で混同しない。
- まず一つの具体例を見せ、その後に必要最小限の比較。専門用語や統計の定義を先に大量に並べない。
- 長文の脚注、条件表、証明の全文を常時表示しない。研究用/現行版、比較の違いは短く明示し、詳細は同梱資料から確認できるようにする。

## Part5の目安

本文は55〜65台詞、全体8〜11分を目標に、必要な内容から決める。尺のために説明を足さない。既存指定の全少女紹介45〜60秒、シリーズOP、立ち絵付き次回予告は維持する。

例：「HPの器が縮む」→小さくなる容量バー。「普通の回復では元の大きさへ戻らない」→同じ器に水を足す。「エレインが器を戻す」→容量だけ広がる。「仲間がHPを回復」→別の色で満たす。この四つを一枚に詰め込まず、声と順番を揃える。

## 琥珀の試作認定

琥珀色を目指して研究を続けるが、見せ方のために認定を先付けしない。必要性・勝利例・合法な代替の検証・旧役割の再審・独立レビューを揃える。専用の接待試練なら、現行ゲームの難所を発見したように言わず「新しい役割を試す研究用護衛」と示す。

動画では、なぜ他の方法が届かないかを一つの図と短い説明に絞り、数学的な範囲・全候補・反例・検査ログは資料へ保存する。説明を短くしても証拠は省略しない。

## 完成動画での確認

図と話が別の情報を同時に要求していないか、数値や文字を読み切れるか、字幕・人物・図の重なりがないかを完成MP4で確認する。原画の頭・耳・髪飾りはcontainで残す。従来の同期、全員表示、ブラウザ再生、完成SHAと公開後の読み戻し検査は継続する。
