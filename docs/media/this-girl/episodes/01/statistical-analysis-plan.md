# 確認解析の凍結仕様

状態: 確認結果を開く前の仕様。対象はこの研究の有限な合法探索・凍結ビルド・既存戦場であり、全合法方策の大域最適や永久的な非支配の証明ではない。

## データと比較

12条件 = 既存2戦場 × 固定3人コア2組 × T3/T4/T6。
各条件で C と A/B/D_fast/D_safe/D_frugal/E の6比較を行う。EはCと同じ編成・石・方針・90%障壁・印/CD/行動費用を維持し、payoutだけを0にする。

1行はseed/logical ID、applicationSeed、departureSeed、勝敗、実rounds、failure-capped rounds、薬消費、残存人数、花/妖精、発令と実対象変更、印の実捕捉/消費/実追加damage、およびsource/build参照を含む。全比較は同じ256行IDを対応づける。失敗を削除しない。全員生還は「勝利かつ4人生存」とする。隣接LCGの開発パネルを確認勝率として転記しない。

## 一次のP値族

72比較×4 endpoint = 288仮説を一つのHolm族に固定する。プロフィールが重複しても黙って削除しない。計算結果の再利用と仮説数は別である。

- win差: discordant pairの厳密McNemar（二側）。
- 全員生還差: 上と同じ厳密McNemar（二側）。
- failure-capped rounds: 全seedでCが少ない/多い回数を数え、同数を除いた厳密sign test（二側）。
- 薬: 全seedでCが少ない/多い回数を数える同じ厳密sign test。

sign testは「少なく済むseedと、多くなるseedの頻度の差」の検定であり、平均差の検定ではない。Wilcoxonを参考で出す場合も対称性等の仮定と補助扱いを明記し、平均改善の証拠へ読み替えない。

## 信頼区間族

1比較につき、win差・全員生還差・round改善頻度差・round平均差・薬改善頻度差・薬平均差の6区間を作る。

主要72比較=432区間、Cの絶対勝率12区間、同一T6ビルドをT3/T4へ落とす3組のTier対比×4条件=12比較の72区間で、合計516区間を一つのBonferroni族とする。各区間の失敗確率δ=0.05/516。C-A非劣性は既存のwin差区間を再使用し、二重計数しない。

win/全員生還/改善頻度差は、discordance率qと、その中でbetterになる条件付き確率πへ分解する。K=better+worse ~ Binomial(n,q)、better|K ~ Binomial(K,π)、差はΔ=q(2π−1)。qとπへそれぞれClopper–Pearson区間を失敗確率δ/2で与え、長方形の四隅の積の最小/最大を差の区間とする。K=0ではπを[0,1]とし、qの上限は正なので全一致でも差の区間幅を0にしない。直接2セルを別々に囲む方法より、discordanceの方向の情報を使える。

平均差は観測平均をそのまま示す。母平均の方向を保証するには、真の有界範囲を使った二側empirical-Bernsteinの保守的区間を使う。round差は[-wave数×40,+wave数×40]、薬差は[-5,+5]。区間が広く0を含めば未確立。参考bootstrapの狭い区間でこれを置き換えない。

## 認定への使い方

「有意な方向」はHolm q<0.05と対応する同時区間が同じ方向を支持した範囲だけとする。平均改善は平均差区間が0を跨がない場合に限る。そうでなければ「この256試行での観測平均」と「改善/悪化した試行頻度」を分けて述べる。

実用性はC勝率の同時CP下限≥0.75、およびC-A差の同時下限≥−0.05を確認し、点推定で達成した状態と不確実性の残る状態を区別する。少なくとも異なる2カテゴリ、異なる2コアで調べる。Cが勝っただけで固有能力・唯一性を認定しない。

採用価値はD_fastだけでなく、安全/節約側へ公平に最適化した代替にも対抗する。確認したプロフィールに対する選ぶ理由であり、全合法方策への厳密非支配ではない。固有因果寄与はC/E、育成価値は同一ビルドのTier対照と各Tier再最適化を区別する。観測したトレードオフを単一の都合よい重みへ合算しない。

T3/T4の主コアにも現在入手不可のXRが含まれるなら「仮想全所持での装備帯比較」と明記し、今すぐ組める入口とは呼ばない。現在入手可能な入口は別測定、未測定なら未確立。

stress/Noel/hidden/石factorialは別の事前固定された補助探索として記録し、主要族の合格不足を事後的に埋めない。固定ビルドの+25/+50stressはビルド頑健性であり、将来の再最適化されたキャラ採用価値の保証ではない。差の差には0%も同じ950パネルで測る。

全75への同一ビルド性能の維持は、その子の相対的採用価値の維持の証明ではない。screen/unverified/反例発見を区別する。重要な条件が未達・未測定なら総合宝石は研究中。個別の検証済み事項は範囲を添える。

## モデル仮定と限界

固定SHA-256 seedパネルを、ほぼ一様な独立seedのMonte Carlo近似として扱うモデルに基づく。不確実性区間はその仮定の下の推論であり、固定パネル自体の数え上げは正確でも全2^32 seedや未知のプレイヤー方針を保証しない。共通seedでも行動変更後の乱数消費は分岐し得る。同じ装備予算・アイテム予算、同family禁止、全所持という仮定、公開/研究実装/未実装案を区別する。

確認を開始する前に、この仕様、解析コード、能力/方針/石/比較群、全seed対応表のSHAをlockへ結びつける。未知結果で仮説数・閾値・対象を変更しない。

## 区間のcoverageの根拠（確認前の方法改訂）

独立seedモデルで各paired結果をbetter/worse/tieの三分類とすると、Kは二項、Kを与えたbetterは条件付き二項である。qのCP区間の非被覆確率はδ/2以下。πのCP区間は各K>0で条件付き非被覆確率δ/2以下なので、Kを平均した非被覆確率もδ/2以下。K=0ではπの全範囲を使う。したがってunion boundで両区間が同時に真値を含む確率は1−δ以上。独立な区間推定である必要はない。真のΔは長方形内でq(2π−1)の値を取り、双線形関数の極値は四隅にあるため、得られる差区間もcoverageが1−δ以上。さらに516区間へのunion boundで全同時coverageが95%以上となる（記載したseedモデル仮定の下）。

この改訂は新しい確認戦闘を一つも実行する前に固定した。仮説数、seed、効果しきい値は変更しない。都合のよいゲーム結果を見て検定方法を選び直したものではない。小標本の多項分布の全列挙でモデル検査も行うが、それはゲーム実戦データではなく、coverageの数理的根拠の代わりではない。
