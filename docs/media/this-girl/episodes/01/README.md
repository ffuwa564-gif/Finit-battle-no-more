## 動画・制作物

[動画・サムネイル・字幕・台本・再現パッケージの配布先](https://github.com/ffuwa564-gif/Finit-battle-no-more/tree/downloads/this-girl-01)

## 研究結果

**総合判定は「研究中」です。** 障壁で実際に守った力を次の主攻撃へ渡す「桜の返礼」を研究版へ実装しました。一部条件で攻撃への寄与を確認できましたが、最終盤での固有の採用理由や、ほかの少女の出番を維持できるかという命題全体の達成は認定していません。

- [実測比較](reports/combat-results.md)：確認前に固定した12条件、各256共通シード。
- [研究範囲と限界](reports/methodology-scope.md)：有限の編成・装備・操作探索です。大域最適解の証明ではありません。
- [正式な研究判定](reports/character-judgment.json)：個別に確認できた事項と、総合の未達・未検証を区別しています。
- [設計の採用・見送り](reports/design-decisions.md)、[全キャラへの影響](reports/roster-audit.md)、[石の育成目標と入手先](reports/stone-goals.md)。
- [元の実測データ](evidence/) と [確認前の固定仕様](confirmation-lock.json)。

実戦映像は共通の既存ステージを同じ乱数・同等予算で遊んだ抜粋です。1戦を勝率の証明として扱いません。SSR/XRを含む全所持の仮想最終盤を検証し、現在は入手できないキャラクターも含めています。
