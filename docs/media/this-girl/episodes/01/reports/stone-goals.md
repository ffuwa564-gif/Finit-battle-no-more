# 石の育成目標と実入手先

以下は実装定義と最終C編成での採用石から生成。T3/T4/T6は同じT6テンプレートのdownroll比較も行った。高Tierが必ず勝率や効率を改善するとは限らない。

T3最大power100=2.5倍、T4最大139=3.085倍、T6最大239=4.585倍は石のスキル倍率。恒久的なキャラ能力値倍率ではない。庇護は石使用後の一時障壁、慈雨は実HPダメージからの回復。

|石|Cでの装備枠数(12case合計)|選抜構成の特性|T6を狙える塔の先頭候補|
|---|---:|---|---|
|残響石|48|庇護 / 慈雨|白亜の塔・第41層 (ivory-tower-041)|

各石の全入手候補、注目石、正確なTier昇格率は `implementation-facts.json` のroutes/profileを参照。profileのTier率は最終Waveで石を得た後の各既存roll属性に対する条件付き率。特定石・異形・特性・両roll最大を含む完成品の排出率や必要周回数ではない。ここから必要周回数を捏造しない。固定roll石はTier6へ昇格しない。

研究版の固有技能は未公開仕様。石自体が公開ゲームに存在することと、この研究技能を今すぐ利用できることを混同しない。T4/T6は次の育成候補であり、全特性の固有相乗効果を因子実験で認定したものではない。
