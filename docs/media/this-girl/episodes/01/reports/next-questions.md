# 未達の理由と次に調べること

## 今回確認できた事実

- T6・塔F1の固定Cは256行すべて勝利した。追加変換を無効化したEとの比較では、固有技能の寄与を調べる根拠が得られた。認定できるendpointと範囲はcritic最終judgmentを参照する。
- 同じF1でも、最良既知代替ヒーラーの方が薬を大幅に節約した。速さ・薬・生還の取捨選択を残すため、勝率だけで採用価値を認定しない。
- T6・塔F4は−5pt非劣性が未確立。観測上はDfastが、今回の速さ重視の固定Cに対し勝率・round・薬・全員生還の4指標で良かった。これは全サクヤ構成の支配証明ではない。
- 葛葉F4では、CとEの結果指標が同じ条件があった。敵を倒せることと、返礼が働いたことは分けて報告する。
- 高レア能力+50%では返礼のC/E差が小さくなる条件がある。凍結buildの摂動結果であり、将来の再最適化後の採用価値は未検証。
- 号令の条件付き使用も、無条件使用も常に利益になる結果ではなかった。指揮官の一手と、元から同じ敵を狙っていた行動の費用を残す必要がある。

## 次の仮説（未実装・未認定）

1. **サクヤの安全・節約方針を別に確認する。** 今回のCは速さで選抜した1案。開発で得たsafe/frugal候補や別の方針を、事前固定した新しい確認パネルで比較する。今回の930パネルを見て選んだ案を、同じ930パネルで新規認定しない。
2. **LSの機会費用を含めて守りと回復をつなぐ。** 既存の再生や別リーダーを失う費用を払ったうえで、花びらの消費を回復へつなぐ選択式LSなどを新候補として研究できる。今回実装した能力ではなく、他の癒し手の役割を奪うかも再監査する。
3. **石の特性を因子実験する。** 選抜された庇護/慈雨の構成だけから固有相乗を認定しない。石の行動・枠・Tier予算を維持し、有無を分けた実験が必要。
4. **指揮の対象変更に実益が生じる局面を調べる。** 発令数を増やすことを目標にせず、敵の行動を防げたか、支払った1手を回収したかを共通既存戦場で測る。回復や障壁の操作を号令へすり替えない。
5. **75姿の不足を埋める。** 固定coreとfamilyが重なって未測定になった姿、確認不足の旧戦術、全75置換や将来条件の再最適化は次の課題として残す。専用の接待ステージは追加しない。

この候補の確認結果に合わせて閾値や数値を動かして合格にしない。次の能力候補を試す場合は、設計・予算・比較・seed・認定規則を改めて事前登録する。今回は **研究中** のまま、機構の部分的な成果と未解決点の両方を研究日誌へ残す。
