# 必須研究資料と今回実施した範囲

外側の辞書式目的 `(N_obsolete, N_dominated, D_dependency, -N_viable_builds, -C_synergy)` は設計を評価する優先順位である。今回は固定した1つの研究候補θ（500%変換、100%上限、90%障壁、付与round+2期限）に対し、有限の編成・石・リーダー・先頭・操作方針の内側探索と対照実験を行う。全θ・全75姿・全合法行動を通じた外側lex大域最適解を求めたものではない。

## 認定

個別の観測平均、同時区間、主familyの補正済み検定、機構の録画例を区別する。主要4つのT6条件と全T3/T4条件を残し、良い条件だけで総合合格に変換しない。

全75の相対価値保存や将来の再最適化を証明できないため、「みんなが輝くRPG」は今回で達成済みとはしない。コノハナサクヤヒメの総合宝石は原則 **研究中**。対応する条件・endpointで本当に成立した範囲だけを部分的な検証結果として報告する。未検証と不合格・不要を混同しない。
