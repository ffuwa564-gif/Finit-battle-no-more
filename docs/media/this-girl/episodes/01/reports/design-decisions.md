# 4要素の設計判断（確認データを開く前の固定）

状態：研究版候補の記録。能力の存在、設計仮説、実戦上の有効性を分ける。本書だけで検証済み認定を与えない。公開1.11へ研究能力を配信したという意味ではない。

|要素|判断|理由と未確立の点|
|---|---|---|
|固有技能「桜の返礼」|研究版に採用、数値固定|既存の有償通常障壁行動を使い、90%の障壁・印は付与round+2まで（R1ならR3まで）・実際の敵主攻撃の吸収からHP割合×5を最大100%まで貯め、次の主攻撃の最初の相手への実HPダメージへ一度だけ加算する。追撃からの蓄積、追撃再帰、追加ゲージ・石特性の再発動はない。無限火力ではなく、守りが実際に働いて初めて攻撃へ転換できるかを測る。確認結果で数値を調整しない。|
|新LS「花宴の循環」|今回は見送り|技能・LS・石を一括で強化すると勝因を分離できない。現行のHPリーダー補正と毎ラウンドの3%再生を維持し、アテナ等の別LSと入れ替える機会費用を含めて探索する。サクヤLSとノエル号令は同時利用できない。新LSの存在や性能を動画で既成事実にしない。|
|新記憶石|今回は追加しない|既存13種類、特性・異形、先頭・リーダー・合法操作から有限探索する。白灯石と庇護を明示候補に含め、慈雨一辺倒の探索を避ける。白灯石自身から返礼の印は発生しない。サクヤ固有行動の印が成立した場合の障壁供給と、それに支払う1行動・装備枠を区別する。T3/T4/T6の実測前に高Tierの改善を約束しない。|
|新指揮能力|今回は改修せず|ノエルの号令は指揮官の一手を使い、追従可能な通常攻撃の選択対象を変える既存機能。回復や障壁を直接操作する効果ではない。F5の同一号令編成で禁止・条件付き・可能時使用を比較し、別途サクヤリーダー案と比較する。発令数、選択対象の実変更、純利益を混同しない。|

E対照では `payoutPercent=0` のみを変更する。障壁90%、AI、CD、印付与・吸収・消費、行動費用は残す。CとEの差は、この固定方針で追加ダメージ変換を有効にする総効果であり、全方針にわたる唯一性や新LSの効果を証明しない。

仮ビルド名は **「花守の返礼」**。戦術の説明名であり、検証済み宝石を先に与えるものではない。主比較F1/F4は現在入手不可のXRアストライアを含む全所持の仮想最終盤。実際の入手可能な入口の実証とは区別する。
