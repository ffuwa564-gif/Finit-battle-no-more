# この子で、勝ちたい。 #02 — ミエット

主役：SRミエット。静かなリケジョつむぎの研究独白。前回承認された停止・枠囲み・拡大・つむぎの説明を継承する。オープニングなし。6〜9分を目安に必要な長さから決める。

問い：障壁をHPへ編み直す「修繕」の一手は、全所持・高Tier石でも採用理由になるか。現状を弱いと先に決めず、実装済みの技能を測る。能力追加は問題の確認後に採否を判断し、未実装案を映像へ混ぜない。

## 研究方針

既存共通ステージを使用。専用接待・レア制限・キャラIDによる敵の弱体化は禁止。最良既知候補と差替え候補の両方で同じ探索予算を使い、リーダー・石・操作を探索する。開発seed・選抜seed・確認seedを分け、確認256seedの前に候補・ステージ・評価方法を固定する。探索後に条件を選び直して成功としない。

評価は勝率、失敗cap込みラウンド、薬、4人生還、障壁の消費と実回復。T3/T4/T6、複数の3人コア、異なる既存戦場を比較。真の全体最適・普遍的上位互換・全キャラ監査の完了は主張しない。必要な未検証が残る場合、認定は研究中。

スキル・リーダー・石・指揮の4要素を、機会費用と行動連鎖で説明。勝率だけで成功としない。映像は新しい実アプリ収録から作る。比較セーブの全所持仮定、現在入手不可XR、公開能力か研究能力かを区別する。

完成MP4の映像/実SE/声を元へ照合、80ms以内、相関不足・必要点不足では公開しない。停止画像は録画frameとsourceSHAへ束縛し、停止中にゲーム音を流さない。原曲・生の合成音声・モデルの単体配布はしない。
