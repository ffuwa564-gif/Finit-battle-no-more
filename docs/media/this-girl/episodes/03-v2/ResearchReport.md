# ティッカ研究03・改訂版 — その一拍で、仲間を守る。

## 実装した改善

Rティッカの封印技能を「秒針の余白」へ改修。敵の通常技能の待ち時間が実際に延びたときだけ、次の通常攻撃一回の威力を50%軽減する有限マーク。次ラウンド終了まで。障壁より前のダメージ計算へ作用し、吸収されても一回を消費。技能・必殺・ボス大技・ビット・状態異常による強制攻撃は対象外。通常一行動と従来の再使用4R、既存の本人25+故障診断8は維持。無限更新/重複なし、戦闘不能/新waveで消去。新しい乱数/追加行動なし。

## 失敗からの再設計

充填20の初期試走、弱体+充填の最初の512確認、充填15のみの次の512確認、石の手番を守る保留方針を全て記録。充填は石と必殺の手番を交換させ、採用基準未達。失敗を改善の実績と混ぜない。両方の開封済み確認パネルは開発データ扱い。新しいheldout:v3をGitへ凍結してから確認した。

## 実戦の一例

ivory-tower-010-T6-F1。同じ出発seed。C19R、B17R、薬C5/B4、生還C3/B4。事前の優先条件と昇順入力で選択。実際のマーク付与と消費を本物のゲームで収録。一戦は勝率の証明ではない。

## 4要素の採用・見送り

- 固有技能：実封印→次の通常攻撃の緩衝を採用。ゲージリレー/防御低下/保留は不採用。
- LS：既存の薄明の追撃（敵HP35%以下へ20%増）を維持。構成ごとにティッカと固定コアの候補リーダーを同予算で比較。
- 石：新石は追加せず既存の合法4枠。T3/T4/T6は4石全体の比較で、特定石一個の効果ではない。緩衝50%自体は石のTierで増えない。
- 指揮：今回は変更しない。ノエルLSと併用できない機会費用を無視せず、全指揮最適化は未検証とする。

## 回帰と全体監査

763ユニット（新機構13を含む）、型/content/UI/locales/build、ChromiumとWebKit実アプリ、公開版旧03実測72戦の完全一致、セーブ検証と乱数再現を確認。ブラウザ用fixtureは研究実績や本収録には使わない。

他キャラの基礎能力/LS/石/共通ステージは変更なし。typedな汎用契約で有効化し、敵ID/ステージIDによる専用接待分岐なし。全キャラ再最適化、真の上位互換の解消、最終盤の恒久的価値は未検証。認定宝石を増やさず、今回の限定改修採用と全体認定を分ける。
