## 改修

有効な他者の盾を直接削る案は不採用。失効した障壁だけを、各本人の最大HPまでの修繕糸として3ラウンド保存。同じ障壁は一度だけ。糸を先に使い、不足分は対象本人の有効盾だけを消費。1行動/CD3・対象HP75%以下・総消費上限15%HP、基礎倍率3倍。宝石色の20%補正は別。普通の回復が2倍以上戻せる少量変換を自動で避ける。新LS/新石/指揮強化は足さない。

## 4要素の判断

- 固有技能：失効障壁→有限糸→有償回復を研究版へ実装し、上記範囲で採用。
- LS：既存の月の慈愛（HP補正と3%再生）を維持。新LSは技能との寄与分離のため見送り。主比較は同じLS。
- 石：主映像はアテナにT6白灯石、他3人にT6残響石。石の期限切れ残量が糸へつながる。G3/G4で操作を固定した育成帯比較を実施。
- 指揮：ノエルへの変更はリーダー枠と1人枠の費用がある。本回の全面指揮最適化は未実施。直接回復や障壁を号令で操作できるとは言わない。
