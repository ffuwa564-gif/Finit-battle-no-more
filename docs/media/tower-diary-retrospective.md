# 白亜の塔攻略日記・Part2までの反省会

承認済みのピンク版動画テンプレートを使い、ずんだもん・四国めたん・春日部つむぎで、ユーザーの4つの指摘を振り返る。約13分54秒、共通OP v4の23秒を先頭に使用。

## 内容

- **ビルドを作りたくならない**：核になる連携が動く瞬間と、最初の素材・途中の装備が見えにくかった。完成した比較用装備の説明と、育てる楽しさを分ける。ゲーム側の共通の守り役への偏りと、動画側の見せ方を別々に検証する。
- **難しさが分からない**：T4中心・固定操作・別乱数100通りの61勝／76勝はプレイヤー全体の勝率ではない。第二層40R失敗と25R成功は複数の条件が変わった記録。入口の映像だけで100層全体を評価しない。
- **遊んでいる感じが薄い**：実ゲームの正規操作でも、成功手順を先に固めた検証実況は迷いを見せにくい。次回は一ラウンドの意図・入力・結果・次の判断を残す。長い素材集めは準備編へ分ける案を議論し、攻略編単体でも楽しめる形を提案する。
- **途中のコーナー**：20秒の「ルネット必殺図鑑」を実際に挿入。着弾へのつむぎの反応を実フラッシュから配置。後半に「そのビルド、どこから作る？」も入れ、歯車20・心臓3・時計素材6の記録を見せる。

## 既存仕様と提案の区別

`src/domain/boss-pressure.ts`・`engine.ts`と収録時点のcontentを確認。一部の敵には予告大技と、溜め中にHPを削ると大技が弱まる仕組みが既にある。防御も既存の操作。これらを未実装として提案し直さず、今ある戦略を見せられていない点と、敵の役割や対応の幅を今後調整する案を分けた。

今回の素材はPart1.1.1とPart2の実戦の再掲。新しい初見プレイ、提案の実装、新しいバランス実験をした動画ではない。100乱数や回復量などの数値は既存の検証記録を引用する。視聴維持率の実データも持っていないので、改善の効果を実測済みとは言わない。

## 再編集と検査

`scripts/diary-retrospective/README.txt`を参照。制作ZIPにナレーションFLAC・図解・画像・5つのAV同期済みカット・企画メモ・絵コンテを同梱。OPは固定の公開素材を取得し、BGMは公式配布元から取得する。`render.py --use-approved-cuts`はカットのSHAと編集条件が一致した場合だけ再利用する。

編集用は30fps・48kHz PCM。背景と透過キャラを30fpsの連続入力へ展開後に合成。OP・本編BGM・実SE・ナレーションを共通サンプル0へ一度に配置し、可逆FLACから配布MP4で一度だけAAC変換する。

配布版の実映像は9枚連続フレームで照合。実SE・全3話者・BGMの開始中間終了、着弾の反応も元音源と比較し、80ms超・相関不足・検査点不足なら公開停止。背景音は元音源から独立に再構成。全体デコード、Chromium/WebKitの再生・シーク、頭の安全域・字幕・話者を別に確認する。検査後に再書き出しすれば再検査する。
