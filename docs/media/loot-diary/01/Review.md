# 制作レビュー

- 今回は公開版で遊ぶ日記。新能力の研究・全キャラの実用性認定は対象外。
- 長期目標は最深部攻略、短期目標はT7用素材。負けてから掘り、更新し、また負ける過程を隠さない。
- 検索結果は編集の参考に限定。特定の投稿者の映像を実視聴して分析したとは主張しない。
- 「今日の惜しい石」は未研磨品を当たりと断定しない小休憩。現状では中身を見せる盛り上がりは弱い。次回は合法に研磨・比較まで進めると改善できる。
- 4分48秒で三戦と九周を省略するため、プレイの連続性は弱い。次の試作では一戦を長く見せ、操作の迷いと予告への対応を音声に合わせる余地がある。
- 実際の最終フレーム6か所とサムネを目視。頭・耳が切れず、サムネは1280×720、字幕は最大2行。ゲーム領域は486×864。
- 全デコード・最終合成の連続9フレーム照合・各話者の波形照合・Chromium/WebKitの3位置再生を実行。
- 同期の限界：元録画の光・音の診断点で補正したが、同じ点での再確認は独立検証にならない。内部の中間点がない。終盤の小さいSEはAAC/他音声に埋もれ相関閾値0.25に届かない箇所があり、閾値を下げて合格にしない。確認済みの完成版と表示せず試作配布する。
- 本編用カット音源と映像、操作ログ、保存データ、補正係数・未合格項目を保存。元の大容量ロスレス録画は本作業環境のcaptureディレクトリに保持。配布するRecording-Sources.zipは使用カットと収録時計・診断記録であり、元録画全体の代わりだとは称さない。
