# 現行STILLVEILの制約と、案の新しさを確認するための棚卸し

基準コミット：`616a0747c4118a991770226d37347f34b31e2ec6`。以下はソースを実読した現行仕様。提案の強さを実測したものではない。

## 基本操作と行動

- 最大4人。同じ仲間の別の姿は同時編成不可。先頭とリーダーは別のID。探索中の自由な編成変更／先頭交代は現行にない。
- プレイヤーは先頭に通常攻撃・防御・使用可能な通常技能・石の技能・必殺を指示できる。先頭以外は役割、体力、技能CD、作戦、状態に従うAI。味方の大まかな予定表示もあるが、敵の次行動を全て確定表示するシステムではない。
- 一人は原則1ラウンド1行動。必殺はその一手を置き換える。先頭の防御予約はターン順より先に構えを準備するが、後に本人の一行動も防御として消費する。
- 素早さは役割固定で、守護者18／呪術師15／剣士14／導き手13／癒し手12／詠唱者11。定数が上がってもこの基礎素早さは増えない。高い順、同速は保存済みtie等で解決する。行動中に死亡した者は以後動かない。ラウンド開始時に行動順が作られ、通常の速度操作／順番交換は現行にない。
- 任意の味方対象を直接選ぶ一般的インターフェースはない。回復はHP割合、強化や星炉は攻撃力等で対象を自動選択する。敵の注視はある。
- 先頭の技能を予約しても、実行時に使用条件が消えればその予約の技能を強制発動できない。状態異常が行動を上書き／中断する。
- 通常探索のラウンド上限100、白亜の塔は1層1Wave・40R上限。塔は全100層。波の終了条件は敵全滅等。周期ボス大技・時計の期限・ビット射撃など、通常技能のCDとは別の仕組みがある。

根拠：`src/domain/engine.ts:161,230-356,531-570,789`、`src/domain/party-orders.ts`、`src/domain/ivory-tower.ts:3-4`。

## 通常スキルは23テンプレート

`overclock / barrier_mend / jam / rally / attack / area / heal / guard / buff / debuff / pierce / drain / regen / barrier / cleanse / mend_pair / shatter / dispel / dawn / confusion / sleep / paralysis / charm`。

名前が個別でも、同じテンプレートの技能は基本の戦闘処理を共有する。既存の全体攻撃へ格好いい名前を付けるだけでは、ルールの異なる新技能にはならない。

- overclock：自身の最大HP10%を支払い、別の味方へ必殺35。自分がHP20%超、対象がゲージ65以下等の条件。自分の支払いは被ダメージ由来のゲージ10を生まない。
- barrier_mend：負傷した味方の有効な障壁を必要な量だけ消費し、2倍のHPへ戻す。最大HP15%分まで消費、HP75%以下の対象。既に障壁→回復はある。
- jam：通常技能の待ち時間を遅らせる。通常攻撃、ボス周期大技、終鐘、ビットを止める万能沈黙ではない。
- guard：別の味方への単体攻撃を引き受け軽減。areaはかばうを無視。
- barrier：一人へ短期のダメージ肩代わり。通常の張り直しで単純加算しない。
- dispel：敵の攻撃強化と再生を外す。障壁やリーダー効果は消さない。
- pierce：防御65%無視。dawnはそれに加え、防御低下している受け手なら威力25%増。
- regen：回復がR終了時に分散。即死を救済しない。mend_pairは2人回復で、一人ごとの量は控えめ。
- 状態異常は混乱／睡眠／麻痺／魅了の4種。毒・出血・炎上・毒スタックの一般システムは現行にない。
- 混乱：スキルを使わず、50%で味方（自分含む）、それ以外は敵へ通常攻撃。睡眠：行動不可、HPダメージで起きる。麻痺：自分の行動時40%で停止。魅了：スキルを使わず自分以外の味方を攻撃し、味方不在なら行動不可、付与者死亡で解除。
- 基本の付与率は通常敵70%／ボス35%。通常は2回の行動、ボスは1回。解除後は短い状態耐性がある。単なる「違う名前のスタン」にならないよう区別する。

根拠：`src/domain/skill-info.ts:4-49`、`src/domain/ailments.ts`、`src/domain/engine.ts:589-640`、`docs/clockwork-maidens.md`。

## 必殺は個別名・演出と、6種類の役割契約

`src/domain/ultimates.ts` が明記する通り、個別の名前や絵があっても、通常の戦闘効果は役割単位。

|役割|現行必殺の基本|
|---|---|
|剣士|単体280%・防御65%無視|
|詠唱者|全体190%・かばう無視|
|癒し手|生存中の味方全員40%回復＋異常/防御低下解除|
|守護者|生存中の味方全員へ、最大HP30%＋発動者防御力2倍の障壁|
|導き手|全員の攻撃40%増＋最大HP15%障壁|
|呪術師|敵全体150%＋防御35%低下|

ゲージは100で使用可能。通常の自分の行動で25、HPダメージを受けると10が基本（強制行動や独立追撃等の除外あり）。必殺は予約が必要で、ゲージが増えただけで自動発動はしない。生存中だけ使用。通常の戦闘蘇生はない。

## リーダーは基本ステータス補正＋6系統

基本ステータス補正はリーダーの`leaderStat`と定数に基づく。基礎補正と、生存時のみ働く追加効果を混同しない。追加効果は以下。

- 曙の加速：Wave2R目から敵味方とも攻撃が毎R5%増加。回復量は増えない。
- 月の慈愛：R末に生存味方の最大HP3%回復。
- 薄明の追撃：敵HP35%以下へのダメージ20%増。
- 黄泉の契り：与えた実ダメージ8%を攻撃者へ吸収。
- 銀灯の庇護：味方被ダメージ10%軽減。
- 星の共鳴：味方全体攻撃15%増。

根拠：`src/domain/engine.ts:53-63,170-173,410-424,741-745,776-782`、`src/domain/skill-info.ts:52-63`、`src/domain/acceleration.ts`。

## 石11種・特性4種・T1〜T6

石はキャラごとに1個。装備IDの重複は認めない。探索開始時にスナップショットが作られ、通常の探索中に自由装備交換できない。戦闘中の交換や技能貸出は新しい案になる。

|石|既存の特徴|
|---|---|
|砕盾石|最大の味方障壁1つを消費して単体攻撃|
|残響石|単体攻撃と、実ダメージ35%の次R追撃|
|巻戻しの石|別の味方の通常技能CDを短縮。石の技/必殺やHP全体の巻戻しではない|
|祓いの涙石|味方の異常/防御低下解除＋小回復|
|白灯石|味方一人への短期障壁|
|奪灯石|敵の攻撃強化/再生を移す。障壁は盗まない|
|夢織石|睡眠。高Tierで本人の追加必殺ゲージ、T6では45|
|夜露石|単体攻撃＋実ダメージ35%を自分へ吸収|
|暁冠の記憶|防御無視＋防御低下相手への上乗せ|
|星炉の記憶|HPを支払い別の味方へ必殺ゲージ。最高攻撃力順等の選好あり|
|双潮の記憶|負傷した2人の回復|

追加特性は連鎖（別敵への追加攻撃）、庇護（最も低いHP割合の味方への障壁追加）、処刑（低HP敵への石の技増幅）、慈雨（石の実ダメージから味方回復）。非攻撃の石は基本的に「なし/庇護」のみで、すべての石に全特性が付くわけではない。

石の技には個別CDと装備者の石共通スロットCDがある。追撃やビットから、次の追撃・技能・ゲージ供給を無限に生まないようにしている。高Tierは威力だけでなく、特定の石でCD/上限/追加ゲージの契約も変える。T6だから全効果が一律に数倍になるわけではない。

威力roll区間は T1=0..33、T2=34..66、T3=67..100、T4=120..139、T5=160..179、T6=220..239。基礎倍率`1+roll*0.015`。T6roll239は基礎4.585倍だが、個別上限等を無視して全効果を4.585倍と説明しない。特性Tierと技効力Tierは別に存在する。

根拠：`src/domain/memory-gems.ts:3-49,71-140,173-177,189-195,298-305`、`src/application/game.ts`の出発と装備同期。

## 役割結晶など

役割結晶は、一度に1役割を選んで、その役割の技・必殺の効力を1.2倍にする。生存中の味方に存在する役割しか選べない。通常攻撃まで常に全員1.2倍、ゲージ供給や固定値すべてを必ず1.2倍、という説明は誤り。特殊技能には固有の計算がある。

回復薬は最大5個持ち込みで、指示待ちに味方一人を30%回復し、1R1回。花と妖精もあり、与ダメージ以外の行動やゲージ発生を重ねる新案は、これらとの連鎖も考慮する。

`src/domain/crystal-resonance.ts`、`engine.ts:570`、`application/game.ts:230-237` 等。
