# 最終台本・視聴性と由来ラベルの査読

対象：`/workspace/stillveil-myth-lab/artifacts/myth-lab/script-draft.json`（22章、427発話、約17,800字）と統合元の各 `*_cases.py`。全文を読んだ。関連箇所は `engine.ts`、`novels.ts`、`skill-info.ts` と照合した。出典の原文突合は各調査担当の記録を前提に、こちらでは由来と創作の接続・言い方を査読した。

**総評：構成は成立している。長いこと自体を理由に削る必要はない。** 原典の逸話→最初の案→反論→修正版→盤面での損得という流れがあり、「強そうな架空スキルの羅列」から一段進んでいる。重大な「創作効果を神話の事実として断言する」箇所は見当たらない。以下の2点は音声確定前に修正・仕様確認を推奨する。

## 1. 修正推奨：めたん本人がOP主人公に聞こえる一文

- 対象：`future_control` 最後のm、現稿の第18発話。
- 現稿：`OPの主人公の私とセリスも別の人物。原作を大切にしながら、創作する部分は区別して進めましょう。`
- 問題：音声だけで聞くと「めたん＝ゲームの主人公の私」と受け取りやすい。`novels.ts` では語り手の「私」と、泉の向こうで待つセリスが別に描かれており、主張自体は正しい。**一人称の引用であることを明確にすればよい。**
- 修正文：`OPで「私」と語る主人公と、セリスは別の人物。原作の人物を混ぜず、創作する部分を分けて考えましょう。`
- 関連する画面の小修正：gardenのnode `主人公の私` は `語り手「私」` にすると、音声と一貫する。

## 2. 仕様確認：ウズメの招待が、そのラウンドだけだと間に合いにくい

- 対象：`uzume` 第10発話と対応する期限の図。
- 現稿：`まずは通常攻撃と通常技能の単体攻撃だけ。そのラウンドに来なければ、招待は消す案にしましょう。`
- 現行の役割速度は、導き手のウズメ13、剣士14、呪術師15。**ウズメが普通に踊る時点で、多くの単体攻撃役は既に動いている。** 今R末消滅だと、白霧の狼や呪術師の攻撃を想定した盤面で出番が生まれない。
- これは原典の誤りではなく、試作の核が働くかの問題。遅い相手だけに価値を絞るなら、その弱点を一言で示す。広く試すなら、準備後〜次R末までの最初の対象攻撃へ期限を延ばす案が分かりやすい。
- 期限を延ばす修正文：`まずは通常攻撃と通常技能の単体攻撃だけ。準備してから次のラウンド末まで、最初の一撃を招く案にしましょう。`
- 現行案を維持する場合の追加説明候補：`ただ、ウズメは速さ十三。狼より後で踊るから、今のラウンドだけでは、間に合わない相手も多いわ。`
- 見た目のマークだけラウンドをまたがせず、対象条件・死亡時失効・期限の札まで一貫させる。**こちらから他担当ファイルは変更していない。**

## 3. 軽微な表示・読みの改善

### 3a. 由来のナビゲーション

`visuals.py` では `lore` の大見出しは「原典・物語のモチーフ」で適切。進捗バーの小見出しだけ「原典」になっている。ゲーム原作の台詞や博物館解説もこの相に入るため、小見出しは**「由来」**にすると、すべてを古代一次資料と呼んでいるように見えない。音声の変更は不要。

### 3b. 庭の石の名を統一

`garden` の第0相node「新しい石」の値が `未提出の観測録`、章題と台詞は `観測の栞`。新規アイテムを二つ提案したように見えるので、nodeも**「観測の栞」**へそろえる。これも音声変更は不要。

### 3c. 実際に確認したVOICEVOXの読み

ローカルVOICEVOXの`audio_query`で、本文と同じ語句を確認した。

- 石長比売 → **イワナガヒメ**：正しく読めている。
- 一手 → **イッテ**：正しく読めている。
- 國學院の神名データベース → **コクガクインノ／カミメエ／デエタベエス**：`神名` の読みだけ不自然。`spoken`で**シンメイ**へ置換するか、台詞を「國學院のデータベース」にする。
- 分け杯 → **ワケハイ**：造語なので唯一の読みの誤りとは断定しないが、意図が「ワケサカズキ」ならspoken側だけ補正を推奨する。

すべての神名をカタカナへ変える必要はない。直す語だけを限定すれば字幕の表記と研究資料を保てる。

## 4. 由来と創作の区別は良好

特に残すべき点：

- ヘカテは「声を聞いたが犯人を見ていない」と、今回の讃歌の範囲を限定する。全知・未来予知を原典の事実にしない。
- セレネの「月半ばの明るさ」から「回復を保管」を創作へ切り替える一文がある。十倍回復は最初の荒い案として即座に訂正される。
- 弁財天の水・音楽は博物館解説、ヘスティアの献酒は讃歌、HP配分は創作と分かれている。インドのサラスヴァティの全伝統との同一視もしていない。
- コノハナサクヤの火耐性は、現行に属性ダメージの分類がないという実装上の問いで止まる。
- 黄泉の坂を塞ぐのはイザナギ側、という役割の訂正を入れてから、イザナミ側への翻案を提案している。
- エオスの不死と若さ、ペルセポネの「この讃歌では三分の一」を区別する。ペルセポネの種の場面を自発的な便利な避難と同一視しない。
- 『キュプリア』を散逸した原典の**梗概**と説明する。本文全巻を読んだように見せない。
- 桃は古事記の黄泉の話であり、桃太郎ではないと短く切り分ける。

「神話全体では常にこう」と断定する台詞は見つからない。資料の全来歴を会話で読み上げず、説明欄と出典表へ置く方針がよい。

## 5. 現行仕様と未実装案の区別も良好

- ルネットの現在のうさぎ必殺演出と、新しい通常の友軍ビット資源が別であることを繰り返し確認する。
- ノクスの固有技能へ、装備した石の連鎖や慈雨を勝手に乗せない。
- 先頭一人への指示、非先頭AI、リーダー一人、石一人一個を、組合せの章でも維持する。
- 防御の半減がR開始時、花の回復は本人の手番という違いを説明する。
- ゲージ模型は二つの予約時点を比較し、敵の被弾や石を含めていない模型だと明示する。「計算したから実機で永久機関が確定」とせず、批評者側も前提を修正する。
- 庭園の女、ザクロ、セリス、OPの語り手を勝手に同一人物扱いしない。庭園の女の画面も、別人の戦闘ポートレートを使わない実装になっている。

表示上は、現行ゲームの参考映像をもし挿す場合に「現行版・参考映像」とし、新効果を実機で発動させた証拠のように編集しないことを最終確認したい。現在の説明図には常時未実装・仮値の札があり、方向性は適切。

## 6. 同系統の水増しをしていない

- リオラの今Rの一手譲渡、ヘカテの最後送り、借衣の次R交換は近いが、比較して一つずつ試すと説明する。
- 水鏡と分け杯は1章で扱い、固有技と汎用石の比較にしている。二つを別々の革新的能力として数えていない。
- 不死・債務・帰還は一章にまとめ、それぞれ違う伝承であることと、保留する理由を説明する。
- 先頭交代と未来観測も大型案のまとめであり、全案を次期に入れる予定とはしていない。
- まとめの優先順位は「最初に触りたい三つ」で、最強や採用決定には言い換えていない。

タイトルや説明文で件数を出す時も、「22の独立した実装予定スキル」のようにはしない。**22章の企画会議**、または**神話と物語から考える次の技能**が実際の内容に合う。

## 7. 視聴性：長さは許容、主に図で説明する

427発話を見て、二人の関係は建設的。ずんだもんも問題を発見している（ウカノミタマの薬増殖、石特性、リーダーの機会費用）。めたんも最初の案を出し、ゲージ模型では自分の前提不足を認める。単なる「何でも欲しがる子を叱り続ける動画」になっていない。この逆転は残したい。

余計な冗長さとして強く削るべき重複は少ない。同じ「未実装」「上限」でも、各章の誤解を防ぐ働きがあるため、一律に削らない。

任意の、音声を少し軽くする候補：

- `hp_transfer` 第14発話の「整数の端数を戻し」は、資料と画面の仕様説明へ回せる。音声なら `生きている二人だけが対象。片方をゼロにせず、最大体力も超えずに、二人の合計を守って配るわ。` でも、面白さと安全条件が伝わる。**現稿でも重大な問題ではないので、キャッシュを保つ判断でもよい。**
- `uka` のCD引継ぎの比較式は、話す順序と同時に「元の残り時間／新しい待ち時間 → 大きい方」の図を出す。テキストだけを45秒並べると、その部分だけ仕様書の読み上げに聞こえやすい。
- 不死章は制度説明が連続しやすい。金色の債務枠、老いの無行動印、冥府への退場を見た目で切り替え、同じ長いカードを置き続けない。
- 章末の「試したい」「保留」は、動画全体の読み方として必要。ただし全章で同じ効果音と同じ大見出しへ戻ると単調になる。優先候補は盤面を残し、保留は短い次の検証項目へ移る、と画面の終わり方を変える。

全発話は60字以下。本文の長さそのものによる極端な字幕負荷はない。45〜50分になっても、章立てと各案の損得の図が付くなら成立する。無言でカードだけを読ませる区間や、台詞にない説明を小字で追加する方を避けたい。
