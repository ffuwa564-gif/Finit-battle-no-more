# 長尺会議の編集設計と、北欧／弁財天の追加候補

担当：video_editorial_research。既存の24分動画の制作資料・render.py・現行フレイヤ／弁財天と役割結晶を確認した。以下は**未実装の提案**。数値は挙動の説明用の机上例で、実戦バランスの検証値ではない。

## 先に確認した原典とゲーム設定

- O01：Snorri Sturluson, *Prose Edda*, Arthur Gilchrist Brodeur訳（1916）、Gylfaginning 24・35。24ではフレイヤのフォールクヴァング、戦死者の半分、猫の車。35では旅に出たÓðrを探し、フレイヤが赤い金の涙を流すこととBrísingamenの所持。これは中世の記録で、信仰の全時代・全地域の一義的な「設定集」ではない。
- O02：*The Younger Edda*, Rasmus B. Anderson訳、Project Gutenberg 18947（取得本文は1901年刊本に基づき、著作権表示は1879年）。Óðrを探す金の涙と、イズン奪還の際にロキがフレイヤから鷹の姿を借りる物語を確認。伝承にあるのは衣／姿の貸与で、ゲームの能力コピーではない。
- O03：University of Pittsburgh、D. L. AshlimanによるÞrymskviðaの再話。Olive Bray訳（1908）pp.126–137をもとにした**再話**と明示されている。フレイヤの羽衣を借りてロキが飛ぶくだりを確認。逐語訳の一次資料として紹介しない。
- O04：Cleveland Museum of Art、歌麿《Fishing at Iwaya on Enoshima》（c.1790、1921.407）解説。日本の弁財天が水・音楽・芸能と結び付けられることを確認。**サラスヴァティの全伝統と日本の弁財天の性格を一枚に重ねない**。今回採用する根拠は日本での水・音楽との結び付きまで。
- ゲームのフレイヤは「琥珀の首飾り」「二匹の猫」「失われる痛み」「帰る場所を一緒につくる」。**琥珀はゲームの表現**で、O01の所持記述だけからBrísingamenの素材を琥珀と断定しない。
- ゲームの弁財天は「水鏡にほどける琵琶」「離れた心の傷」「最後の一音まで席を立たない」。現行はheal＋mend_pair、leader regeneration。ここを単に回復倍率を高くするだけで終わらせない。

## 候補 O-A：鷹羽の借衣（記憶石）— 借りるのは能力ではなく、行動順の席

**原典の核**：フレイヤの羽衣／鷹の姿を他者が借りる（O02/O03）。

**初案への反論**：他人の役割をコピーして結晶の強化を得るだけでは、現行の1.2倍補正の対象を変える程度。名前の割に操作が変わらない。全技能コピーにするとキャラ固有性を石が奪う。

**修正版**：装備者が生存中の味方1人を選び、**次ラウンドの2人の通常行動の順番の席を交換する**。速度値・役割・技能・必殺・ステータスはコピーしない。今ラウンドは石の使用に1行動を使い、直接攻撃しない。

- 机上の盤面：通常は「ヘカテ（呪術師15） → 狼（剣士14） → エレイン（癒し手12）」。借衣を準備した次Rは「エレイン → 狼 → ヘカテ」。回復を先に出せる代わり、ヘカテは狼より後になる。
- 差別化：巻戻しは通常スキルの待ち時間、星炉はゲージ。この石は**既存の1行動をいつ置くか**を操作する。行動回数は増えない。
- 弱点：準備ラウンドに回復・攻撃を1手諦める。相方が先に倒れる／行動不能になると交換は不成立。攻撃役を遅くして負ける可能性もある。
- 制約案：1Rだけ、同じ2人を2重予約不可、1人につき予約1件。優先防御や必殺の特別な行動順は交換しない。交換対象が不成立なら追加行動もCD返却も生まれない。
- AIとの整合：順番だけを変え、仲間が選ぶ技能まで保証しない。確実に回復したければエレインを先頭にして通常の手動指示と組み合わせる。
- 実装の難所：優先防御／必殺との整合と行動不能時の扱い。キャラの顔を選ぶ既存操作に「次Rの席交換」の小アイコンを足す程度で、常時の横ボタン列は増やさない。
- 優先度：**プロトタイプ向き**。原典と効果の距離を説明しやすく、戦闘順の図だけで魅力が伝わる。

短い掛け合い：
ず「羽衣なら、ノクスの技を全部借りるのだ！」
め「それ、ノクスを仲間にする意味まで石が奪ってない？」
ず「じゃあ、借りるのは強さじゃなくて……先に動く場所なのだ。」
め「エレインを狼より前へ。でも代わりにヘカテは後ろ。得した分、誰かが待つわね。」

## 候補 O-B：金の涙の猶予（フレイヤ固有技能）— 助かったふりではなく、回復の期限を作る

**原典の核**：Óðrを探すフレイヤの涙が金になる（O01/O02）。「HPの借金」はこちらの創作で、神話そのものの能力として語らない。

**初案への反論**：「傷付くほど金や火力が増える」は自傷で稼ぐだけになる。「瀕死になるほど強い」だけでは殴り続ける最適解から変わらない。

**修正版**：指定した生存中の味方への、次の敵によるHPダメージの一部を「猶予」に回す。次R末までに**その味方へ届く直接回復を、HPより先に猶予の支払いへ使う**。払えない分は期限にHP損失として確定する。攻撃を続けるか、回復の必殺を先に使って返すかを選ぶ。

- 机上の例：今80HP、敵から100ダメージ、30だけを猶予へ送ると現在HP10／猶予30。次に40の直接回復を受けると猶予0／HP20。合計回復を増やす効果ではない。
- 弱点：猶予を払っている間はHPが戻らない。次の敵に倒されることもある。全回復の見た目に騙されない、という会議の論点になる。
- 必須の安全策：1戦1回または極めて明確な上限。猶予額には上限を置き、上限を超える攻撃の残りは即座に受ける。巨人の一撃を無料で全額踏み倒せない。自傷・星炉のHP支払・味方攻撃から猶予を生成しない。猶予確定損失はダメージ反応／猶予再生成を呼ばない。未払いはWave移行や戦闘終了で清算する。
- 開発時に決めること：再生／吸収まで返済に使うと循環が読みづらい。最初の試作は「直接回復」だけに絞り、対象に期限と残額の小さなアイコンを出す。細かい数値や対象範囲は未調整。
- 優先度：**設計保留を含む尖った候補**。説明・UI・例外が多く、試作前に厳しい査読が必要。

短い掛け合い：
ず「死にそうな攻撃を、明日まで待ってもらうのだ。」
め「でも明日、払えなかったら？」
ず「……忘れてもらうのだ？」
め「それだとただの無敵。払った回復はHPに戻らない、ってところまで代償にしましょう。」

## 候補 O-C：水鏡の調律（弁財天のリーダースキル）— 回復を増やさず、傷を分ける

**資料と物語の核**：日本の弁財天と水・音楽の結び付き（O04）＋ゲームの「離れた傷」「最後の一音まで」。神話にHP移し替えの記述がある、とは説明しない。

**初案への反論**：回復が2人に届く、だけなら現行mend_pairと被る。オーバーヒールをさらに回復へ変換すると回復の永久機関になりやすい。

**修正版**：1Waveに1度、**生きている味方2人の現在HPの合計を保存し、最大HP比に応じて配り直す**。2人の残HP率を近付ける。倒れた者は対象外。発動の代償として弁財天は次の通常行動を休む。

- 机上例：A 最大400／現在320、B 最大200／現在20。合計340はそのまま、A 約227／B 約113へ。Aは93を渡し、Bは93を受け取る。満タンになる者を増やす通常回復と役目が違う。
- 「HP率をただ交換」してはいけない。400HPのキャラの80%と200HPのキャラの10%を交換すると総HPが変わり、複製が起きる。**総量保存**を図で見せることが重要。
- プレイヤーの選択：一番頑丈な壁を傷つけてでも、狙われるアタッカーを残すか。ヒーラーの次の回復行動まで休ませる価値があるか。
- 差別化：mend_pairは新しいHPを生む回復、この案は仲間の持っているHPの配分。吸収・慈雨・再生の発動源としては扱わない。
- 悪用対策：配分を被ダメージ／回復イベントとして連鎖させない。戦闘不能・HP支払予約・猶予中の者との相互作用を先に定義し、最初の試作はそれらがある対象には使えない仕様でもよい。整数の端数を片側に戻して総HPを厳密に保存する。
- UI：2人を選んだ時に「現在 → 配分後」を2本のバーで表示。確定まで取り消せる。既存の戦闘操作列を大きくしない。
- 優先度：**プロトタイプ候補**。回復数字の大きさ以外で、弁財天の在席と献身を表現できる。役割変更の代償は厳しく査読してほしい。

短い掛け合い：
ず「二人が同じ残り割合になったのだ。回復が増えたのだ？」
め「合計340は変わっていないわ。アテナから分けてもらったの。」
ず「じゃあ、アテナのほうが危なくなるのだ。」
め「そう。傷を消したんじゃなくて、誰が引き受けるかを選んだのよ。」

1. 通常の会話盤面は前作を踏襲しつつ、中央を縦ゲーム画面固定から**横長の設計卓**へ変更。左右に二人、中央に4人の顔と順番レーン／HPバー。実機映像に偽の未実装能力を合成しない。

4. 借衣は3枚のカードを滑らせるだけで分かる：ヘカテ→狼→エレイン、の2人を矢印で交換。ボタンを増やしたゲームUIは描かない。

9. SEは現行ゲームのUI音・軽い魔法音を「説明用の演出音」として小さく使う。未実装技を録音したかのように言わない。通常の参考映像では映像と同じゲーム音声を維持する。
10. 前作と同じ小さめの字幕を下部独立領域に保ち、出典と本文を字幕の後ろへ重ねない。BGMは言葉を追える音量で、会議の改稿ごとに曲を頭出ししない。

# 第一巡査読を受けた第二案（この節を本文より優先）

査読：strict_skill_critic。上の初稿は会議の発想過程として残し、以下を改稿仕様とする。

## O-A v2：借衣は「固有技能か石か」を競わせる

- **現行仕様の訂正**：engine.ts 549行では必殺も含めてspeed / tie / uidで1回の行動順を作る。「現行の必殺には特別な別順位がある」とは説明しない。先頭の手動防御はラウンド開始時に防御状態を先に準備し、実際の1行動は通常の席で消費する。
- 修正版の交換は、次Rに2人が持つ**それぞれ1回の行動の席**を交換する。普通の攻撃・スキル・必殺を分類して後から交換を取り消す複雑さは持ち込まない。手動防御の事前準備のタイミングは変更しない。
- 2人の片方が倒れている／行動不能で動けない場合、もう片方へ2回目の行動は渡らない。自分の席での行動が残るだけ。どちらの死亡でもCD・ゲージは複製しない。
- **企画上の競合**：リオラ固有案にも行動順操作があるなら、同時に汎用石へ同じ体験を配らない。今回は「フレイヤの貸す物語から作る汎用石」対「リオラが守るために動く固有技能」の**比較案**にする。両方とも実装予定と扱わない。
- 第2巡への問い：単なる速度バフで実現できる範囲との違いは、相手が必ず遅い席を引き受ける**対称の交換**であること。使用者の1手＋相手の遅延があっても、全編成に載せたい必需品になっていないかを試作で調べる。

## O-B v2：フレイヤとイワナガ、債務を二つ並べない

- イワナガの債務案と同じゲーム上の役割なら、二つを足して独創性を水増ししない。フレイヤの「失う痛みと価値」から着想したという**別の由来の候補**として、どちらの人物の物語に一番合うかを比較する。
- 猶予額・期限・回復の支払先・Wave終了時の清算・相討ち時の勝敗順序まで決まらない段階では保留。綺麗な名前で実装コストを隠さない。
- 動画では30〜45秒の「同じ面白さなら、二人に同じ能力を配らなくてもいい」で十分。独立した採用候補章にはしなくてもよい。

## O-C v2：リーダーの追加UIから、本人の固有技能へ絞る

- **優先する試作形**：弁財天が先頭のとき、本人の今Rの1行動で「水鏡の調律」を使う。後払いの行動休みは削除する。
- 操作を絞るため、最初は予約時点で**現在HP率が最大／最小の生存中の味方2人**を自動で候補にする。顔アイコンと「発動した場合の配分」を表示して、使うか通常の回復にするかを選ぶ。
- 対象2人は予約時に固定する。実際の配分は発動時のHPと最大HPから計算するため、プレビューは「現在値での参考」と明示。どちらかが倒れた時に勝手に別の味方へ対象変更せず、不成立の消費ルールも決める。
- 配分式は `total = hpA + hpB`、理想値を最大HP比で割る。ただし新HPを **両者最低1、最大HP以下**の整数に制約し、その範囲で最もHP率が近くなる配分を選ぶ。端数は片側へ返し、必ず合計を保存する。
- 現行mend_pairと違い、HPが新しく生まれず、壁役から脆い役へ移すことに価値がある。大部分の状況では通常回復の方がよい可能性を認め、倍率で誤魔化さず、有用な場面が本当にあるかを試作する。
- 「リーダースキル版」はこの1手の試作が面白かった後の別案として保留。能動操作を持つリーダー効果を現行の受動LSと同じ工数だと言わない。

速度図の査読訂正：ノクスと狼はどちらも剣士速度14で同速tieに依存するため、原案のノクスを使った固定順の説明は採用しない。ヘカテ15→狼14→エレイン12なら現行の役割速度に沿う。交換後の順は未実装の概念図として示す。

# 第二巡の最終判定

- **O-C 水鏡**：本人の今R一手・候補二人・総量保存・最低1に絞った固有技能を**試作候補**。即時に任意2人を指定するLS版は見送り。ヘスティアのHP配送石案と役割が近いので、最初は片方を優先し、動画では「HPを生む回復／持っているHPを置き直す配分」の比較にまとめる。
- HP配分を回復でも被弾でもない独立処理にすると、将来の回復禁止や債務を迂回する可能性がある。**初回はそれらの新状態異常と同時に導入しない**か、対象制限を明確にする。独立した分類にするだけで相互作用が解決済みとは言わない。
- **O-A 借衣**：現行速度・必殺・防御処理の訂正を確認したうえで、リオラ固有の順番譲渡と**代替比較の保留**。どちらも強い案だが、同じ更新で二つ足すことを前提にしない。
- **O-B 金の涙**：イワナガの債務案との由来比較と、例外の多さを隠さない**短い保留例**。長く引っ張って動画の核案を水増ししない。
