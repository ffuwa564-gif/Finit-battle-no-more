# 日本神話からの次期スキル会議 — 調査・提案・査読用

作成日 2026-11-01。**全部、未実装の企画案**。神話の記述・STILLVEIL固有の人物設定・効果の創作を分ける。参照先は実際に取得した國學院大學「古典文化学」神名データベース8記事。古事記本文そのものを通読・校訂したという意味ではなく、学術DBの梗概と諸説を読み、同DBが指す古事記の段を明示する。

## 採用を検討したい核

### J1 アメノウズメ / スキル「舞台への招待」 — 試作優先 M

**出典事実**：古事記上巻「天の石屋」。石屋にこもる天照を外へ招くために神がかりし、諸神の笑いを誘う。天孫降臨段での案内の仕事もあり、「踊って魅了する」だけに神格を限定しない。[JP01]

**ゲーム内の人物**：`iris`。沈黙した街に笑いを戻そうとする鈴舞の支援者。現行の副技は魅了なので、魅了の名前替えにしない。

**最初の案 → 反論**：「踊ると敵が一回休み」は睡眠・混乱・魅了と似すぎる。ボス行動を無条件に潰すだけになる。

**改稿**：発動時に、敵の現在の狙いとは別に「招待」印を一体へつける。その敵が次に使う**単体の通常攻撃か通常スキル**の最終対象を、踊った本人へ固定する。実際に被弾する。全体攻撃、自律兵器、固定標的の特殊攻撃、味方への同士討ちは変更しない。最初の対象適合攻撃で印を消費し、発動R終了までに来なければ失効。威力軽減はこの技能自体には付けない。

**新しい判断**：守りたい味方の代わりに、攻撃に耐えられる状態のウズメが舞う。敵の攻撃を消すのではなく、受ける人を変える。

**真の代償**：攻撃役の一手を使い、低レアの支援役自身が被弾する。標的を引くため、障壁や回復と組む意味がある。

**悪用対策（厳格査読反映）**：同時に複数の招待印を置けない。既存「かばう」でさらに別人へ転送する二重の身代わりは、この招待攻撃では禁止するか、「招待は最終対象決定」と仕様化する。印の更新で攻撃を永久回避しない。攻撃されたときの効果は実ダメージに従い、印が付くだけではゲージを与えない。

**短い掛け合い**：ず「魅了より強いのだ？」め「敵は本気で殴ってくるわ。笑いで注意を引く役を、どこまで守れるかね。」

### J2 トヨタマヒメ / リーダースキル「海坂の便り」 — 試作優先 M

**出典事実**：古事記上巻の豊玉毘売。見るなという約束が破られ、海坂を閉ざして帰る。しかし妹の玉依毘売に御子の養育を託し、火遠理へ歌を贈る。[JP02]

**ゲーム内の人物**：`toyotama`。帰れなくなった海宮の記憶を持ち、二人を隔てず包み込む癒し手。

**最初の案 → 反論**：「見てはいけない」ので敵の予告や味方HPを隠す。これは情報を奪うだけで判断が悪くなり、難しさと不親切を取り違える。**却下**。

**改稿**：出発時の**先頭と末尾**の二人を結ぶ。どちらかへ直接回復が届く際、対象の欠損HPで上限をかける**前の回復予定量**を半分ずつ二人へ配分する。自身への吸収回復も含むが、吸収の原資は実際に与えたHPダメージから求める。分配後に、それぞれの欠損HPや債務に適用する。片方満タンの溢れは失う。分配先から再度分配しない。

**具体例**：前衛も後衛も傷ついているとき、回復予定80を40/40に分ける。後衛が満タンでも、その後衛の自己吸収で生じた回復予定80から前衛へ40を届けられる。一方、前衛に緊急80が必要なときに40しか戻らない危険がある。

**図解用の二例**：二人ともHP20/100で回復予定80なら、40/40を受けて両方60。前衛20/100・後衛100/100で後衛に自己回復予定80なら、前衛へ40、後衛の40は溢れて消え、結果60/100・100/100。どちらも元の80を160にしていないが、後者の実効回復は0から40へ増える。

**新しい判断**：自力吸収する剣士を後ろへ、守りたい役を前へ置く。誰を先頭にするかが回復経路にもなる。

**悪用対策（二巡目査読反映）**：原資の**回復予定量**を増やさない。満タンへの溢れを別人へ運ぶため、**実際に戻るHP量は増える場合がある**。「実効回復量まで常に不変」とは説明しない。端数は本来の対象に残して整数の合計を保つ。全体回復は各対象の回復予定を一回ずつ分ける。同じイベントの再分配なし。戦闘中の並び替え不可。片方戦闘不能でもその半分は届かない。リーダー死亡後の新規回復には適用しない。再生の定期回復・回復薬・花などの外部回復は初期案では除外し、技能・吸収・慈雨などの直接回復から試す。薬をそのままの緊急回復に残せる。二人未満の編成ではリンクを作らない。T6慈雨92%からも発生するが、原資自体が倍になることはない。

**神話との差**：「歌を贈る→回復を送る」はゲームの翻案。原典にHP分配能力があるという説明にしない。原典の姿は古事記では八尋和邇、日本書紀本書では竜という差があり、ゲームの海竜表現は翻案として扱う。

### J3 ウカノミタマ / リーダースキル「蔵開き」 — 中期試作 L

**出典事実**：古事記では須佐之男と神大市比売の子。名のウカは食物と関わり、國學院DBは特に収穫された稲の穀霊、倉に祭る信仰を論じる。日本書紀一書では出生の記述も異なる。[JP03]

**ゲーム内の人物**：`ukanomitama`。種籾を分け、明日の食卓を守る神を、作品では女性の姿に描く。

**最初の案 → 反論**：「薬が増える」「全員自動回復」では既存再生の拡大。弱い敵を残すと無限に蓄えられる案も却下。

**改稿**：出発時に所持石から**予備石を一個だけ蔵に封印**する。ダンジョン中、Wave間で一度だけ、その石と味方一人の装備石を交換できる。戦闘中は交換不可。二つを同時装備することはない。持ち込まなかった在庫にはアクセスできない。使い終わりの攻撃石を次Waveの支援石へ変えるなど、先の敵に備える構築が生まれる。

**新しい判断**：最初から完成形一組だけを持つか、二つの局面へ備えるか。低いティアでも用途の違う石を持つ理由が増える。

**真の費用**：再生など既存のリーダー効果を捨てる。単一Waveの塔1層ではほぼ出番がない。万能な攻撃石として紹介しない。

**悪用対策**：装備枠の現在CDを維持する。交換先の最大CDが違う場合は `新しい残りCD=max(旧枠の残りCD, 新石の通常CD)` とする初期案なら即時再発動を防げる。能動的に石を使っていない枠も交換で開始時/初使用のトリガーを新たに得ない。既に払ったHP・消費資源は返さない。リーダーの一時離脱/復帰で交換回数を戻さない。

**実装費用**：新しい出発準備枠、Wave間操作、セーブと互換性、石のCD保存が必要。新しい攻撃効果を足すより重い**装備ルール拡張**として、後半の会議で扱う。

## 強い核があるが保留したい案

### J4 イワナガヒメ / リーダースキル「朽ちぬ器」 — 仕様検証を先に L

**出典事実**：古事記上巻「木花之佐久夜毘売」に関わる短命起源譚。姉の石長を迎えれば岩のような長い命、妹を迎えれば花のような繁栄という父神の誓約が語られる。國學院DBは書紀諸伝との差も解説する。[JP04/JP05]

**ゲーム内の人物**：`iwanagahime`。拒まれた記憶を恨みではなく守りへ変えた盾役。

**最初の案 → 反論**：「全員一回HP1で耐える」は既存ゲームでよくある踏ん張り、数値インフレで実質無敵にもなる。

**改稿**：パーティ全体で戦闘一回、味方の致死ダメージの一部を**債務**として残し、その場ではHP1に留める。債務は最大3Rの固定HP支払いとなり、総量を減らさない。回復が届いた場合はまず債務返済へ回り、残りだけHPへ入る。だから高い慈雨でもHPを戻せず、次の被弾で死ぬ危険が残る。

**技術上の厳格な条件**：債務は被ダメージ/自傷/HP支払いと別の分類。障壁、かばう、軽減、反射、被弾ゲージ、吸収、連鎖、慈雨を起動しない。返済は新しい回復や攻撃ではない。コピーやリーダー再登場で再起動不可。Wave間も消えない。

**二巡目の反論**：「敵を倒したら債務消滅」は短期戦だけ無料になる。最終勝利判定前に残額を精算し、全員倒れれば敗北という案なら踏み倒せない。しかし**勝ったと思った瞬間の敗北**になるため、最後の一撃を打つ前に残額を確認できる必要がある。現行UIへ無駄な説明欄を増やすのでなく、債務アイコンの数字とタップ詳細で知らせる。この重さまで含め、初回導入は保留。

**会議の核**：時間を買う効果が本当に支援になるのか。無敵ではないことと、理不尽に見えないことの両方が必要。

### J5 アマテラス / 能動スキル「朝を閉ざす岩戸」 — 情報UIを先に試す保留 M/L

**出典事実**：須佐之男の乱行から石屋へこもり、神々に招き出され、世界が照り明るくなる。[JP06] **原典に時間停止やCD停止は書かれていない**。

**ゲーム内の人物**：`asteria`。朝の来ない世界へ、岩戸の向こうから暁を持ってくる。

**最初の案 → 反論**：岩戸から出る条件を「他の三人が異なる行動をする」にすると、他三人はAIであるため、押した本人が成立を制御できない。さらに閉じている間に無敵なら無料の待ちになる。

**改稿**：先頭アマテラスの一手を使い、戦闘一回、そのラウンドに限り**敵味方の待機中の技の自然なCD進行を止める**。攻撃・被弾は止めない。バフ持続、HP、R数上限、固定Rのボス予告・断罪も通常通り。石のCDも同じ原則で止める。能動の巻戻しによる短縮は通常通りとする。

**判断**：敵の危険な技があと1R、味方が使いたい技は準備済みの時を狙う。味方の再使用も遅れるので、押せば得とは限らない。無敵も不可視もない。

**二巡目査読の結論**：現行の敵通常技能の残CDは公開されていない。「危険な技があと1」を選ぶなら、敵詳細で残CDを見られる設計が先。既存のティッカ等の `jam` が通常技能CDを延ばすため、この案を単に「全体jam＋味方も不便」と呼ぶだけでは新しい面白さが足りない。初回の採用候補からは下げ、原典が魅力的でも情報設計が追いつかない**保留例**にする。

**要検証**：すでに技を使った同Rに設定される新規CDの扱いを統一する。敵の固定スケジュールまで止めると有名ボスの解答を消すため、初期案では止めない。光を閉ざす→技の歩みを止める、という**翻案の飛躍**を会話で明示する。

### J6 イザナミ / 能動スキル「千引の帰還門」 — 保留 L

**出典事実**：古事記上巻「黄泉の国」。見るなという頼みが破られ、追跡と黄泉比良坂の境界の封鎖・別離へ至る。[JP07]

**原典の主体**：黄泉比良坂を石で塞ぐのは伊耶那岐側。イザナミに「帰還門」を使わせるのは、役割の置き換えを含むゲームの翻案と明言する。

**ゲーム内の人物**：`evelyn` は、境界に立ちながら現在の仲間を守る選択をした。復活を単純に付けず、この作品の意思に合わせて翻案する。

**案**：味方一人をその探索から**生きて帰還**させ、空いた場所に一度だけ身代わりとなる門を残す。帰還した者は残りの探索に復帰できず、技・石・リーダー効果・死亡トリガーを全て失う。門は次の適合する単体攻撃一回で消える。全体技や特殊設置には無効。

**反論と扱い**：瀕死者を安全に戻して守る物語は合う。一方、低性能の四人目を門の弾にする編成が最適になりかねず、誰を選ぶUI、帰還と戦闘不能の違い、勝利画面やセーブまで増える。通常の盾スキルではなく、**一行の人数を減らす戦術**として独立して設計すべき。今期の試作優先からは外す。

### J7 コノハナサクヤヒメ / 「火中の産屋」 — 却下例から議論する

**出典事実**：古事記上巻で、一夜の懐妊を疑われ、戸口のない殿を土で閉じ、火をつけ、その中で三神を無事に産むことで証を立てる。[JP05] 「木花」を桜だけに限定するかにも諸説があり、ゲームの黒桜は作品独自の表現として扱う。

**ゲーム内の人物**：`mireille` は命をつなぐ花守の癒し手。

**最初の案**：「炎を受けると大回復」「炎無効」。**現行に火属性のダメージ分類がない**ため、文字だけの耐性を生やしても機能しない。生き延びる誓いを、そのまま無敵へ変えるのも平凡。

**再考の方向**：一人が一R、外からの回復・障壁・強化を受けずに、実際の被弾をしのぐと、その人物の次の通常技能の使用権を一回だけ予約できる。追加の行動を生むのでなく、本人の次の通常行動で使う。石の技・必殺は対象外、被ダメージを代償として払う技能にしない。

**なぜ保留か**：先頭以外はAIで、その予約をいつ使うかの決定が難しい。強い被弾を要求すると初心者向けの自殺ボタンになり、回復を禁止する理由の説明も長い。強い原典があっても、すぐ良いスキルになるとは限らないという**会議の失敗例**に使える。

### J8 桃の石 / 記憶石「三つ桃の路標」 — 対応する敵を作る時に M/L

**出典事実**：古事記上巻「黄泉の国」。伊耶那岐が桃の実三つで追手を退け、意富加牟豆美命の名を与える。書紀には桃が出ない異伝もある。桃太郎そのものの話と混同しない。[JP08]

**案**：石の技を使うと、パーティ共通で最大三つの桃札を置く。その後の敵の**明示的に「追撃」と分類された追加行動**だけを一枚ずつ取り消す。本体の最初の攻撃や、一つの技に含まれる多段ヒットは止めない。反射ダメージや回復は生まない。

**判断と代償**：ボスの追撃前に一手を使うか、攻撃石を持ち込むか。追撃しない相手には不向き。すべてのボスの必殺をキャンセルする万能石にしない。

**悪用対策**：複数装備でもパーティ共有三枚、戦闘一回の準備、Waveをまたぐ補充なし。コピー・T6強化で枚数を増やさない。新規タグを持つ敵がまだいない段階では無効な石になるため、先に敵行動の分類が必要。現在の自律ビットを追撃と呼ぶかは意図して決める必要がある。

## 現行の編成契約を守る

- リーダーは一人なので、トヨタマの分配、ウカノミタマの予備石、イワナガの債務を同時に有効にできるという組み合わせを宣伝しない。候補のリーダー効果同士は別案。
- 通常形と別衣装の同一人物を、二人ぶんの別キャラクターとして同時編成できるとはしない。
- 他三人はAI。新しく任意の味方を選ぶ能力には、選択UIの費用が発生する。ウズメは本人、トヨタマは編成先頭/末尾で対象を固定して、この追加操作を減らした。

## 動画に使いやすい流れ

1. 踊り＝魅了と決めつけず、ウズメで「攻撃を引き受ける」を提案。
2. トヨタマで「見るなだからUIを隠す」をめたんが却下。手紙の翻案から、回復経路を作る案に直す。
3. 神話の世界とゲームの独自人物像を比較。イザナミを単純な蘇生係にしない。
4. 岩戸のAI条件待ちを却下して、有限のCD停止へ修正。原典と創作の飛躍を明言。
5. 石長の債務で、代償が高性能の慈雨に消されないか検討。ただし「勝った後の敗北」の不快さまで議論。
6. ウカノミタマの蔵で、石を拾う価値を「倍率」から「次のWaveの選択肢」へ広げる。実装費用も隠さない。
7. 桃札と火中の産屋は保留。元ネタがあっても未整備の敵分類・UI・AIが足を引く例にする。
