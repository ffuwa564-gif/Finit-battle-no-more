# 宝石の共鳴と黒い追撃花

右下の宝石をタップすると、6色と内部紋章を使った役割の選択画面が開きます。選択した役割の、生存中の味方全員が対象です。該当する仲間がいない役割は選べません。選択は探索内のWave移動と再読み込みで保持し、新しい探索は共鳴なしで始めます。

作戦を選ぶ時間だけ変更できます。選択だけではラウンド・乱数・必殺ゲージ・回復薬・再使用待ちを進めません。強化は1役割だけで、切替で蓄積しません。「共鳴を解除」で外せます。演出中は切替できず、同じラウンドの仲間の行動すべてに同じ共鳴を適用します。敵の同じ役割は対象外です。

## 補正

選択した役割のスキル・必殺技の数値効果を1.2倍にします。

- ダメージ：防御計算後、かばう・障壁の軽減前に1.2倍。
- 回復・複数回復・吸収・解除に伴う回復・障壁：元の効果量を1.2倍、HPや必殺ゲージの上限は維持。
- かばう・攻撃強化・防御低下：内部の強度値ではなく、軽減／増減する割合を1.2倍。過剰な軽減は90%まで。
- 継続回復：付与時に1.2倍した強度を保存。その後共鳴を変えても、付与済みの効果は変化しません。
- 必殺ゲージ付与：35なら42。本人の通常の行動による25や被ダメージによる10は変えません。
- 状態異常：成功率を1.2倍（通常70→84%、ボス35→42%、上限100%）。耐性・状態異常中の制限・付与後の猶予は維持。

効果時間・クールダウン・解除だけの効果・妨害の追加待ち時間・リーダースキル・花・妖精の祝福・薬は変えません。混乱・魅了による強制攻撃にも補正しません。数値のない効果を強制的に別の効果へ変換しません。

## 見た目

回復役は緑の花、守護役は青の盾、単体攻撃役は赤の剣、全体攻撃役は橙の放射紋、支援役は金の星、弱体役は紫の砕けた輪。枠の上に常時テキストは追加せず、宝石の色・内部紋章と、タップ時の選択画面で確認できます。キーボードと読み上げにも対応し、動き軽減・通信量節約・アニメ読込失敗時は静止画を使います。

回復花はこれまでの白い花、追撃花は白い蕾から開く途中に黒紫へ染まる専用アニメと開花後の黒い静止画を使います。蕾は共通。5秒で開花しますが、開花途中でも操作待ちなら摘めます。未採取の花はWave移動・再読み込みでも保持し、摘んだら蕾へ戻ります。

原画・動画はユーザー依頼で制作した素材をそのまま採用。動画はRunwayで生成し、透過・背景マットの清掃・中心合わせ・ループ・開花区間の編集を行いました。SHA-256・生成タスクIDは `role-crystal-assets.json`。今回の実装で追加の有料生成はしていません。水やり・充填回数のゲーム案は別案で、今回追加していません。
