# 仲間のレアリティ枠

CharacterPortraitで共通の装飾枠とR／SR／SSRの文字バッジを表示する。戦闘中の味方、パーティ編成、図鑑、仲間候補など、この共通部品を使うカードに反映する。敵の戦闘表示には追加しない。

- R：銀と青灰色の細い枠、簡素な角線。
- SR：紫と銀の二重線、宝石形の角飾り。
- SSR：金の二重枠、曲線と宝石を組み合わせた角飾り、下辺の小さな中央飾り。

RarityFrameはSVGとCSSで絵の上に重ねる。画像・動画の大きさや顔の表示位置を動かさず、左下のレアリティ文字と、左上のリーダーマーク・右下の定数を別々に配置する。装飾はpointer-events: noneとaria-hiddenで操作・読み上げを妨げず、文字バッジとボタンのレアリティ説明から等級を確認できる。装飾のアニメーションはなく、動き軽減時も同じ静かな表示を使う。強制カラーモードにも対応する。

素材のcommon／rare／epicや、敵のRARE遭遇表示は別の分類として既存のまま扱う。

確認：R／SR／SSRを同時に含む味方編成を390px・320pxで撮影。1440pxも含めた横はみ出し、敵ページ送り、敵への装飾がないこと、枠が入力を遮らないことを確認。既存の顔グラ・人物詳細・動画・戦術試練と、itch埋め込みのブラウザーテストを実施する。
