# 1.10 探索記録・周回実測の独立QA

GitHubの既知研究資料に基づくローカル改良。PR・commit・push・deployは行わない。現行の資源挙動を変えず、終了した探索の観測結果を保持することを受け入れ条件とする。

| 領域 | 受入条件 | 状態 |
|---|---|---|
| 成功の資源 | 撃破gold、wave宝石、claim報酬をそれぞれ一度だけ。初回石と通常lootを区別 | 通過 |
| 失敗/撤退 | 既確保gold/宝石保持、仮素材喪失、薬は実消費だけ。returnで1run1記録 | 通過 |
| batch集計 | round/bloom/fairyは生成時1回、replayは加算しない。2waveでも累積維持 | 通過 |
| 回復薬 | potionは実HP回復と1消費のみ。古いeventsを再集計しない | 通過 |
| 時計 | departから初回reward/failed確定まで、claim待ち除外。欠落/逆行はnullで後から補わない | 通過 |
| 時給 | 合計の観測収入/観測時間。0秒/時刻不明収入を時給の分子へ混ぜない | 通過 |
| reportの正確さ | 敵からの実HP被害と回復、障壁吸収、HP自己支払を区別。被弾wave/roundを正しく表示 | 通過 |
| 互換 | 計測なし既存探索の履歴を遡及追加しない。旧移行を通常runへ計上しない | 通過 |
| 保存 | backup roundtrip、invalid record拒否、最後30件、runID重複なし、RNG不変 | 通過 |
| UI | JA/EN×320/390、横overflowなし、長い区画はInventorySection初期折畳み | 通過 |

検証用戦闘は処理を短くするため一部のHP/攻撃力をfixture内だけで変更する。資源・保存・観測のライフサイクルを検証するもので、難度や人間の周回時給の証明ではない。

## 実装前監査で共有した注意

- 結果battle.roundはresolve後に+1されるため、最大被弾のroundは解決前contextを渡す。
- duration0だけでは時給nullでも、他の有効時間runと混在すると分子だけ加算され得る。0秒runの資源は全収穫には残し、時間集計から除く。
