# 通常姿の女神・共通プール

初期追加の通常版5人をすべての祈願シリーズに収録。Rはフローラ（朝庭の花守り）とイザナミ（静かな境の守り手）、SRはセレネ（月明かりの導き手）・アテナ（静謐の知恵）・アマテラス（暁を照らす光）。原画は本作の通常旅装を描くアニメ調の創作で、歴史的・宗教的衣装の復元をうたうものではない。

通常版のIDは `*-standard`。既存の衣装版ID・セーブ・所有情報を維持する。`familyId` は対応する既存衣装版のIDに合わせ、別々の所有・ホーム選択は可能、同じ女神の複数形態の同時編成は不可。図鑑と詳細の「同じ女神の姿」から通常版・衣装版を相互に確認できる。

`sharedGoddessIds` はR/SRの通常姿、`sharedSSRIds` は共通SSR。各 `GachaCollection.characterIds` はシリーズ限定対象で、`gachaPoolIds()` が実際の合算プールを構成し、抽選・表示・検証で同じ定義を使う。基準R80% / SR17% / SSR3%、石5個、重複R1 / SR2 / SSR3還元、初回2回目保証の一度きりの共通消費、74回目からの確率上昇と90回天井を維持する。

通常SSR抽選はピックアップ50%・共通SSR50%、各グループ内は均等。ピックアップ2人は各0.75%、共通SSR3人は各0.5%が基準値。初回保証・90回天井は従来どおり選択中のピックアップ2人から均等抽選。共通SSRでもSSR天井はリセットされ、すり抜け後の次回ピックアップ保証は設けない。確率上昇中はSSR総率だけを上げ、グループ比率は維持する。R/SRはレアリティ内で均等抽選。各カードの基準排出率は実際の抽選と同じグループ定義から算定する。

原画は画像生成で新規制作し、配信用WebPを `public/art/gacha-*-standard.webp` に収録。各1024×1536、動画なし。Runwayの動画クレジットは使用していない。通常姿もホーム・編成・戦闘・図鑑に使用できる。小さい顔枠は専用の拡大率を使い、詳細では原画全体を表示する。

検証は `tests/standard-goddesses.test.ts`（両シリーズで全通常版の獲得、還元、保証、旧セーブ、家族制約）と `e2e/standard-goddesses.spec.ts`（表示・翻訳・姿切り替え・獲得・ホーム・バックアップ）を参照。

第2弾時点の合算プールは和装23人、ゴス25人。SSR確率・天井・還元は従来通り。個別の通常時SR確率は和装17/11≒1.5455%、ゴス17/12≒1.4167%。Rは和装80/10=8%、ゴス80/11≒7.2727%。既存の所有IDとセーブ形式を維持する。

## 10連祈願

単発は石5個、10連は開始時に石50個が必要。10連専用のレアリティ保証や割引は設けず、同じ乱数列・同じ条件の単発10回と同じ抽選結果となる。初回2回目保証、74回目からの確率上昇、90回天井、SSR獲得時の天井リセットを各回に適用し、同じ10連内の再獲得も即時に重複判定・還元する。還元の見込みで50個未満から開始することはできない。

抽選10回は1コマンド・1リビジョン・1保存トランザクションで確定。途中の抽選エラーや保存失敗時は全体を確定しない。最新結果は `lastGachaResults`（1件または10件）に保持し、既存の `lastGachaResult` は最後の1件として維持する。旧セーブでは新フィールドの欠如を許容する。履歴IDは連続抽選でも重複しない。

10連で初回保証を含む場合は選択シリーズと石50個の消費を事前表示し、取消では保証も石も消費しない。結果一覧には各人のレアリティ・NEW／還元数、合計還元数を表示。カードをタップすると従来の個別演出へ進み、閉じると一覧へ戻る。個別演出の表示は再抽選・追加消費を行わない。全体を閉じても既に確定した10人の獲得は保持する。モーション軽減に対応する。

`tests/ten-wishes.test.ts` で単発との同値性、各保証境界、重複還元、エラー時の原状保持、結果の保存互換を検証。`e2e/ten-wishes.spec.ts` でスマホの一覧・個別表示・初回保証取消・連打防止・両シリーズの天井・石不足・再読み込み後の獲得保持を検証する。
