# 勲章ツリー（1.25）

図鑑 → 勲章。工房9・探索8・連携6・仲間8の計31種類。前提勲章で枝を開き、条件を事前に確認して目標を設定できる。獲得名は図鑑内の称号にできる。勲章から工房・地図・編成・募集・キャラクター詳細へ移動する。戦闘能力や通貨の報酬は付けない。

定義は `src/content/medals.json`、達成判定・保存契約は `src/domain/medals.ts`。`check:content` が参照先と前提の循環を検査する。表示は共通Button・Modalと単一の勲章バッジを使用する。

## 記録と引き継ぎ

製作完了数、発灯・消費灯力、現在の加工品・設備、確定済みの踏破と会話は既存の保存から評価できる。加工品を後から使っても獲得した勲章は失わない。

固有の戦闘条件は新しい探索から観測する。ラウンドなどで生成されたイベントを1回だけ検査し、演出の再生では数えない。観測は乱数・ダメージ・行動順を変更しない。原則として報酬の獲得確定時だけ探索中の証跡を永続化する。全滅・撤退では固有戦績を確定しない。前提勲章がまだなくても、確定した証跡は保存し、前提の獲得時に解放する。

過去の集計には個々のスキルの使い方が残っていないため、昔の戦闘で固有条件を達成したと推測して授与しない。旧版の探索途中セーブには途中から証跡を捏造しない。終了時に直接分かる全員生存などは、確定時に判定できる。

例：狼が基礎定数の高いボスを倒して生還、エレインがHP25%以下を50%以上へ回復、リオラが瀕死の仲間をかばって全員生還、ノエルが全体攻撃で2体同時撃破、セリスが貫通技能でボスを撃破。定数1.5以下4体による塔攻略では、内部表現が10倍整数であることに注意する。

戦闘の証跡は探索スナップショットに、確定済み証跡・勲章・目標・称号は通常セーブに含まれ、再開とバックアップに対応する。
