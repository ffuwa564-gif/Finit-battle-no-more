# 名将と低レア軍：対象選択を乗っ取る指揮システム会議

前作「神話と物語から考える、次のスキル会議」に続く、ずんだもんと四国めたんの研究動画。ユーザーの原案は、味方の選んだ敵を指揮官が強制的に変える効果と、低レアは従いやすく高レア同士はまとめにくい軍制。個の強さと軍の統率に、異なる編成の価値を作れるか検討する。

**全案未実装**。ゲーム本体、セーブ、itch.ioへシステムを追加する変更ではない。開発や追加時期、最終性能を約束しない。固定ゲーム版は `616a0747c4118a991770226d37347f34b31e2ec6`。

## 研究の結論

- 現行AIも通常攻撃は集中しやすい。高レア軍だけをわざと分散させて、現行ゲームの勝利証明にしない。
- 新案の核は、技能を本人に選ばせたまま、通常攻撃を含む敵単体の通常行動の宛先へ介入する権限。回復や全体技を勝手に単体攻撃へ変えない。
- レア別ランダム服従は、原案として確率を比較。複数人の重要な一撃を隠れた抽選へ委ねる不快さがある。
- 比較試作は、誰へ届くかを入力時に名指しする固定の指揮容量、ラウンド開始の指令、指揮官の通常一手とLSの席の費用へ絞る。通常25充填は一度付与し、元の手番で二重に行動・充填しない。
- R1／SR2／SSR3／XR4と総枠3は仮の値。XRはこの値だと対象外になり、それも未調整の問題として明示する。
- 元から同じ標的なら変更の追加価値はない。育成後に指揮費用が上がる罰、特定の指揮官＋同じ三人の固定編成、指揮入力の反復も評価する。

## 模型の範囲

`model.py` は現行AIの模倣や実機戦闘ではない。三人の本来の意図A/B/Cを外から与え、Rの一手40、SSR55、同一指揮官の通常攻撃20、CのHP115、全味方の後にCが動く、という仮条件で宛先の配分だけを比べる。

指揮なしR40／SSR55、指揮ありR120／SSR110がCへ向く。両軍に同じ指揮権限を与え、両軍で指揮官の通常20を失う。Rだけが届く窓はHP111〜120の10点。SSRの一手が60なら二人で120となり、容量差だけでは大きな性能差は救えない。元から指揮官も含め全員がCを狙う対照は、同じ関数でR140／SSR185、号令時R120／SSR165と再現する。

目標一体を止める模型から、戦闘全体の勝率・最適編成・実機の低レア救済成功を導かない。防御、状態異常、回復、石、協撃、対象死亡後の再配分は模型へ入れていない。7380の体力閾値・SSR出力の組合せを計算し、逆転が消える条件も示す。現行技能で自然に生じる意図の競合を有益に解けるかは、今後の実装試験の課題。

## 出典と査読

公式ゲーム資料はBARとZero-K、軍学は英国MODのJDP0-01とクラウゼヴィッツの指定英訳。4系統であり、BARの複数ページを別々の効果実証研究として数えない。資料から希少度別服従の値は導けない。任務型指揮には信頼と裁量があり、盲従や集中の万能性を証明する資料として扱わない。

現行コードと原作の読み直し、外部資料、厳格批評を分担し、固定指揮枠、25充填、境界模型、ノエルの役割速度を改稿した。ノエルはarea_attackerで速度11。支援役13ではない。現行にない一般的な挑発も、既存機能として語らない。

詳細は配布物の `Sources.md`、研究・批評は入力ZIPの `artifacts/command-lab/research/`。外部資料の全文HTML/PDFは再配布しない。新ルールと原作の人物描写を区別する。

## 再編集

制作ソースは `scripts/command-lab/`。Linux、Python3.12、FFmpeg7.1系、Noto Sans CJK、4CPU・16GB RAM。VOICEVOX Engine0.26.0、ずんだもん3、四国めたん2/6。標準のworkerは章を逐次処理する。

1. このソースブランチを用意し、配布のProduction-Inputs.zipをリポジトリのルートへ展開。
2. requirements.txtのPython依存を用意。ゲーム版のpublic内のアートとBGMを使用。
3. `python scripts/command-lab/bootstrap.py` で公式立ち絵を取得し利用規約を確認。公式PNGと単独BGMはZIPに含めない。
4. `python scripts/command-lab/restore_audio.py` でロスレスFLACを24kHz/16bit/mono WAVへ戻す。Speech-Manifest.jsonでPCMフレームのハッシュを検証。WAVヘッダーの差は許容する。
5. `python scripts/command-lab/model.py` で配分結果と自作図表を生成。
6. `python scripts/command-lab/worker.py` で章映像と連続BGMの最終版を生成。
7. `python scripts/command-lab/finish.py` とthumbnail.pyで字幕・台本・チャプター等を出力。
8. `python scripts/command-lab/validate.py` で全編デコード・尺・形式・字幕参照・音量・予定発話間隔を検証。同一ファイルの成功したデコード結果はSHAで再利用する。
9. `python scripts/command-lab/package.py` で入力ZIPを生成。

音声変更時はローカル50021番へVOICEVOXを起動し、古いnarration.jsonを退避してsynth.pyを実行。配布入力だけで再構成する場合は音声エンジン不要。rendererは前作の図解方式を再使用。SEは抽出済みを同梱するため、前作収録の絶対パスは再構成時に不要。

全編動画・字幕・出典・模型・図表・入力ZIPは `downloads/command-doctrine` ブランチへ保存。YouTube用説明文も含めるが、YouTubeへの投稿は行わない。
