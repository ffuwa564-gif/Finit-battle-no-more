# 戦術判断を必要にする難度調整

2026-10-31。設計・批判/操作感・バランス・テストを別担当で検討した。改修前はSSR4人と物語覚醒4人が、調べた通常・イベント・女神の試練9ルートを各20seedとも薬なしで踏破していた。一方、初期編成には既に覚醒級で敗北があるため、全員への一律弱体化や全敵HPの大幅増加は採用しない。

## 実装した対処の選択

- 最初の2探索、初級イベント、短い石集めルートを維持。初期編成で最初の12探索を各20seed踏破できることを確認した。
- 通常の中盤以降を守護・回復・妨害・攻撃の混成にする。第2章以降と上位イベントのボスには護衛を配置し、支援役を倒す順序を考えられるようにする。
- 対応するボスは3ターン周期で大技を予告。直前ターンに実HPを最大HPの8%以上削れば、次の大技が弱まる。障壁への攻撃や護衛への攻撃は累積に入らない。
- 崩す火力が足りなければ、先頭の自己防御、守護・障壁・回復で凌ぐ。手動防御は指示確定時に準備され、速い敵にも間に合うが、通常の一行動を消費する。
- 大技を実行した直後から次ターン末まで、ボスの被ダメージが25%増える。溜めに必殺技を使うか、守って隙に使うかを選べる。
- ボスHPは周回時間と8%の到達可能性を考えて抑え、攻撃倍率と護衛を段階調整する。キャラクター本体や取得済みガチャの能力は変更しない。

予告はボスが奥にいる場合も既存の帯で表示する。長い説明を戦闘操作パネルへ追加せず、妖精ガイドと章ヒントに対処を記載する。旧セーブ・確定済みリプレイ・所持素材は保持する。

## 比較条件と結果

seed 1〜20。初期編成はエレイン/リオラ/セリス/ノエル、SSRはノクス/アテナ/セレネ/アマテラス、覚醒編成は物語初期4人の覚醒。手動方針は公開予告からボス集中・防御・使用可能な必殺技を選ぶ汎用ヒューリスティックで、最適攻略を意味しない。対照では両方とも同じ条件で薬を最大5個、HP45%未満で使用する。

| 編成・場所 | オート＋薬 | 判断あり＋同条件の薬 |
| --- | ---: | ---: |
| SSR・ルネット覚醒級 | 13/20 | 20/20 |
| 物語覚醒・ルネット覚醒級 | 14/20 | 20/20 |
| SSR・九尾覚醒級 | 10/20 | 11/20 |
| 物語覚醒・九尾覚醒級 | 4/20 | 4/20 |

ルネットでは手動判断による差を確認できる。九尾は編成と回復資源の影響が強く、読みだけの効果とは評価しない。初期編成の白の玉座は薬なしオート0/20、薬と手動あり16/20だが、この差にも薬の影響が含まれる。SSRが通常ルートを快適に周回できる強さは残す。

ガチャ不要の攻略例として、通常葛葉を先頭に、覚醒リオラ/エレイン/セリス、リオラをリーダーにした編成を確認した。seed 1の九尾覚醒級を公開情報からの指示と薬で踏破し、実アプリケーションのコマンド経由で覚醒核を獲得する回帰テストを残す。無料編成の全seed必勝を保証するものではない。

再検証は `npm run balance:difficulty -- controls`（同じ薬条件）、`-- early`（序盤12探索）、`-- current`（3編成×9ルート）で行う。出力は `artifacts/difficulty-balance/`。基準値・改修後・序盤・同薬条件の結果は `docs/reports/difficulty-*.json`。改修前の基準はコミット `087f031` で取得した。敗北と外部シミュレータの打切りを区別しており、今回の計測に外部打切りはない。


## 第3章以降の追加引き上げ

ユーザーの「第3章から難しすぎるくらいに」という要望に合わせ、本編第1・2章とイベントは維持し、第3・4章を再調整した。第3章の通常ボスはHP1200〜1500%、攻撃500〜650%、章末はHP1600%・攻撃650%。予告大技は260〜300%、発動後の隙は被ダメージ+30%。護衛、溜め崩し8%、準備防御のルールは共用する。キャラクター本体・所持品・解放履歴は変更しない。

第4章の樹海はHP1500%・攻撃650%のボスと回復・妨害役。ザクロはHP1200%・攻撃170%と護衛2体を持つ。元の定数2.8の全体攻撃があるため攻撃倍率を単純に650%へ揃えず、開幕の回避不能な全滅を避けつつ継戦と予告への対応を要求する。追憶素材の周回先は育成用に維持する。

再測定は `npm run balance:difficulty -- chapter3`。seed 1〜20、両方同じ薬条件で比較。指示ありでは仲間の必殺技も合法なゲージ100%時に予約する。先頭をアテナにしたSSR編成は第3章入口がオート8/20勝・指示20/20勝、最後の観測所が0/20・2/20、白の玉座が0/20・5/20。先頭リオラの物語覚醒4人は玉座0/20・2/20。編成例をエヴリン/アストライア/セレネ/弁財天へ変えると玉座は指示17/20勝となり、継戦・先頭耐久・全員の必殺技の重要度が増した。最適攻略や全編成の踏破を保証せず、後半は相性が悪いとほぼ突破できない水準を意図している。

詳細は `docs/reports/difficulty-chapter3-hard.json`。先の通常ルートの勝率表は追加引き上げ前の記録であり、現在の第3・4章には適用しない。報酬・ストーリー・保存互換のテストは維持し、旧オート必勝条件は公開予告・回復薬・必殺技を使う攻略例へ更新した。
