# 戦術判断を必要にする難度調整

2026-10-31。設計・批判/操作感・バランス・テストを別担当で検討した。改修前はSSR4人と物語覚醒4人が、調べた通常・イベント・女神の試練9ルートを各20seedとも薬なしで踏破していた。一方、初期編成には既に覚醒級で敗北があるため、全員への一律弱体化や全敵HPの大幅増加は採用しない。

## 実装した対処の選択

- 最初の2探索、初級イベント、短い石集めルートを維持。初期編成で最初の12探索を各20seed踏破できることを確認した。
- 通常の中盤以降を守護・回復・妨害・攻撃の混成にする。第2章以降と上位イベントのボスには護衛を配置し、支援役を倒す順序を考えられるようにする。
- 対応するボスは3ターン周期で大技を予告。直前ターンに実HPを最大HPの8%以上削れば、次の大技が弱まる。障壁への攻撃や護衛への攻撃は累積に入らない。
- 崩す火力が足りなければ、先頭の自己防御、守護・障壁・回復で凌ぐ。手動防御は指示確定時に準備され、速い敵にも間に合うが、通常の一行動を消費する。
- 大技を実行した直後から次ターン末まで、ボスの被ダメージが25%増える。溜めに必殺技を使うか、守って隙に使うかを選べる。
- ボスHPは周回時間と8%の到達可能性を考えて抑え、攻撃倍率と護衛を段階調整する。キャラクター本体や取得済みガチャの能力は変更しない。

予告はボスが奥にいる場合も既存の帯で表示する。長い説明を戦闘操作パネルへ追加せず、妖精ガイドと章ヒントに対処を記載する。旧セーブ・確定済みリプレイ・所持素材は保持する。

## 記憶石のTierと上位個体

TierはキャラクターのSSR/XRとは独立した、記憶石の項目ごとの品質。効力・特性値の旧raw 0〜100は性能・ID・保存形式を変更せず、0〜33=T1、34〜66=T2、67〜100=T3と表示する。新しいT4は120〜139、T5は160〜179で、帯の隙間は不正データとして拒否する。効力はT3最高250%、T4は280〜308.5%、T5は340〜368.5%。特性だけがT5の石もあるため、一覧のTierは最高項目、詳細は両項目を表示する。単純なTier番号だけで装備の強さを断定しない。

通常製作・通常調律はT3まで。探索で得た上位項目の調律は同じTier帯の中だけで行い、もう一方の項目を保持する。上位の特性があるから効力も上位へ調律できる、という仕様ではない。候補採用前の保存・バックアップ復元にも同じ契約を適用し、通常→上位、上位→別Tier、両項目同時変更を拒否する。既存の合法な調律候補は引き続き復元できる。

上位率と注目石は `src/content/gem-loot.ts` のコンテンツ設定をドロップと入手先UIで共有する。上位Tierは対応する最終Waveの石だけで、道中・初回保証・腕試しからは生成しない。率は石を入手した条件下で、効力と存在する特性のそれぞれに独立適用する。注目石は40%の分岐で選び、残り60%は従来プール（ボス限定石12%を含む）を使う。したがって注目石の実入手率は40%ではなく、石の出現率と従来プールの重複分にも依存する。塔以外の第2章以降・イベント上級以降にもT5経路を持つ。

巻戻し・星炉は既存の効果上限を維持し、効力T4で再使用間隔-1、T5で-2。夢織は全Tierで旧CD4を維持し、効力T4使用時に自己必殺ゲージ+15、T5は+30を通常行動の充填に加える（成否不問、実行1行動につき1回、上限100）。星炉のHP消費、巻戻しが記憶石のCDを短縮しない制約、睡眠のボス成功率・1行動制限・回復後耐性は維持する。特性Tierが高いだけでは技のCDや追加充填は変わらない。

排出の再測定は `npm run balance:gem-tiers`。各入手先10万seed、初回保証を除く最終Wave抽選の記録は `docs/reports/gem-tier-drops.json`。石燐の泉/短い周回路ではT4個体が約5.45%/抽選（平均18.4周、95%到達54周）、ルネット覚醒級はT4約21.08%・T5約3.59%。これは品質個体の出現であり、欲しい技/変種/項目の更新率や実プレイ時間ではない。上位が出ても現在装備の更新とは限らず、面白さや必要周回数の最適性は未測定。

戦闘比較は `tsx scripts/balance-gem-tier-combat.ts --seeds=5`。旧最高・T4下限・T5上限で同じ編成/技/変種/seedを比較し、複数星炉と複数睡眠の負荷編成も含める。結果は `docs/reports/memory-gem-tier-combat.json`。比較用に石を与えた固定方策であり、入手時間・最適解・全編成のバランスを保証しない。単発のダメージ比較だけでなく、20ラウンドの再使用・必殺・ボス拘束もテストする。敵や塔の既存の難度係数は変更しない。

実装レビューでは、初案のT4最低251.5%（旧最高との差0.6%）を却下して性能差を確保し、上限支援技の偽更新をCD差へ変更した。次のレビューで保存pending経由の上位製造を発見し、保存/直接採用の両境界に検証と回帰テストを追加した。再レビューで入手先のTier上限だけでは率差が読めない点を修正し、条件付き確率を表示した。スマホ320px英語と390px日本語の装備・調律・再読込をブラウザ検証する。第4回の戦闘再レビューでは、夢織のCD短縮でAIも攻撃機会を減らし遅くなる結果を確認したため、睡眠だけCDを旧値へ戻し、使用時の自己ゲージ追加へ変更した。「制御を選べるから問題なし」という評価も修正し、再比較する。

最終比較のrevisionは `sleep-power-charge-v2`、210条件×5seed=1050戦。同じseedで双方勝利した攻撃＋障壁53戦は旧最高10.40→T4下限9.92→T5上限9.47ラウンド。夢織AI構成の旧最高とT5双方勝利49戦は15.65→14.73ラウンド、総勝利50/70→53/70。AIの耐性/既存異常への空打ちは0、ボスの連続睡眠スキップは最大1。これは固定方策の標本比較で、T4/T5による全seedの勝率単調性は保証しない。

上位の巻戻し・星炉・夢織は同Tier内の効力再抽選で実効CD/充填/成功率が変わらないため、管理UIの効力調律を無効にして理由を表示する。追加特性の調律は可能。旧pendingとドメインコマンドの互換性は維持する。
