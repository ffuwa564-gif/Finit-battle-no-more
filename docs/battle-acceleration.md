# エオスのリーダースキル「曙の加速」

全戦闘での自動適用を廃止し、通常姿のエオス（eos-standard）か和装のエオス（eos）をリーダーにした場合だけ発動する。通常姿は両ガチャの共通R、和装は和装ガチャのR。既存所持者にも自動で新しいリーダー効果が付く。所持だけ・非リーダーの編成では発動しない。速度・行動回数・演出速度は変更しない。

- リーダーが生存している間だけ敵味方双方へ適用し、倒れた直後から両陣営の上昇分を解除する。同じターンの後続攻撃にも残さない。
- 各Waveの1ターン目は補正なし。2ターン目から攻撃力を1ターンにつき5%加算する。5ターン目は+20%、21ターン目は+100%。上限は設けない。
- 基礎攻撃力 × (1 + 加速率) × 既存の攻撃強化倍率を丸めてから、攻撃スキル倍率や防御・かばう・障壁・リーダー効果を解決する。
- 通常攻撃、単体・全体・貫通・吸収などの攻撃スキル、混乱・魅了による攻撃、章末の大技、ルネットのビット射撃に適用する。吸収回復は増えた実ダメージに連動する。
- 単体・複数回復、浄化による回復、再生、回復薬、障壁の生成量、最大HP・防御・素早さは加速で増やさない。通常の攻撃強化スキルによる既存の回復・障壁補正は維持する。
- Waveが変われば1ターン目へ戻り、敵味方とも補正なしから始める。長期戦で回復だけを続ける編成は危険が増す。

`src/domain/acceleration.ts` の加算率を攻撃計算に適用する。ユニットの基礎攻撃力や一時強化欄を書き換えないため、浄化・強化解除の対象にならず、複利や二重適用も発生しない。セーブのフィールドは増やさず、選択リーダーの効果・生存と、既存のWave内ラウンド数から算出する。旧セーブの進行中探索も、次に解決するラウンドから新しい発動条件を使う。保存済みのイベント・HP差分はそのまま再生し、再計算しない。

戦闘中の加速テキスト・発動者・説明欄は表示しない。加速の数値を操作パネルへ渡すAPIと表示専用CSSも削除し、説明用の空白を残さない。スキルの仕組みはパーティ・キャラクター詳細・遊び方で確認できる。ダメージ倍率とWaveリセットなどの戦闘ルールは維持する。

常時表示の説明文を戻さない方針はルートの `AGENTS.md` に明記。`e2e/acceleration.spec.ts` はエオスの加速が有効な戦闘でも加速欄が出ないことを、日本語・英語、ラウンド進行・Wave切替後に確認する。

## 確認

- `tests/acceleration.test.ts`：1・2・5・21・41ターン目での両陣営の実ダメージ、基礎値非変更、攻撃強化との合成と防御計算、障壁、回復・薬・最大HPの非増加、セーブ・再生・Wave移行、非リーダー・死亡時の不発、ターン中の死亡による即時解除、両ガチャからの実取得とリーダー設定。
- `tests/campaign.test.ts`：章末の大技にも適用（加速リーダー不在の3ターン目、基礎攻撃100、威力280%なら280ダメージ）。
- `tests/events.test.ts`：通常仲間と通常葛葉による覚醒級踏破を引き続き確認。
- `e2e/acceleration.spec.ts`：加速テキストが表示されないこと、スマホでの実ダメージ、ラウンド進行・Wave切替、英語。既存の探索・報酬・章進行とitch埋め込みのテストも実行。
- `docs/reports/chapter-balance.json`：エオスを使わない各編成は加速なしでの各章末・20シードの結果へ更新。加速を使う場合は、回復主体の長期戦で不利になることがある。
