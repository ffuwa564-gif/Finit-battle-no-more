# 共通パッシブスキル「加速」

全ての戦闘で、敵味方の全員に自動で適用する。編成・所持・発動操作は不要。速度・行動回数・演出速度は変更しない。

- 各Waveの1ターン目は補正なし。2ターン目から攻撃力を1ターンにつき5%加算する。5ターン目は+20%、21ターン目は+100%。上限は設けない。
- 基礎攻撃力 × (1 + 加速率) × 既存の攻撃強化倍率を丸めてから、攻撃スキル倍率や防御・かばう・障壁・リーダー効果を解決する。
- 通常攻撃、単体・全体・貫通・吸収などの攻撃スキル、混乱・魅了による攻撃、章末の大技、ルネットのビット射撃に適用する。吸収回復は増えた実ダメージに連動する。
- 単体・複数回復、浄化による回復、再生、回復薬、障壁の生成量、最大HP・防御・素早さは加速で増やさない。通常の攻撃強化スキルによる既存の回復・障壁補正は維持する。
- Waveが変われば1ターン目へ戻り、敵味方とも補正なしから始める。長期戦で回復だけを続ける編成は危険が増す。

`src/domain/acceleration.ts` の加算率を、攻撃計算と戦闘操作パネルで共有する。ユニットの基礎攻撃力や一時強化欄を書き換えないため、浄化・強化解除の対象にならず、複利や二重適用も発生しない。セーブのフィールドは増やさず、既存のWave内ラウンド数から算出する。旧セーブの進行中探索も、次に解決するラウンドから適用する。保存済みのイベント・HP差分はそのまま再生し、再計算しない。

戦闘操作パネルに「加速：敵味方の攻撃 +N%」とWave切替でのリセットを常時表示する。演出中は解決したターン、操作待ちでは次に実行するターンの上昇率を表示する。毎ターンのトーストは追加しない。日本語・英語対応。ホームの「遊び方」にも説明を追加する。

## 確認

- `tests/acceleration.test.ts`：1・2・5・21・41ターン目での両陣営の実ダメージ、基礎値非変更、攻撃強化との合成と防御計算、障壁、回復・薬・最大HPの非増加、セーブ・再生・Wave移行。
- `tests/campaign.test.ts`：章末の大技にも適用（3ターン目、基礎攻撃100、威力280%なら308ダメージ）。
- `tests/events.test.ts`：通常仲間と通常葛葉による覚醒級踏破を引き続き確認。
- `e2e/acceleration.spec.ts`：スマホでの表示・実ダメージ、演出中と次ターンの区別、Wave切替、英語。既存の探索・報酬・章進行とitch埋め込みのテストも実行。
- `docs/reports/chapter-balance.json`：加速適用後の各章末、各編成20シードの結果へ更新。回復主体の編成ほど長期戦で不利になることがある。
