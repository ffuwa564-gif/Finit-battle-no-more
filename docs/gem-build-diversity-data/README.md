## T6の追加特性を含む塔の追試

技効力239・追加特性239の4石。攻撃石に慈雨、支援石に庇護を付けた。主実験の「追加特性なし」と予算が異なるので混ぜない。各編成は同じ開発用8シードで再選定し、同じ確認用200シードで比較。確認用シードの再利用を含む探索的な追試であり、厳密な独立認定には未使用シードによる追認が必要。

|---|---|---|---:|---:|---:|---:|

|high|astraea, athena, selene, nox|athena|21/200|12.00|0.87|8.0%|

純粋な技効力だけを高くした候補では塔が両群0/200。追加特性も含めると攻略できる例が出た。これを「全員の実用性が証明できた」「全SSR/XR最適編成に勝った」と扱わない。

各勝率のWilson区間はJSONに保存。区間は個別推定で、多重比較を補正した全体認定ではない。結果は有限候補と掲載方針に依存し、キャラ固有能力の不可代替性はこの比較だけでは認定できない。

## 回帰検証

- 単体986件を一括実行して通過（`vitest --maxWorkers=2`）。
- 追加の旧版実ソース由来golden replay 6件が完全一致。合計992件。
- 型検査、コンテンツ・UI・日英翻訳ゲート、Vite本番ビルド通過。
- 対象ブラウザー検証13項目を確認。320px英語の初回OPフェード待ちが負荷集中時に5秒でタイムアウトし、単独再実行では通過。その他12項目は同一実行で通過。
- 新しい宝箱操作テストは、探索の強化カードを実際のUIで閉じてから原石を開く。
- `balance-gem-diversity.ts --verify` で凍結した36ケースを最終ソースへ照合し、全項目一致。

旧SSR耐久編成など、能力再配分により同じ装備で勝敗が変わる例もある。全既存ビルドの再認定は未完了。公開版へのマージ・itch配信は行っていない。

生の全シードは `results.json.gz` と `endgame-tower.json.gz`。`gzip -dc ファイル名` で読めます。`experiment.json` に最終ソースのSHA-256を記録しています。
