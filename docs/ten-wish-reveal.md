# 10連祈願の演出

抽選・消費・還元・所持・天井は既存のコマンドで保存し終えてから演出を開始する。演出は保存済みの結果を元の順番で見せるだけで、再抽選や結果の変更は行わない。

- 約2.2秒：10個の星と祈願の門が集まって開く。金色は実際のSSR・XR結果が含まれる場合だけ使用する。
- 10枚の封印されたカードが順に開く。通常240ms、SR450ms、SSR・XR900msの間を取る。
- SSR・XRは既存の全身立ち絵・粒子・レアリティ・名前の顕現へ切り替え、迎える／閉じる操作で次のカードへ進む。
- 全カードを見せた後は従来の10体一覧・還元合計へ戻る。開封済みカードはいつでも詳細を見直せる。
- 開始演出と顕現中から「結果をまとめて見る」で一括表示できる。閉じても既に保存された結果・消費を変更しない。
- ゲーム設定またはOSの動きを減らす設定では、開始演出・順次開封・自動顕現を省き、最初から一覧を表示する。単発祈願は既存演出を維持する。

`e2e/ten-wish-reveal.spec.ts` は実際の10連コマンドで、開始→開封→SSR→一覧、開始／SSRからのスキップ、詳細の再表示・再読込後のセーブ一致、OSの動作軽減を確認する。既存の単発・機巧10連テストも維持する。
