# 状態異常

混乱・睡眠・麻痺・魅了を、味方と敵で共通の戦闘処理として実装。スキル説明、状態アイコン、残り行動回数、成功／防止／行動失敗／解除のログは日本語・英語に対応する。

| 状態 | 行動への影響 | 主な使い手 |
| --- | --- | --- |
| 混乱 | スキルを使わず、50%で味方（自分を含む）、残り50%で敵への通常攻撃 | セオリツヒメ |
| 睡眠 | 行動不能。HPダメージで解除。障壁で全量吸収した攻撃では目覚めない | ペルセポネ（和装）、月翅の蛾 |
| 麻痺 | 自分の行動ごとに40%で行動不能。それ以外は通常通り判断 | ミヅハノメ、虚ろの守り手 |
| 魅了 | スキルを使わず、自分以外の味方への通常攻撃。単独なら行動不能。付与者が倒れると解除 | アメノウズメ、荊の魔女 |

通常対象への付与率70%、持続2回の行動。ボスへの付与率35%、持続1回の行動。再使用4ラウンド。強さの定数で付与率を隠れて増減させない。既存の役割必須スキルと2スキル制約を維持し、第2スキルを置き換える。葛葉とルネットの固有能力は維持する。

## 解除と対策

- 浄化は4種類と防御低下をまとめて解除し、従来通り小回復する。エレイン・フローラなどが利用できる。重傷者への回復の後、状態異常を持つ味方の浄化を優先する。
- 自然回復・浄化・被ダメージによる覚醒・付与者の戦闘不能による魅了解除の後、次ラウンド終了まで4種類への状態耐性を付与する。防御低下はこの耐性の対象外。
- AIは既に状態異常のある相手や状態耐性中の相手へ重ねて付与しない。通常の単体攻撃は、他に狙える敵がいれば睡眠中の敵を避ける。全体攻撃・混乱・魅了による攻撃は睡眠を解くことがある。
- 状態異常の付与時には対象のかばうを解除する。他の味方からかばわれることは可能。
- 同時に複数状態が記録されている場合は、魅了の付与者の生存確認→睡眠→麻痺の判定→魅了→混乱の順で行動を決定する。残り回数はスキップした場合も含め、自分の行動のたびに減る。
- 戦闘不能時と次Wave開始時に状態を除去する。回復や継続回復だけでは睡眠は解除しない。クールダウンは行動失敗中もラウンドで進む。
- ルネットのビットは独立した機械なので、本体の状態異常中も既存の展開・射撃周期で動く。ボス撃破で停止する。

## 保存・再生

`Unit.ailments` に種類別の残り行動回数（1〜2）と付与者UID、`statusWardUntil` に耐性の期限ラウンドを保存する。どちらも省略可能で既存セーブは読み込める。付与者が倒れてもそのWave内では死体のUIDを保持しており、魅了解除の確認に使う。

`BattleEvent.ailment` と `statusAction` は付与・抵抗・行動失敗・回復・同士討ちのメタデータ。種類は既存の攻撃／弱体／強化を使用し、共通の演出・HP差分表示・効果音に接続する。状態スキル4種には追加の合成SEを割り当てる。状態異常に関する乱数も保存済みseedから抽選し、再生・再読み込みは結果を再計算しない。

セーブ検証では未知の状態、無効な残り回数、空の付与者、戦闘に存在しない付与者を拒否する。状態異常のない既存の戦闘履歴もそのまま再生できる。

## 検証

`tests/ailments.test.ts` は実際の4スキルの付与率と持続、ボス耐性、行動失敗、敵味方を含む対象選択、HPダメージと障壁の区別、浄化、再付与防止、保存と再生、Wave切り替え、英語ログを検証。`e2e/ailments.spec.ts` はスマホでの4種類の表示、行動失敗のトースト、再読み込み、英語の状態説明とスキル詳細を検証する。

`docs/reports/ailment-balance.json` は均衡作戦・薬5個・HP65%未満で使用、各20シード（1〜20）の試行。initialは初期4人／リオラリーダー、ordinaryはエレイン・帳の巫女・リオラ・通常葛葉／リオラリーダー、SSRはコノハナサクヤヒメ・イザナミ・アマテラス・通常葛葉／イザナミリーダー。通常の序盤と、両イベントの初級・覚醒級を確認。過去のイベント実装時のレポートは当時の条件を記録したまま保持する。
