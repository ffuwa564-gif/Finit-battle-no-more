# 枠を訪れる白銀の妖精

実ターンの再生が終わって作戦を選べるとき、18%で左右いずれかの縁へ1人だけ出現します。出現した判断待ちのターンを含む3ターン滞在し、使わずに進めても不利益はありません。ウェーブ移動・戦闘終了・撤退で退場します。

タップすると生存中の味方全員の必殺ゲージが15ポイント増えます（上限100）。準備済みの必殺予約は維持し、ターン、敵の行動、回復薬、クールダウン、戦闘乱数は進めません。再生中には触れず、祝福の再生中はふわっと消えて味方側へ淡い光を送ります。効果音は既存の柔らかい回復音を1回使います。

出現抽選は花・戦闘と独立した保存済み乱数です。同じターンでの再読み込みや花の採取では再抽選しません。古いセーブには任意項目 `fairies` がないままでも対応します。

## 素材

ユーザー依頼で生成した白髪・青銀の衣装・蝶の羽を持つオリジナル妖精。生成シートから分離した左右向き原画をRunwayで各5秒アニメ化しました。白髪・顔を消す自動背景除去の結果は採用せず、生成動画のインク輪郭から白い内部領域を残す動画マットで透過しています。

- 右向き動画: `223bf745-59a5-4f5b-ba9e-0fa5b863585d`。左の縁に配置、12fps、約9.83秒の往復ループ。
- 左向き動画: `40d7952f-9487-4435-9713-802ef87b8edd`。右の縁に配置、羽先が収まる3〜5秒を採用、12fps、約3.83秒の往復ループ。
- 各512×512透過WebPと静止PNGを `public/art/living-garden/fairy-facing-*` に同梱。
- ゲーム内の動き軽減、OSの動き軽減、通信量節約、非表示、画面外、モーダル表示時は静止画へ切り替えます。アニメが読めなくても静止画からタップできます。

今回の実装では追加の有料生成はしていません。itch.ioへのアップロードは別途、確認済みの版を指定する公開手順で行います。
