# 通常攻撃・スキルの効果音

通常戦闘の攻撃・回復・防御に、短い専用の合成音を追加した。`combat-audio.ts` の9系統を使用し、必殺技の8種類とは波形・音量・尺を分ける。戦闘結果、スキル効果、BGM設定は変更しない。

| 系統 | 音の特徴 | 尺 |
| --- | --- | --- |
| attack | 中域の打撃、短い風切り、金属の芯 | 380ms |
| pierce | 細い風切り、急降下する共鳴 | 340ms |
| shatter | 細かい破砕と低い打撃 | 580ms |
| area | 広がる空気と衝撃の本体 | 680ms |
| drain | 吸い込まれる共鳴と暗い摩擦 | 620ms |
| dawn | 明るい範囲攻撃の響き | 720ms |
| heal | 柔らかな共鳴と空気 | 680ms |
| guard | 短い盾の打撃と金属面の響き | 430ms |
| barrier | 柔らかく立ち上がる透明な共鳴 | 650ms |

`regen` / `mend_pair` / `barrier_mend` / `cleanse` はheal系統、通常guardとbarrierは各系統へ割り当てる。未変更の補助・状態異常・波の切替などは従来のToneレシピを使う。必殺技の指定は通常スキルのtemplateより優先する。

3種類の小さな音程・質感の違いを順に使い、同じ素材の連打感を減らす。ゲームの乱数やセーブへ干渉せず、系統ごとのローカルカウンターを使う。波形は初回使用時に生成・キャッシュし、上限は9系統×3種類。基本のattackだけ最初に1種類を用意する。

ピークは通常攻撃0.53、強い攻撃0.60、回復0.36、結界0.42を上限に整え、必殺技の主打撃0.83より控えめにする。素材のピーク差は知覚音量の差と同一ではないため、実際の画面とBGMでの試聴も必要。全素材は800ms未満で、最速の通常行動950msより短い。短い反射以外の長い残響は重ねない。

再生はnative AudioBufferを使い、通常の打撃にもToneの115ms先読みを加えず、数字・動きにすぐ追従する。共通SEゲインとリミッターを通り、ミュートは残音にも効く。連続発音は6本を基本上限とし、入れ替え時に未開始の古い音は即時取消、開始済みの音は8msで減衰する。最終出力には0.88以下をそのまま通すピーク保護を置き、コンプレッサーの立ち上がりで生じる瞬間的な過大出力だけを抑える。

試聴用WAVは `npm run preview:combat-audio` で `artifacts/combat-audio/` へ出力する。ゲームで使うものと同じ生成関数・通常バリエーション0の波形。自動検査では22.05/44.1/48kHzの有限性・音量階層・尺・端点、3種類の再利用、native再生予約、スキルの振り分け、連打上限、実出力ピークとミュートを確認する。iPhone実機での音質を自動検査が保証するわけではない。
