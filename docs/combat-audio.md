# 通常戦闘音の重量感とバリエーション

通常戦闘の9系統は、各3種類、計27パッチを持つ。以前の音程約3%の違いから、発音源・材質・破片のリズム・共鳴・減衰の異なる構成に変更した。`combat-audio.ts` の `combatTakes` が名前と材質、尺、基音、重量成分を管理する。

| 系統 | バリエーション |
| --- | --- |
| attack | 一閃／重打／破裂 |
| pierce | 鋼の刺突／放電する貫通／装甲への刺突 |
| shatter | 砕裂／岩砕き／結晶破砕 |
| area | 爆発／重なる衝撃波／奔流 |
| drain | 吸引／脈動／侵食 |
| dawn | 光の炸裂／光線／陽光の波 |
| heal | 鐘の癒し／癒しの風／清水 |
| guard | 鉄盾／木盾／石壁 |
| barrier | 結晶の壁／柔らかな結界／脈動する結界 |

## 重さの作り方

通常攻撃は、以前の短いノイズ・減衰する低音に、200〜1,000Hz付近の衝突音と倍音を持つ本体を加えた。重打は飽和させた下降音と長めの本体、一閃は風切りと鋭い共鳴、破裂は不規則な細かい砕け音を組み合わせる。破片や反射音は1回の命中の余波として扱い、戦闘のヒット数やダメージは変えない。

標準攻撃の素材ピークを0.53から0.70へ、範囲／破砕を最大0.74へ変更。回復0.48、結界0.54は穏やかにし、必殺技の主打撃0.83を下回る。音量の増加に加えて、重打・破砕は中低域の持続を増やしている。各素材の尺は520〜880msで、通常の最速行動950msの中に収める。

44.1kHzの素材の先頭200msを分析したRMSは、旧attackが0.096、一閃0.180、重打0.238、破裂0.238。150〜1,100Hzの無補正エネルギー割合は旧25.0%、一閃31.4%、重打67.1%、破裂41.7%。これは音の質や「体感の重さ」の点数ではない。スマホやBGMと合わせた試聴を行う。

## 再生と割り当て

同じキャラの攻撃で違いが巡るよう、AppからactorIdを渡し、キャラ×系統ごとに3種類を順に使う。他の敵や味方の行動でカウンターが進まない。試聴などactorIdのない呼び出しは独立した共通ストリームを使う。カウンターは64ストリーム以内、波形キャッシュは9系統×3種類以内。ゲームの乱数・セーブ・戦闘計算には干渉しない。

`regen` / `mend_pair` / `barrier_mend` / `cleanse` はheal系統を共有する。対象外の補助・状態異常などは従来のToneレシピを使う。必殺技のパッチ・演出は維持し、通常スキルのtemplateより優先する。

native AudioBufferによる即時再生、共通SE音量、リミッターと過大ピークの保護を継続。連続発音は6本を基本上限に、未開始の古い音は即時取消、再生中の古い音は短く減衰する。BGM設定に触れない。

## 比較と検証

`npm run preview:combat-audio` は `artifacts/combat-audio/` に各系統の3種類を全て書き出す。`attack-1.wav` などの単体音、0.35秒の無音を挟む `attack-comparison.wav`、一覧の `index.html` を生成する。互換用の `attack.wav` などはバリエーション1と同じ。前回のように試聴が1種類だけになることを避ける。

自動検査は、サンプルレートごとの有限性・ピーク階層・端点、重打と一閃の帯域および持続の違い、材質の切り替わり、キャラ別の独立カウンター、キャッシュ再利用、連打上限、出力ピーク・ミュートと配布用iframeを対象とする。波形が違うことだけで聴感の品質を保証せず、人間の視聴確認は引き続き必要。
