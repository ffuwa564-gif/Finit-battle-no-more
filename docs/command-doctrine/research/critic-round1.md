# 続編会議・独立第一査読：統率軍と強者の烏合の衆

対象：ユーザーの新案「味方の選んだ敵を強制変更する指揮。高レア同士は従いづらく、低レアは従いやすい」。ゲーム基準は `616a0747c4118a991770226d37347f34b31e2ec6`。本稿は未実装案の研究で、ゲームコードを変更していない。

## 残したい核

**一人ずつの出力の大きさとは別に、集団で必要な一手をそろえる価値を作る。** 低レアに同じ大きな倍率を配って高レアを追い越させる話ではなく、誰をいつ同じ敵へ向かわせるかで局面が変わる話にしたい。

ただし「指揮がなければSSRは馬鹿な標的へ散る」と既存AIを書き換えて勝たせるのは反証にならない。名将が有能だからではなく、相手を無能にしただけになる。

## 先に守る現行仕様

- `chooseTarget` は既に作戦で寄る。BALANCEDは基本的に低い現在HP、OFFENSEは高い攻撃力、DEFENSEは回復役の優先を含む。同じ敵へ寄る状況は指揮なしでもある。
- 役割には別の対象優先がある。解除は強化中の敵、弱体は未弱体の高HP、状態異常は付与可能な高攻撃力の敵など。違う標的を選んだ時も、必ず誤判断とは限らない。
- 手動の焦点・指示は主に先頭へ作用する。全員へ任意の敵を指定できる現在の機能ではない。
- 仲間の具体的な行動をR入力時に保存する `companionCommitments` は、`dungeon.coordination` がある戦闘でのみ使用する。通常の戦闘では手番時に `chooseAction`。**全ダンジョンで、操作待ちに全員の確定済み標的が見えるとは説明しない。**
- 現行に一般的な「挑発」状態はない。かばうと、今後の挑発案を区別する。
- ウェーブ開始時の条件付き石装備変更は既存。指揮動画で新機能の実装済み証拠に使わない。
- 必殺予約、回復／支援、全体攻撃、状態異常に強制された行動は、それぞれ別の契約。敵への単体技の宛先変更から始める。

参照：`src/domain/engine.ts:chooseTarget / chooseDefaultAction / chooseAction / companionCommitments / plannedAction / damage`、`src/domain/party-orders.ts:orderTargets`、`src/application/game.ts:equipMemoryGem / round`。

## 原案の確率服従は、まず本気で比較する

### 魅力

- 大きな出力を持つが、指定した一点へまとめるのが難しい英雄たちと、出力は控えめでも合図どおり動く兵の対比は分かりやすい。
- 期待値が高い攻撃と、必要な敵を確実に倒す攻撃は同じではない。締切のある予告の妨害など、集中の確実さが価値になる可能性はある。
- 強制変更に成功しなかった味方も、自分の通常判断で有効な一手を使うなら、単純な行動喪失よりは自律性の表現になる。

### 深刻な危険

1. **命令を押した後に理由なく拒否する不快さ。** 必要な場面ほど失敗が痛い。既存AIを補う操作を作ったのに、その操作だけRNGで裏切られる。
2. **レアリティが性格を決める。** ノクスは高レアでも命令の完遂が核。覚醒したセリスは仲間へ道を尋ねる。レアリティが上がるほど協調しなくなるという一律ルールは、人物像や育成の意味と衝突する。
3. **SSRの価値を、失敗演出で削る。** ガチャで得た人物が低レアより使いづらい理由を、毎回「命令無視」と見せると、育成の報酬ではなく罰に感じやすい。
4. **低レアが人格のない命令部品になる。** 誰でも同じ石を持つ安い指揮対象なら、低レアの技能や物語は選ばれず、安い器だけを探す。
5. **確率を盛るための接待敵。** 高レアの通常の強さが十分なら、指揮に従わなくても周囲を早く倒して勝つ。指示した一体の撃破率と、ダンジョン勝率をすり替えない。

### 比較用の小さな確率例

`probability-local-model.json` に、次の**未実装の局所模型**を記録した。実キャラの攻撃値、観測された服従率ではない。

- 両隊とも同じ指揮官＋攻撃役3人。
- 全員の通常の宛先はA。命令先は、合法な別の敵B。
- 例R：一人40の潜在ダメージ、変更成功100%。
- 例SSR：一人90の潜在ダメージ、変更成功50%。失敗しても通常判断のAへ攻撃する。

| 指標 | R3人 | SSR3人 |
|---|---:|---:|
| Bへの潜在ダメージ期待値 | 120 | 135 |
| Bへ110以上のパケットを集める確率 | 100% | 50% |
| 全標的を合わせた潜在ダメージ | 120 | 270 |

SSRはBへの期待値でも上回るが、締切までに110をそろえる確率は下がる。一方で、失敗した攻撃はAを倒す助けにもなるため、**これだけでR軍の方が戦闘に勝つとは言えない。**

120/180/270はHP上限前のパケットで、Bの実HPが110なら実HPダメージは110を超えない。B撃破後の残りの一手は本来の再標的へ戻す必要があり、動画で過剰ダメージをそのまま実HPダメージにしない。

元の通常宛先もBなら、服従の抽選をしない。追加の変更イベントも生まない。その対照条件では、指揮の追加価値はほぼない。

## 修正版の主候補：確定の「指揮枠」を先に占有する

rootとの比較案では、R/SR/SSR/XRの占有1/2/3/4、総枠3を**説明用の初期値**とする。指揮官のレアリティと統率容量は別。

**主模型として推す理由**：誰へ指揮を配るかが入力時に分かる。R3人とSSR1人の選択を、失敗の抽選なしで比べられる。大きな個人出力を一人へ集中させるか、小さい一手を複数そろえるかという元の核が残る。

### 占有と実変更を混同しない

- これは毎回減る通貨ではなく、今Rに指揮できる容量。名指しした味方の枠はR中解放しない。
- その味方がもともと同じ敵を狙った場合も、占有は返さない。ただし「従った」「標的を変更した」という発動回数や追加誘発は0。
- 命令対象が先に倒れた時は通常AIへ戻し、一手を棒立ちにしない。容量の予約を戻して、そのRに別人へ後出し配分はしない。
- 枠3・XR4の模型では、XRは「従いづらい」ではなく**選べない**。将来の統率容量や調整が未定であることを明示。XR永久対象外を、模型の都合のまま最終仕様へ運ばない。
- 変更がなかったからといって、指揮官が払った一手まで返さない。不要な号令を選ばず、普通に動く判断が要る。

## 指令を出す時点：R開始と、本人手番の比較

### 本人の手番から、そのRだけ

**良い点**：現在の速度順の中へ一つの能動技能として収まりやすい。先に動いた人には遡及しない。

**問題**：ノエル11の号令は、剣士14・呪術師15へほぼ届かない。R同士でも速い味方は先に動くため、「高レアだから聞かない」と速度の問題を混同しやすい。速い盾役18などの指揮官だけが固定枠になりうる。

**判定**：速度を代償にする別案として比較する価値はあるが、元の統率軍の核を残す主模型にはしない。

### 明示的なR開始指令で、本人の通常一手を払う

**主模型に推奨。** 現行に既にある操作とは言わず、新しい指令フェーズと表示する。

順番案：R入力をロック → 持続効果の失効処理 → 指令を確定 → 通常の速度順。指揮官の一手は既に使用したものとし、元の手番で再行動しない。追加行動、二度目のゲージ25、二度目の異常減算を作らない。

**境界を先に決める**：
- 指揮官が発令後に倒れても、既に発令した今Rの命令は残す案が明快。次Rは発令できない。これは一Rの技能効果としての契約で、継続LSの生存条件と混ぜない。
- 代案として死亡時に残命令が消える設計もあり得るが、その場合は入力時に分かるリスクとして別模型にする。途中で都合よくどちらへも変えない。
- 指令は通常の一手なので、同じRの本人の必殺・石・回復を追加では使えない。
- 普通の行動として+25を付けるなら一度だけ。いつ付けるかを決め、初期模型では省略した値まで実ゲーム同様と称さない。

### 状態異常の扱いを曖昧にしない

まずは正常な指揮官だけを扱う模型でよい。その模型から、異常込みの実戦を証明したとは言わない。

実装を考えるなら、次のどちらかを明示する。

1. **初期案は四種の異常保持中には発令不可**。確定した可否を入力時に見せ、通常の一手を選べる。これは新しい指令の制限で、現行の麻痺は常に動けないという説明にはしない。
2. **入力ロック後、本人の通常の異常処理を指令フェーズへ一度だけ前倒し**。失敗しても入力待ちへ戻さず、元の手番で再抽選しない。魅了・混乱で別の行動へなる扱いも、指揮だけ無料で残す契約にしない。

「麻痺の結果を見てから号令を取り消し、もう一手だけ通常行動」は抜け道。

## 宛先の優先順位：狙いと、実際の被弾者は別

初期の対象は、通常の敵単体技（攻撃・弱体・解除）の**宛先だけ**。技能の種類や威力、待ち時間は変えない。

| 層 | 指揮との関係 |
|---|---|
| 本人死亡・行動不能・強制行動 | 通常の妨害を指揮で解除しない。魅了・混乱の同士討ちを、攻撃命令で敵への攻撃へ戻さない。 |
| プレイヤーの先頭への明示指示・必殺予約 | 大隊命令で勝手に上書きしない。優先する入力契約として最初に扱う。 |
| 技能の対象資格 | 生存敵等の合法性を守る。回復を攻撃へ、全体を単体へ変えない。 |
| 命令先が有効か | 死亡・退場なら通常の対象優先へ戻す。後から別の敵をプレイヤーが選び直さない。 |
| 通常の対象選好 | ここを宣言した敵へ置き換える。もともと同じなら変更イベント0。 |
| 敵側のかばう | 最後の被弾者は既存のかばうで変わり得る。号令はかばう無視を無料で得る能力ではない。 |
| 障壁・防御・命中等 | その後の通常の処理。軽減や不発で容量を返し、再命令できるようにはしない。 |

**解除・弱体に固有の失敗**：自分のAIは強化中の敵Aを解除しようとしたのに、号令で無強化のBへ変えれば、有効な解除を捨てることもある。技能を攻撃へ自動で選び直す便利さを、宛先変更へこっそり足さない。

**範囲技**：現行のareaは基本的に敵全体。中心・円形・扇形を持つ新しい空間範囲の仕組みではない。全体技は初期指揮の対象外とし、単体へ集中して威力を増す変換は別案とする。

**必殺**：単体必殺も初期指揮からは分ける。通常の予約契約と区別し、「単体だから全部自由に対象変更できる」とまとめない。

**挑発**：現行に一般的な挑発はない。将来案を入れるなら、対象候補の制約を先に適用するのか、指揮とどちらが優先かを明示する。初期比較では除外してよい。かばうを挑発と呼び換えない。

**連鎖・残響**：命令は主たる通常の一手へ一度。既に発射された追撃を毎回同じ敵へ曲げたり、変更回数ぶんゲージを増やしたりしない。指揮対象が変わったことで石の通常の効果が出る場合も、既存の再帰止めを維持する。

## 指揮官が固定枠になる危険

- 一人を使うだけで全員の強い技能が常に好きな敵へ飛ぶなら、名将ではなく基本操作の鍵になる。ほかのリーダーや先頭を選ぶ価値を奪う。
- 対価の一手を払う案では、弱い本人の通常行動を失うだけなら安く、強い指揮官ほど使いにくい逆転もある。統率とレアリティを別にしただけで解決したとしない。
- ボスの単一敵戦では宛先変更に価値がない。そこで号令に大きな火力バフを付けて万能化すると、指揮が必要ない盤面まで固定枠になる。
- 反対に、複数敵戦ならいつでも指揮官が最適という結果なら、味方全員の焦点指定を共通操作にするべきかも検討する。面白い基本操作を特定一人だけへ独占させる設計を疑う。

**比較してほしい編成**：低レア統率軍、高レア自律軍、低レア指揮対象と高レアの大技を混ぜた軍。最後の混成が魅力的になることは、低レアの敗北ではない。低レアを安い指揮枠だけで選ばせず、解除・守り・単体技能の役目を残す。

## 比較模型の最低要件

1. **同じ4枠、同じ敵、同じ条件**。指揮官を三人の兵の外に無料で置かない。指揮官が失う一手を数える。
2. **二段の比較**。同ステータスで制御だけの違いを分離し、その後に現行の実キャラ・実装備の差を入れる。どちらか一方から全体の結論へ飛ばない。
3. **通常AIをそのまま対照に**。BALANCED/OFFENSE/DEFENSEのうち都合の悪い一つだけをSSR軍へ押し付けない。
4. **元宛先が同じ対照**。命令しなくても集まる場合、指揮の変更数は0。ここを無償の成功回数や連携バフにしない。
5. **本当に指揮が欲しい局面と、要らない局面**。予告妨害、強化解除先、単体敵、AOE中心、回復が必要、先に一体倒す方が安全、を比較する。
6. **結果は分ける**。指定敵の撃破率、全体勝率、残HP、所要R、指揮回数、変更件数、実際に無駄だった号令、指揮官の機会費用。
7. **確率案は分布を残す**。平均だけでなく悪い連続不服従、成功しても得がない場面、完全無変更も出す。成功動画だけを選ばない。
8. **枠の初期値を真理にしない**。1/2/3/4・総枠3は比較用。総枠2/3/4等で閾値が急変しないかも見る。XR不可を見落とさない。
9. **追加ルールを一度に混ぜない**。服従率、固定枠、号令開始時点、連携ダメージバフ、訓練値を全部変えると、何で勝ったか分からない。
10. **再現可能なモデル**。全入力、対象選好、判定順、乱数、失効、死亡時fallbackを記録し、未実装の紙上模型と実ゲームを分ける。

## 会議で残したい反論

- 「そのSSRたち、命令しなくても同じ敵を狙っていない？」
- 「指定した敵を倒す確率と、戦闘に勝つ確率は別よ。ほかの敵へ飛んだ攻撃も、無駄とは限らないわ。」
- 「レアになったら協調しない、で人物を決めていい？　ノクスは命令を完遂する人よ。」
- 「低レアを選びたいの？　安い指揮枠を三つ買いたいだけになっていない？」
- 「同じ敵を狙っただけで、号令に成功した回数を稼がせないで。」
- 「遅い指揮官だから届かないのに、英雄が言うことを聞かなかった、と説明しないの。」
- 「名将を一人入れないと普通に狙えないなら、それは個性より操作の鍵かもしれないわ。」

## 第一段階の推奨

原案の確率服従を真面目に比較したうえで、動画の主模型は**固定の指揮枠・入力時の名指し・新しいR開始指令・本人一手の支払い**へ進める。本人手番からの号令は速度の反例として残す。

レアリティの表を完成仕様とせず、人物ごとの一律な反抗性としない。強い個人の自由と、集団をそろえる容易さを、**失敗演出による罰ではなく、入力時に読める配分**へ翻訳できるかが今回の一番よい問い。
