# プレイヤーが予約する必殺技

全キャラクターへ `ultimateFor` から固有名・既存原画のカットインと、役割に応じた6系統の効果を用意する。初期4人・覚醒初期4人・アテナ両形態・セレネ両形態・ルネット両形態・ノクス・フォルトゥナには個別の技名を設定し、他キャラは固有の二つ名と系統名を組み合わせる。レアリティや課金を発動条件にしない。

## 操作

探索開始時のゲージは0。通常の行動（スキルを含む）で25、実際にHPダメージを受けた場合に10を獲得し、100で止まる。障壁で全て吸収した場合・行動不能・混乱や魅了による強制攻撃では対応する行動分を加算しない。ゲージはWaveをまたいで保持し、次の探索ではリセットする。

指示待ちで生存している味方のゲージが100になると、顔枠が金色に光る。枠のタップで発動予約し、再タップで解除。ゲージは予約時には消費しない。複数人を予約でき、作戦変更で予約は失われない。ATTACKを押すと通常の速度順で、そのキャラの行動1回を必殺技へ置き換える。追加行動は与えず、既存の2つの自動スキルとクールダウンは維持する。発動時に100消費し、必殺技自体の行動による25は加算しない。

睡眠・麻痺の行動不能、混乱・魅了は必殺技より優先する。発動できなかった予約はゲージとともに次の指示待ちまで保持する。行動前の戦闘不能では発動しない。Wave切替時には予約だけを解除し、次Waveでの意図しない発動を防ぐ。演出再生中は予約を変更できない。回復薬を選択中は枠のタップで回復し、必殺技の予約を変更しない。

## 効果

| 役割 | 効果 |
| --- | --- |
| 剣士 | 敵単体へ攻撃力280%、防御65%無視。かばうは有効 |
| 詠唱者 | 敵全体へ攻撃力190%、かばう無視 |
| 癒し手 | 生存味方全員の最大HP40%回復、状態異常・防御低下解除。蘇生しない |
| 守護者 | 生存味方全員に各最大HP30%＋発動者防御×2の障壁 |
| 導き手 | 生存味方全員に攻撃40%強化＋各最大HP15%の障壁 |
| 呪術師 | 敵全体へ攻撃力150%の攻撃後、防御35%低下 |

障壁・攻撃強化・防御低下は次ラウンド終了まで。既存の強い効果と長い期限を維持し、加算しない。攻撃・加速・リーダー効果・障壁・状態異常解除・撃破・ドロップは既存エンジンの計算を使う。敵にはゲージ・予約・必殺技を付与しない。

## 表示・保存

Unitの任意フィールド `ultimateCharge` / `ultimateQueued`、BattleEventの任意boolean `ultimate` を使用。旧セーブの欠落フィールドは0・未予約として扱い、保存検査は0〜100の整数と予約状態の整合を検証する。予約、消費、効果は通常のコマンドによる一括保存とイベントスナップショットへ含む。再読み込みで二重発動せず、再生中は演出位置のユニットを表示する。

敵の戦場上に原画カットイン、技名、回転する魔法陣、系統色、斬撃・光輪・星の衝撃を重ねる。パーティと操作面を覆わず、演出は入力を横取りしない。通常速度3秒・倍速2.4秒、HP数値は1.1秒後の衝撃に合わせる。NEXTによるスキップも従来通り。専用SEは共通シンセの既存ノードを使い、単一イベントから一度だけ鳴らす。新規の画像・動画生成やデコーダーは不要。設定・OSの動き軽減では静止カットインと一定の枠に切り替える。

日英の必殺技説明・チャージ・予約状態・操作ラベルに対応する。検証は `tests/ultimates.test.ts` と `e2e/ultimates.spec.ts`。これまでのバランス試算は必殺技を予約しない自動戦闘の基準として残す。
