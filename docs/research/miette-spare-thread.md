# ミエット研究版：余り糸の修繕

公開ルールは変更しない。`VITE_MIETTE_RESEARCH=1` の隔離研究版のみ、appVersion `1.12.0-miette-research.3` / contentVersion `miette-research-v3` / rulesVersion `2-miette-research-v3`。サクヤ研究の同時有効化は禁止。公開セーブと研究セーブは互換と称さない。

## 問題と実装

有効な他者の障壁を直接消費する4案は、開発データで生還が悪化するため不採用。新方式は失効した障壁の残りを、有限な修繕糸として各本人に保存する。1人の在庫上限は最大HP、最長3ラウンド。失効の新規追加だけが在庫を増やし、同じ障壁を二度数えない。Wave・死亡で清掃し、自動回復・追加行動・新たな盾は発生しない。

ミエットの既存の副技能ID/CDを維持し、技能名を「余り糸の修繕」へ研究用に差し替える。HP75%以下の味方1人へ、糸を先に使い、足りなければ対象本人の有効盾だけを消費する。他者の有効盾は消費しない。総消費は対象最大HPの15%まで、基礎倍率は3倍。通常の宝石色20%補正は別。

少量の変換より通常回復の実回復が2倍以上になるとき、自動行動は既存の回復判断に戻る。回復の再使用待ちを考慮せず、わずかに多いだけで毎回通常回復へ切り替えることはしない。緊急時以外は従来の盾持ち対象を優先する。手動選択の権利は残す。

共通エンジンは技能の型付き契約から失効処理へ参加させる。敵/ステージIDによる特別扱いはない。ミエット以外の定義・LS・石・能力値は変更しない。通常回復と号令は直接操作を混同しない。

## 保存・UI・回帰

`Unit.mendThread` は量と期限だけを保存。破損在庫を検証し、units/initialUnits/イベントsnapshotを再生する。準備時には公知の失効だけから在庫を射影し、AI予定や未来乱数を使わない。状態アイコンの詳細で在庫と期限を表示、戦闘操作パネルへ常設説明を足さない。円形選択の対象プレビューにも個人技能の契約を渡す。

実装の新規テスト14件、公開規則の全750テスト、旧パート2の凍結記録との72戦の一致、型/コンテンツ/UI/英語/buildを確認する。ブラウザではChromium/WebKitの実ゲームで、盾なし対象への新技能と円形選択の対象プレビューを確認する。

## 採用は別の未使用データで決める

比較・合格条件は `scripts/this-girl-02-v2/protocol.md`。全ヒーラーを同予算で有限探索し、改修前/後・同方針対照・他者糸なし・旧判断・最良既知代替を、512の未使用共通入力で確認する。未達なら動画を完成させず開発へ戻る。全体最適の認定と、実装の限定的な採用を分ける。

この文書は実装説明で、採用の実測結果の代わりではない。現段階でmainへの能力マージ、itch配信は行わない。
