# 転生裏ルートの実戦検証

本体仕様は [転生仕様](../../reincarnation.md)。戦闘ルール4、コンテンツv1.30-r1を実際の `createBattle` / `resolveRound` / `advanceReplay` で計測した。映像・表示値から勝敗を推定していない。

## 有限候補探索

`scripts/balance-reincarnation.ts --quick --confirm` を使用する。

- 9編成 × 各4リーダー × 5装備構成 × 3作戦 = 540候補。いずれも公開された仲間・記憶石・合法操作を使用する。
- 候補の絞り込み: seed101。編成と石の並びの45組ごとに、最も良いリーダー・作戦を1つ残す。
- 残した45方針を別のseed201–205で選択する。勝数を最優先し、同数なら生存人数とラウンドで選ぶ。
- 選んだ方針を **未使用のseed60001–60200（200戦）** で確認。候補ごとの確認シードは共通。
- T6は技効力・特性値230、T7は290。固定石の灯芯石は固定値80・追加特性なし。装備数4、薬5個。
- 攻撃石の追加特性は慈雨、支援石は庇護。全種類・全変種・全追加特性の網羅的最適化ではない。
- 傷ついた味方への薬、予告中のボス集中、予告発動時の先頭防御、合法な必殺予約、回復役へのクリスタル切り替えを実施。妖精・花・回収物の援護は使わない。これらを含むプレイヤーの実戦とは異なる。
- 最大150総ラウンドで打ち切る。ゲーム本体の100ラウンド/WAVE制限に加える保守的な測定上限。失敗・打ち切りを勝利に含めない。

これは全編成の最適化証明や低レアの恒久的採用価値の認定ではない。T6/T7で別々に候補を選んでいるため、勝率差をそのまま「Tierだけの因果効果」と読まない。小さい選択用サンプルには方針の過適合も残る。特にT7の成績が悪い区間は、同一方針の装備差の対照実験なしに弱体化と判断できない。

固定の連番シード集合であり、独立無作為抽出を保証しない。Wilson区間は二項モデルを仮定した参考値で、実プレイヤーの母勝率を保証しない。各200戦の二項比率には不確実性がある。表は個別のWilson 95%区間であり、多重比較を補正した優劣判定ではない。200/200でも真の勝率100%という意味ではない。0/200でも、ゲームのあらゆる合法編成で攻略不可能という意味ではない。

## 調整履歴

`rejected/fixed-leaders.json`: 当初の敵攻撃倍率3.2–4.2、HP倍率12–22、固定リーダーでの小規模試行。第2・第5・第6区間はT7でも勝利が見つからなかった。

`rejected/all-leaders-high-damage.json`: 当初の第6区間を全リーダー候補で再探索しても、8確認戦ずつで勝利がなかった。これは不可能性の証明ではないが、通常攻撃の致死性を調整する根拠にした。

最終案は敵の共通ステージ倍率をHP7–12、攻撃1.6–2.4へ変更。ボスHP300–475%、攻撃120%、4ラウンドごとの予告大技・崩しを残した。仲間個別の能力はこのPRで変更していない。深層核を全6区間のボスから出すようにし、T7製作素材を入口で集められるようにした。既存通常・塔・イベントの倍率を変更していない。

## 自動・ブラウザ検証

- 転生条件、二重実行拒否、所持品保存、初回報酬の重複拒否、今周クリアの別台帳、2回目の転生。
- 全7章と七管理者編を転生後のグラフで辿り、会話・クラフト条件・ダンジョン解放に行き止まりがないことを確認。ダンジョン勝利はこのグラフ試験ではfixtureで、上の実戦測定とは別。
- 上位製作費の一括決済、抽選の再現、既知の合法レシピのみ、製作品の保護、T7原石・バックアップ・調律、転生前T7の拒否。
- T7の実際のダメージ増、星炉80充填上限、巻戻し2短縮上限、30ラウンドでの充填ループとHPコスト。
- 1.29進行中戦闘のイベント/RNGを保存した移行、既存ルール3の実スナップショットgolden。
- ChromiumとWebKit: 320px/390px、日本語/英語、二段階確認、T7製作と再読込、通常の探索準備へ遷移。完了済みストーリーfixtureを入口に使う。

この実行環境ではWebKitに不足する `liblzo2` と `libGLESv2` をDebian配布debから `/tmp` へ展開した。`LD_LIBRARY_PATH`でロードし、システムのldconfig登録だけを調べる事前チェックをスキップして、**実際のWebKitブラウザを起動して試験**した。WebKitそのものをスキップした結果ではない。通常のPlaywright依存関係が揃った環境では `npx playwright test --config playwright.reincarnation.config.ts` だけでよい。

最終確認: 単体試験122ファイル・1,014件、製品ビルド、内容/UI/英語翻訳ゲート、ChromiumとWebKitの追加操作シナリオが成功。スクリーンショット: [上位製作](forge-webkit-390.png)、[英語の裏ルート](route-webkit-en.png)。
