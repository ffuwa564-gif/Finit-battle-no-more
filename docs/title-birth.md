# 誕生の空を背景にしたスタート画面

2026-10-29。退廃した街と光輪から生まれる少女たちを背景にし、静止した題字と全画面の開始操作を重ねる。開始後のノベル、既読記録、セーブ、戦闘やホームの進行は変更しない。

## 現在の方式：少女だけをRunwayで動かして合成

ユーザーの指定に従い、背景から切り分けた中央の少女だけをRunwayへ送った。呼吸と髪先・裾の小さい動きを指示した5秒の映像を作り、背景を除去して、静止した背景へ重ねる。Live2D SDKは使用していない。中央の人物をメッシュで変形させる旧実装は撤去した。

- 背景：`public/art/title-birth-background.webp`、1672×941。中央の人物だけを除いたクリーンプレート。建物・光輪・カメラは動かさない。
- 切り分け原画：`public/art/title-birth-character.webp`、1024×1536、透過。小さい遠景の輪郭にも使う。
- 透過動画マスター：`docs/media/title-character-alpha.webm`、720×1280、5秒、24fps、無音、VP9 alpha。プレーヤーによって透過部分が黒く見えるため、透過対応の編集ソフトで扱う。
- 配信用：`public/video/title-character-packed.mp4`、1008×896、24fps、約9.9秒、無音、H.264 Baseline Level 3.1 / yuv420p / faststart。左半分がRGB、右半分が同時刻のアルファ。通常のMP4として開くとマスクも見えるため、配信画面では専用シェーダーを通す。
- `src/ui/title-character-video.ts` がGPUで透明度を復元する。iPhoneでのVP9透過デコードへの依存を避ける。黒い背景を乗算で消す方式ではなく、別のアルファを使うため、衣装の黒いリボンも残る。
- 自然なアイドルループにするため、生成した120フレームを順再生し、中間の118フレームを逆再生する。折り返しの端を重複させず、二重の人物が出るクロスフェードは使わない。誕生の進行を逆転する映像ではなく、少女単体の待機動作のみ。
- `public/art/title-birth-still.webp` は、背景と人物の動画先頭フレームを同じ描画処理で合成した静止画。動き軽減・データ節約・描画失敗時にも同じ構図を見せる。
- 光の濃淡・少量の粒子・遠景の小さい輪郭の出現は独立したレイヤー。シーン描画は最大30fps。
- フィルムノイズは128pxの細かいタイルを低濃度で重ね、中央の顔・髪はマスクでさらに薄くする。移動幅は最大3px、3秒のステップ更新とし、画面全体がざらついて跳ねる印象を抑える。

`TitleBirthScene` は遅延取得と停止・静止画への切替、`src/ui/title-birth-rig.ts` は合成シーンを担当する。動き軽減・データ節約では動画もレンダラーも取得しない。非表示・一時停止・開始遷移時には動画と描画を両方止める。開始操作は準備を待たない。読み込み・再生・WebGLの失敗では静止画へ切り替える。終了時には動画・ネットワーク取得・GPU資源を解放する。

## 再書き出し

有料サービスへの呼び出しは含まない。

1. `python scripts/prepare-title-character.py docs/media/title-character-alpha.webm`。全不透明の誤った切り抜きを拒否し、配信用のRGB/アルファ動画を作る。VP9のアルファを読むため明示的にlibvpx-vp9を指定する。
2. `npm run export:motion-posters`。配信用動画の先頭フレームと完全に一致する検証用ポスターを出す。
3. Viteを4173番で起動し、`npx tsx scripts/export-title-birth-poster.ts`。合成シーンの先頭をロスレスWebPへ書き出す。

## 操作と検証

「死にたがりの世界で、私は死ねなかった。」の二行と光の目印で開始を促す。開始ボタンは共有Buttonを使った全画面のネイティブボタン。絵でもタップでき、Enter/Spaceでも開始する。言語切替と一時停止は独立し、触れてもゲームを開始しない。音声は既存Appの開始操作で解禁する。

`e2e/title-birth.spec.ts` は実動画の無音再生、合成した背景のピクセル保持と不透明な顔、絵のタップ、言語と操作の分離、動画と描画の停止・再開、動き軽減・データ節約、WebGL非対応、画像・動画取得失敗、自動再生拒否、取得中の開始、スマホ縦横・デスクトップを確認する。`e2e/title.spec.ts` は既存の音声解禁・指定ページ保持・タイトル背面の戦闘停止を維持する。

Chromiumで13件、配信用iframeのアニメ・ノベル・モバイル音声で4件を確認。WebKitは実行環境のシステムライブラリ不足で起動できず、iPhone実機での最終確認は未実施。H.264のデコードと実際のアルファ復元はChromiumで確認し、自動再生拒否時の静止画フォールバックも検証する。
