# 誕生の空を背景にしたスタート画面

2026-10-29。退廃した街と光輪から生まれる少女たちを背景にし、静止した題字と全画面の開始操作を重ねる。開始後のノベル、既読記録、セーブ、戦闘やホームの進行は変更しない。

## 品質修正：生成動画から原画パーツの制御へ

初版の動画は顔・衣装・背景まで動いて形が揺れるため、配信素材から外した。現在は **Live2D風の2Dメッシュ制御**。Live2D SDKや既製のLive2Dモデルは使用していない。元のアニメ原画を背景と中央の人物に分け、毎フレーム画像を生成せず、同じテクスチャを動かす。

- 背景：`public/art/title-birth-background.webp`、1672×941。元の構図を維持し、中央の人物だけを除いたクリーンプレート。
- 中央の少女：`public/art/title-birth-character.webp`、1024×1536、透過。目を閉じた姿のまま。髪・衣装・身体の絵は固定する。
- 静止画：`public/art/title-birth-still.webp`。同じパーツを重ねたメッシュ初期姿勢の書き出し。動き軽減や描画失敗時にも同じ構図を見せる。
- 頭部上22%の頂点は固定。髪先と裾は最大4.5シーンピクセル以内、呼吸は1ピクセル未満を目安に制御。カメラ・建物・輪の形は動かさない。
- 閉じた目の形も固定し、疑似的な瞬きや顔の差し替えはしない。光の濃淡、粒子、遠景の小さい輪郭の出現を別レイヤーで動かす。
- 30fpsで描画。動画の低fps化、逆再生、終端から先頭へのクロスフェードは使わない。

`src/platform/title-rig.ts` は頭部固定と変形量、`src/ui/title-birth-rig.ts` は描画・時計、`TitleBirthScene` は取得と停止・静止画への切替を担当する。Rendererは遅延取得し、動き軽減・データ節約ではパーツも取得しない。開始操作は描画の準備を待たない。WebGL非対応・パーツ取得失敗・コンテキスト喪失では静止画に切り替える。非表示・一時停止・開始遷移時は時計を止め、終了時にGPU資源を解放する。

静止画の再書き出し：Vite開発サーバーを4173番で起動し、`npx tsx scripts/export-title-birth-poster.ts`。ブラウザで初期姿勢を描いてロスレスWebPへ書き出す。AI生成や有料サービスの呼び出しはしない。

## タイトルと操作

「死にたがりの世界で、私は死ねなかった。」の二行と、静かに広がる光の目印で開始を促す。開始ボタンは共有Buttonを使った全画面の一つのネイティブボタン。絵の部分でもタップでき、Enter/Spaceでも開始する。言語切替と一時停止は独立した兄弟コントロールとし、触れてもゲームを開始しない。音声は既存Appの開始操作で解禁する。
