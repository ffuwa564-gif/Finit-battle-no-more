# 必殺技のPixiJSエフェクトと電撃音

必殺技の動画を撤去し、PixiJS 8で透過キャンバスへリアルタイム描画する。カットイン後に、光の収束→斬撃／放電／守護の着弾→衝撃波と粒子の消散、という流れを描く。技名は冒頭のカットインだけに表示し、エフェクト下や着弾後に重ねない。ガチャの映像・演出コードは使わない。

## 描画

`src/ui/ultimate-pixi.ts` は必要になったときだけ動的読み込みする。透明なWebGL描画なので、黒背景のscreen合成やデコード待ちは不要。刃は交差する3本の斬撃と分岐する電弧、星／蝕は8方向の稲妻と3重の衝撃波、花／盾／暁は味方の周囲を包む花形または六角の光と周囲を漂う粒子。6役割ごとに色を変える。回復・守護は敵を背景にせず、生存する味方の顔へ切り替える。

1シーンの光粒は88個、描画は最大30fps、解像度倍率は最大1.5。ぼかし用の多重フレームバッファは作らず、3層の線と1枚の共有グロー・テクスチャで発光を表現する。シーンは戦場の内側に収め、作戦・NEXT・味方枠の操作を遮らない。戦闘ロジックやゲージ消費は変えない。

## 効果音

`src/platform/ultimate-audio.ts` が初回の音声有効化時に波形を生成する。通常スキルのベル・旋律シンセから分離し、急降下する非整数比FMの電弧、短い広帯域ノイズの連続破裂、低音の衝撃、低域ノイズの雷鳴、有限の反射音を重ねる。攻撃・魔法・回復守護は放電の回数と間隔・共鳴を変える。ための音も上昇する電気音へ置き換える。

生成済みAudioBufferを必殺技専用の経路で再生し、通常スキルのtemplate指定に上書きされないようにする。全レイヤーは共通SE音量とリミッターを通り、BGM音量とは独立する。波形のピーク上限と先頭・末尾のゼロ、サンプルレートごとの有限性、初期の高域破裂と減衰する雷鳴を検査する。ブラウザーでは実際の出力・ピーク・ミュート・着弾同期を検査する。音の好みを自動テストが保証するわけではないため、試聴用WAVも作業成果物へ書き出す。

## 時間と失敗時

従来の `UltimateClock` を維持し、900msで収束開始、1650msに着弾と音とHP数字、2600msから全体をフェード、3600msで次の行動へ進む。倍速1.25倍・途中の速度変更も同じ時計を使い、位置を巻き戻さない。描画フレームごとに絶対時刻から位置を決め、フレーム落ちでも着弾音と結果を遅らせない。

非表示中はtickerを止め、復帰時は現在の時計位置へ進む。NEXTやキャラ切替でticker・WebGLコンテキスト・テクスチャ・canvasを破棄する。読み込み失敗、WebGL非対応、コンテキスト喪失ではSVGの軽量効果に切り替え、戦闘を止めない。OS／ゲームの動き軽減・データ節約はライブラリも読み込まず、原画と技名の静止表示にする。必殺技のmp4と専用ポスターは台帳・配信用publicから削除した。他のキャラクターアニメーションは引き続き使用する。

検証: `tests/ultimate-effects.test.ts`, `tests/ultimate-audio.test.ts`, `e2e/ultimates.spec.ts`, `e2e/ultimate-media.spec.ts`, `e2e/feedback.spec.ts`, `itch-e2e/ultimate-effects.spec.ts`。iPhone実機の見た目と試聴は公開前の確認に含める。
