# 必殺技専用のRunwayエフェクト

必殺技のカットイン後に、敵の戦場へ専用の光エフェクト動画を重ねる。斬撃・魔法・回復守護の3本をRunwayで生成し、6役割へ色を変えて割り当てる。ガチャ用の動画・粒子は参照しない。素材の黒背景は画面全体の `mix-blend-mode: screen` 合成で消し、戦場を透かして発光部分を重ねる。回復・守護では敵の映像を味方4人の表示へ切り替え、光が味方を包む構図にする。

## 素材と生成記録

| 系統 | 割り当て | Runway task ID | 原動画の主着弾時刻 |
| --- | --- | --- | --- |
| slash | 剣士 | `1d340010-59c0-4656-bbc1-052615eb8bc2` | 2.75秒 |
| arcane | 詠唱者・呪術師 | `362f6e09-17a6-4c0c-bd8f-67a92e5bbbec` | 5.0秒 |
| sanctuary | 癒し手・守護者・導き手 | `48dd4f5a-a3ee-41ec-bd40-e7634d2f5c63` | 4.75秒 |

元動画は各960×960px・10秒・無音。生成時の指定は、純黒背景、正面固定カメラ、人物・舞台・UI・文字を入れないアニメ調の発光VFX、ため→一度の主着弾→光の消散。斬撃は青白い三日月と衝撃波、魔法は紫の魔法陣と放射状の破片、回復守護は金と緑の花・盾・光粒子。原本を `artifacts/ultimate-fx-source/{slash,arcane,sanctuary}.mp4` に保持する。署名付きダウンロードURLはコミットしない。

`scripts/encode-ultimate-effects.py` で原動画の着弾前と後を個別に時間圧縮し、各素材の主着弾を0.75秒へ揃える。縁の余白を28pxずつ整理し、暗い背景を黒へ補正。配信用は各540×540px・24fps・約2.4秒・H.264 Constrained Baseline Level 3.0 / yuv420p / faststart / 無音MP4。先頭・末尾に黒へのフェードを入れる。3本の合計は約1MB。

```sh
python scripts/encode-ultimate-effects.py
npx tsx -e "import {content} from './src/content';import {exportMotionPosters} from './scripts/motion-posters';exportMotionPosters(content.assets.filter(asset=>asset.id.startsWith('ultimate-fx-')),'public');"
```

`src/content/ultimate-effects.ts` の台帳から同じリリース内の動画を参照する。動画の先頭に一致する専用PNGポスターを登録し、既存の実寸・RGB一致検査も通す。ゲーム実行時にRunwayへ通信しない。配信素材を更新したら動画とポスターを同時に更新する。

## 着弾のタイミング

`src/platform/ultimate-timing.ts` の正規化されたタイムラインを、カットイン、動画、着弾音、HP数字、演出送りで共有する。

| 通常速度 | 表示 |
| --- | --- |
| 0ms | キャラ原画・固有技名のカットイン、ための音 |
| 900ms | カットインが引き、戦場で専用動画が始まる |
| 1650ms | 動画の主着弾、系統別の着弾SE、大きいHP数字がそろう |
| 2600ms | エフェクト全体が1秒かけて自然にフェードし始める |
| 3600ms | 次の演出へ |

倍速設定は1.25倍の再生で全体2880ms。途中で速度を切り替えた場合も `UltimateClock` が進行位置を維持する。音・数字の再発生や動画の先頭への巻き戻しを防ぐ。NEXTでスキップしたら、動画を停止し、未発火の着弾音と数字のタイマーを破棄する。戦闘結果・ゲージ消費はこれまでどおりドメインで一度だけ確定し、メディアの準備や再生完了に依存しない。

着弾音は斬撃・魔法・回復守護を描き分ける。専用の歪ませたFMシンセと高域ノイズの3〜5連続放電、低い衝撃音、短いディレイ・残響を重ねて稲妻のような鋭さと余韻を作る。音量を上げるだけではなく音色を重ね、既存の共通SEゲインとリミッターを通す。BGM音量には触れない。必殺動画の再生中は味方の顔枠ループを停止して、追加デコーダーの負荷を抑える。

## 失敗時・スマホ・動き軽減

- 動画はmuted/defaultMuted・playsInline、ループなし。カットイン中に読み込み、演出位置に合わせて再生・シークする。
- 読み込み失敗・自動再生拒否では、系統別の軽いSVG効果へ切り替え、通常のタイミングで戦闘を進める。
- OSまたはゲームの動き軽減、データ節約では動画を要求せず、静止した原画と技名で表示する。
- 別タブ・非表示中は動画を止め、戻った時は現在の演出位置へ合わせる。再生制御・動画エラーでゲージやHPを再計算しない。
- 必殺技中は通常トーストを隠し、技名は最初のカットインだけに表示する。着弾後・エフェクト下には文字を重ねない。エフェクトは敵の戦場内だけに収め、味方枠・作戦・NEXTの操作を遮らない。
