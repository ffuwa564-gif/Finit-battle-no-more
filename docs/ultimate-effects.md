# 必殺技の演出・音・同期

調査で見つけた「完成した線を薄く消す共通演出」「音の共通成分の多さ」「着弾後に115ms先の音を予約する差」を改善した。PixiJS 8の透過canvasを使い、発動者のカットイン→固有の溜め→対象へ到達する主動作→決めの保持→消散→結果を読む時間、という流れを作る。技名は冒頭だけ。動画やガチャの演出コードは使わない。

## 7種類の形と動き

| 系統 | 主役の形・動き | 効果音 |
| --- | --- | --- |
| blade | 太い刃の先端が横切り、切断の光がずれて開く。雷や同心円は出さない | 風切り、短い金属の芯、打撃 |
| stars | 上方から星の槍が降り、月の弧が残る | ガラス質の共鳴、空気の着弾 |
| eclipse | 太い雷の主幹が到達し、細い枝と衝撃が広がる | 不規則な放電、中域の厚み、雷鳴 |
| bloom | 生存する味方の下で花が開き、光が上へ抜ける | 柔らかな共鳴と空気。雷鳴なし |
| aegis | 各味方の盾の面が下から立ち上がり、輪郭が残る | 低い確定音、金属面の共鳴 |
| dawn | 頭上の紋章から各味方へ光が渡る | 明るい起動・号令の響き |
| clockwork | ノクス／ティッカのビットが展開、照準、収束射撃 | 短い機械的な3連放射 |

`ultimate-choreography.ts` が表示専用の分類と絶対時刻の状態を決める。攻撃の動く決めを60ms保持してから後続へ進む。回復・守護の連続動作は止めない。ドメインの計算やゲージを止めたり再計算したりしない。通常の共通FXを二重に重ねず、敵の一枚絵だけに短い被弾反応を付け、HP表示・操作パネルは揺らさない。

光粒は56個、30fps、解像度倍率上限1.5。1枚の共有グロー・テクスチャと、塗りの形・発光する芯を組み合わせる。モジュールは必要時だけ読み込む。NEXT・終了でticker、GPUリソース、canvasを破棄し、非表示中は描画を止める。WebGL非対応・コンテキスト喪失・初期化や描画失敗はSVGへ切り替える。動き軽減／データ節約ではPixiJSを読み込まない。

## 音色とスマホ向けの帯域

`ultimate-audio.ts` はためを含め8種類の独立したレシピを持つ。初回の音声有効化時にPCMを作りAudioBufferへ保持する。各素材の発音、音量包絡、材質の共鳴、反射の量を変える。フィルターはHzから係数を計算し、サンプルレート変更で帯域が半分になる旧処理を廃止した。

電撃は短いFMの電弧、帯域を絞ったノイズ、230／460Hz付近の本体、低域ノイズを組み合わせる。斬撃は風切りと短い金属成分、回復は滑らかな立ち上がりの共鳴で、同じ雷のベッドを共有しない。全て共通SEゲインとリミッターを通し、BGMの設定には触れない。

`npm run preview:ultimate-audio` で `artifacts/ultimate-audio/` に8本のWAVを書き出す。引数で出力先も指定できる。素材の信号解析では150Hz〜6kHzのエネルギー割合が旧斬撃18.4%から53.0%、旧魔法18.4%から67.3%になった。これは聴感の品質点数でも、実機の周波数応答の測定でもない。音質は実際の画面・BGM・スピーカー／イヤホンで試聴する。

## 着弾音を前もって予約する

`audio.ts` の `scheduleUltimateSound` は、Toneの0.1秒lookAheadを加算しないnative clockを使い、必殺技の開始時点で未来の着弾を予約する。着弾フレームの後にさらに115msを足す旧経路は使わない。即時の必殺音プレビューもnative clockを使う。通常スキルのToneスケジューリングは従来どおり。

ネイティブ音源と短いゲイン包絡を追跡し、速度変更では未開始の予約だけを取り消して再予約する。既に聞こえている余韻は速度変更で切り直さない。NEXT／次のイベントでは未開始分を止め、再生中なら短くフェードして停止する。非表示中も停止し、戻った時に過ぎた着弾をまとめて鳴らさない。SEミュートは予約済みの音も含めて共通ゲインで効く。

通知イベントは引き続き再生の診断用であり、実際の音の出力時刻そのものではない。ブラウザーテストではAudioBufferSourceNode.startとstopも直接観測し、未来の予約、速度変更での取消、数字のタイマーとの目標時刻差を検査する。出力機器の遅延やBluetooth遅延までゼロになったことを意味しない。

## 時間と検証

`ULTIMATE_TIMING`：0〜900msはカットイン、900〜1450msは収束／主動作の始まり、1450msで着弾、2300msから900msかけて全体が消え、3200msで次へ進む。着弾後に1.75秒を確保し、数字を読めるようにする。必殺技の数字は通常の850msから1350msへ延長し、動き軽減でも同じ長さで表示する。倍速は1.25倍で全体2560ms、途中で変えても時計位置を維持する。

主な検証は `tests/ultimates.test.ts`, `tests/ultimate-effects.test.ts`, `tests/ultimate-audio.test.ts`, `e2e/ultimates.spec.ts`, `e2e/ultimate-audio-timing.spec.ts`, `e2e/ultimate-media.spec.ts`, `e2e/feedback.spec.ts`, `itch-e2e/ultimate-effects.spec.ts`。7系統の描画、フォールバック、速度変更、ミュート、予約キャンセル、同期、配布用iframeを確認する。自動検査は見た目や音の好みの合格を保証しない。公開前の人間の視聴確認は引き続き必要。
