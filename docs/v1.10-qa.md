# STILLVEIL 1.10 ローカル受入検証

対象はこれまで制作した解説・研究動画シリーズ全体。YouTube一覧は通信403で取得できず、ユーザーがシリーズ全体を対象と明示したため、制作時のローカル資料と現行1.0ソースを根拠とする。PR・push・デプロイは行わない。

## 判定の方針

- 研究で改善した案と、棄却・保留・未検証を区別する。定数100層275.3の未校正初案、一律の追加薄盾、王冠4案の全員配布はそのまま採用しない。
- 実装があることだけでなく、既存セーブ・取得・装備・戦闘・再開・説明の一連を確認する。
- 上位や旧データを壊して小さく見せた差を改善と呼ばない。強い既存障壁・強化・石ロック・家族重複禁止・既存所有物を守る。
- 新規/既存、JA/EN、320/390px、未所持/多数所持、進行中/報酬待ちを分ける。

## 初期監査で見つかった既存契約

1. `assertSaveCompatibility`と`persistSave`は版情報の完全一致を要求する。単純な1.10の文字更新では旧セーブを移行できない。
2. `tests/ivory-tower.test.ts`は旧塔の全wave<=3・各階共通scale・単調HP/ATKを固定している。新塔の編成別予算に合わせ、担当が意味のある不変条件へ改める必要がある。skipして通すのは不可。
3. 既存Playwrightは4173固定。新作業木の4194を明示し、別作業木へ誤接続しない。
4. 既存版のテストでは中盤の進行中battleや未確定調律のセーブも扱う。新しいUnit/Battle stateは保存validatorとbackupにも反映が必要。

## 範囲の限界

この検証は実装の回帰・導線・局所の戦闘妥当性を確認する。全パーティー・全loot・全操作の最適化、全100層の人間による難度校正、実プレイヤーの継続率を保証するものではない。大規模研究の試算回数を、本番実装後の再検証済み回数として流用しない。
