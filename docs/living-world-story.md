# 地図で暮らし、事件を解決するストーリー

## 始め方

世界地図の右下にある巻物アイコンを開き、「最初の依頼を受ける」から主人公の名前・話し方・好きなものを設定する。地図上の人物を選び、自動移動で到着してから声をかける。大きな目標・主人公の設定・旅の記録はこのアイコンに格納し、人物の頭上にはその場の用事だけを表示する。ホームにも再生・停止ボタンの下に同じ目標アイコンを置く。事件中は小さな印を付け、本文は開いたときだけ表示する。ホームの「準備へ」は旧一覧へ移動せず、地図で対応する探索地点を選択する。移動中や到着の状態を引き継ぎ、到着してから探索準備を開く。人物一覧は地図の「仲間」から開ける。

既存のセーブは「今の旅から始める」で、連続して踏破した章の先から合流する。「第1章から会話を辿る」も選べる。既存の所持品・探索記録を削除せず、以前の会話を読んだことにも置き換えない。開始前は従来の探索がそのまま使える。

## 日常と事件

全7章に、進行会話56件と繰り返し訪ねられる日常会話11件を配置した。日常の会話は再訪で入れ替わる。主人公も会話に入り、話し方や好みへの反応、住まいや儀式に関する選択が保存される。

第一章は、2ページの導入からリオラの3台詞の依頼へ進み、聖堂の探索を始める。世界の紹介をまとめて先に読む構成から、探索と報告の合間に街を知る構成へ変更した。

1. リオラの依頼を受け、聖堂を探索する。
2. 丘で報告する。白亜の塔と少女だけの街を見て、参道の巡回を頼まれる。
3. 参道から帰り、広場で宝石を集める少女たちを見る。次は鐘楼の調査へ向かう。
4. 鐘楼の後、個体生成の庭を通る。二人の恋人と生まれた少女が手をつないで帰る姿に、主人公は扉での争いを思い出す。ノエルの調査報告から事件へ進む。
5. 水路の調査報告、橋の足跡、苗床の薬草、工房で作る携帯灯を経て、泉へ向かう。

最初の3探索に関わる人物・探索地点への移動は最大8秒。移動予告と実際の到着時刻に同じ計算を使い、3地点を踏破した後は通常の移動時間に戻す。

庭園の女が少女を一人ずつ訪ねる場面と、少女たちに囲まれて眠る夜は任意の訪問にした。初訪問は短く、事件中は帰還者を迎える支度の会話へ切り替える。女の優越感、別の管理者の「かわいそうなひと……」という台詞、各場面の元の全文は記録から読み返せる。個体生成は物語上の描写であり、所持品や加入キャラクターを変更しない。

新規開始時は短い導入を使う。旧OP「欲望の扉」の全文は設定の記録から任意に読める。更新前から開いていた会話・旧OPは、元の本文とページ位置で継続する。旧版の第一章前提条件は保存記録の検査にのみ使い、新しく受ける依頼は現在の探索順を使う。読了フラグや踏破履歴を捏造して移行しない。

第一章の泉を踏破した後、庭園でリオラが意図せず主人公に忠義を誓う場面を追加した。本人も動揺し、寝込んだ夜は庭園の女に抱かれる。主人公は庭園の女の影響を疑うに留め、忠義の理由や主人公の正体は明かさない。翌朝もリオラは答えられず、庭園の女に休養を任せて花を届ける。旧ノベルの第一章末にも同じ二場面を追記し、既存の頁位置は動かさない。

普段は茶飲み話や支度をし、探索・会話の節目で事件が発生する。初回はアラートを出し、その後もホームと地図に事件を表示する。「あとで向かう」は通知を閉じるだけで、解決扱いにはしない。事件中は仲間の日常会話もそれぞれの支度や心配事に切り替わり、解決後は日常に戻る。現実時間の期限や放置ペナルティは設けない。

| 章 | 発生条件 | 事件の解決 |
| --- | --- | --- |
| 1 | 地図を確認する会話の終了 | 聖域から帰還する |
| 2 | 安全鍵の会話後、「失われた名前」を踏破 | 温室の事故後の面会 |
| 3 | 記録を確認する | 水門・避難を経て朝を迎える |
| 4 | 樹海へ出かけ、儀式の石の採取地を踏破 | ザクロとの遭遇後に退く |
| 5 | 帰還便の依頼を聞く | 少女の帰る場所を整える |
| 6 | 当番の引き継ぎ後、帰路の閉鎖区間を踏破 | 祭りの夜を越えて朝食を囲む |
| 7 | 中止の合図を確認し、「未完の名前」を踏破 | 二人で儀式の進め方を決める |

事件は既存ダンジョンの踏破と結びつく。会話だけで戦闘を突破したことにはしない。複数の人物の支度を並行して進める場面を設け、少女の所在、療養先、帰る家、街の灯り、封鎖などが同じ地図に反映される。温室の少女は記憶と療養の経過に合わせて会話と居場所が変わる。

旧ノベルは記録として残す。新しい地図ストーリーを開始した場合だけ、同じ内容の旧ノベル自動再生と探索前後の長い説明を抑える。戦闘バランス、報酬、日常会話による報酬増加は変更しない。

## 実装と文章の方針

`src/content/world-story.json` が会話・前提条件・移動先・事件・選択肢の定義。`src/domain/world-story.ts` が進行と保存状態を扱う。本文は日本語と英語の固定データで、実行時のAI生成は行わない。

主人公を含む各少女が、その場で見たものや必要な支度について話す。主題を毎回言い直す台詞や、初対面なのに昨日の出来事を共有する台詞は避ける。事件中の反応も人物ごとに分ける。初対面の少女の時制、主人公が知らない好みを断言する台詞、記憶喪失後の居場所と言動の不一致を見直した。

コンテンツ検査は人物・場所・ダンジョン参照、会話の循環、全必須会話から章末への到達、事件の参照を確認する。セーブ検査は未知の会話、無効な選択肢、壊れた途中会話・移動状態を拒否する。将来の章を追加できるよう、地図ストーリーが通常章の連続した先頭部分だけをカバーする構成も許容する。

## 会話画面の統一

地図の会話もOP「欲望の扉」と共通の `NovelStage` を使う全画面ノベルに統一した。地図と顔グラ一覧は会話中には表示せず、背景・話者名・下部の台詞・前後送り・会話ログを表示する。背景は会話／台詞のデータで指定し、個体生成の場面で扉の記憶がよぎるときは背景も切り替える。選択肢、途中保存、名前や話し方の反映を維持する。前の台詞へ戻っても、選んだ返答や報酬は変更しない。原石研磨の移動欄も地図ストーリーの保存済み経路を参照する。

## 行動案内と工房（1.22）

主会話ごとに `task`（誰に何をする）と `purpose`（なぜ必要か）を日英で定義する。事件中は章の平常時の目的ではなく事件の見出しを使う。ホーム、地図の小さな案内、目標アイコンは同じ次の行動を表示する。小案内は閉じられ、行動先の変更時に再表示する。

必要な道具は `src/content/industry.json` の `storyTools` で会話へ接続する。未完の会話のみ製作を要求し、済んだ会話の再生や保存済みの途中会話を阻害しない。製作目標から不足する装置・中間素材・原資源を逆引きし、原資源の入手先から地図へ移動できる。原資源はダンジョン踏破の確定時に獲得する。工房の道具は戦闘に関与しない。

準備前・踏破後の旧ダンジョン本文と自動ノベル割込みは表示しない。準備画面には短い環境のフレーバーと資源情報を置く。地図の人物が調査結果や道具を受け取り、次の探索へつなぐ。読了履歴と任意のアーカイブは保持する。

## 序盤の進行調整（1.23）

初回用の短い会話は `firstVisitLines`、保存中の本文種別は `active.briefing` で区別する。再読は既存の全文を使う。進行の並べ替えによる旧記録の拒否を避けるため、1.22の第一章前提条件を互換検査用に保持する。戦闘の強さや報酬、製作コストは変更しない。

1.24では工房にTier・灯力・上位採集道具を追加する。物語の道具は従来の手順を維持する。詳細は [工房のTierと灯力](industry-power.md) を参照。
