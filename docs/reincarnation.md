# 転生と「記録の裏側」— 1.30

## 遊び方

ホームの「転生・記録の裏側」から利用する。現在のメインストーリーは全7章。第7章の結末と、その後の七管理者編「seven-breakfast」の会話を読み終えると転生可能になる。探索・会話・鑑定・調律の途中では実行できない。内容確認 → 確定の二段階操作。

| 巻き戻す | 引き継ぐ |
| --- | --- |
| 現在の章、会話・選択、今周のストーリーダンジョン攻略、地図上の現在地・旅 | 仲間・覚醒・パーティ・リーダー・装備・石・素材・金貨・祈願石・工房・設定・勲章・塔・既読の映像・生涯初回報酬台帳 |

ストーリーを再び終えるたびに転生できる。回数で敵を自動強化しない。転生時の選択履歴は直前周の記録として保持する。裏ルートのクリアとT7は恒久解放。転生を繰り返しても初踏破の祈願石は二重に受け取れない。通常の再クリア報酬は従来通り。

周回中の物語用クリア記録 `worldStory.dungeonProgress` を、生涯の `completedDungeonIds` と分離した。旧クリアだけでは新しい章や会話を飛ばせない。通常ルート以外の解放記録は巻き戻さない。

## T7と製作

T7の技効力・追加特性値はそれぞれ **280–299**。技効力と追加特性のTierは別。生の技倍率は既存式 `1 + 0.015 × power` により5.20–5.485倍になる。キャラ適性、技ごとの上限・再使用待ち・非再帰条件は既存仕様を維持する。T6を調律してT7へ昇格することはない。

転生後、ホームの同画面にある「T6・T7の上位製作」を開く。入手済みの石種、合法な変種、対応する追加特性を選び、両数値を指定Tier内で抽選する。完成品は自動保護。白花の種・灯芯石など固定製作品は対象外。

| 製作Tier | 同系統の欠片 | 金貨 | 輪廻の殻 | 深層核 |
| --- | ---: | ---: | ---: | ---: |
| T6 | 90 | 3,000 | 3 | 0 |
| T7 | 270 | 10,000 | 9 | 3 |

輪廻の殻・深層核は裏ルートのボス踏破素材。第1区間から深層核も得られるため、T7製作に深部の突破は不要。殻の数だけを考えると入口9回でT7の殻が揃うが、金貨・同系統欠片・石種の発見は別途必要であり、「9周で完成する」という保証ではない。素材は素材交換・自動再利用の対象外。

T7自然ドロップは裏ルートの**踏破宝箱**のみ。戦闘途中の回収原石にはT7を付けない。第1–5区間は各既存項目のT7昇格率1%、第6区間は3%。石そのものの抽選、系統・石種・変種・特性抽選とは別で、1周あたりのT7入手率ではない。技効力と、付いている追加特性は独立抽選。通常ダンジョン・既存塔の排出率と乱数消費は変更していない。

## 超絶難度の別ルート

全6区間、各2WAVE。最初の戦いは1体、最後はボスと随伴。仲間として使える既存の少女の**記憶の反照**を相手にする。管理者の立ち絵・能力を、既存仲間で代用した設定ではない。敵味方の共通基礎スタッツを維持し、敵側は公開されたステージ倍率・ボス倍率のみで強化する。特定の味方IDを要求する判定はない。

| 区間 | 名前 | 記憶上のボス / 随伴 | 殻 / 核 | T7項目率 |
| --- | --- | --- | ---: | ---: |
| 1 | 裏庭・欠番の温室 | サクヤヒメ / リオラ | 1 / 1 | 1% |
| 2 | 白庭・校訂前の記録 | アテナ / ノクス | 2 / 1 | 1% |
| 3 | 花冠院・選外者の階段 | アステリア / ティッカ | 3 / 1 | 1% |
| 4 | 綴り蔵・借りられた明日 | ヴェスペラ / セレネ | 4 / 1 | 1% |
| 5 | 灰鐘・停止印のない夜 | ノクス / ベンザイテン | 5 / 1 | 1% |
| 6 | 管理中枢・名前の外側 | アストレア / アテナ | 6 / 2 | 3% |

前区間の踏破に加え、その後の「裏側の記録」の読了で次区間が開く。各記録は同画面で再読できる。表の地図へ無理に置かず、転生画面を入口にする。通常の探索準備、薬、予告大技、崩し、障壁、妨害、指揮の共通ルールを使用する。連続討伐とは別の通常WAVE戦。

## シナリオ（以下、ネタバレ）

既存の第7章・七管理者編の結末を消す時間逆行ではなく、選ばなかった道の記録へ渡る。救った少女の未来をなかったことにしない。前周の同意を次の少女の同意として扱わない。

導入と6本の記録を追加。庭の女の処分札と避難先、イヴラの記録訂正、ヴェスパの達成者を追い越すノルマ、墨染シオンの技能契約と生命維持、アズハ・リゼ・ザクロの帰還命令を辿る。管理の必要性と、人を所有する権限を切り離す。

最後の記録では、欲望の扉の「勝者」欄が実は所有者欄だったと明かす。主人公は他の少女を願いへ従わせる宣言をできず、判定が停滞した。その間にリオラが帰還路を開き、庭の女が受け取った。特別な血統や無欲へのご褒美ではない。リオラの跪きは学習された服従であり、今日の本人の意思ではない。庭の女の保護と独占の責任も残す。

台帳を焼いて存在記録や配給まで失わせず、願いを他者の所有権へ変換する仕組みを止める。「みんなの幸福」を主人公一人が決めない。ミナは蘇らず、灯は有限で、遠い庭の課題も残る。個体管理とアイデンティティのテーマを、拒否・再同意・記録と今日の声の区別で回収する。

## 再現と検証

```sh
npm run test -- --maxWorkers=2
npm run build
npx playwright test --config playwright.reincarnation.config.ts
npx tsx scripts/balance-reincarnation.ts --quick --confirm
npx tsx scripts/report-reincarnation.ts
```

ブラウザ検証は完了済み会話フラグのfixtureから開始するUI試験であり、ストーリー全戦闘を実プレイでクリアした証拠ではない。日本語・英語、320px・390px、二段階転生、T7製作、保存・再読込、別ルートの探索準備への遷移を確認する。物語グラフの再進行は別の単体試験で全7章と七管理者編を辿る。

実戦測定の方法・結果は `docs/research/reincarnation/README.md` に記録する。勝率は有限候補探索で選んだ個別方針の結果であり、全編成の最適解や、どの端末でも同じ操作成功率になるという認定ではない。
