# 七管理者編：配給表の下の約束（1.28）

2026-11-06のユーザー承認案を本編の全画面会話へ反映した。設定案だけを保存したものではない。`src/content/world-story.json` の `seven-` から始まる16場面・139台詞が、地図の次の行動として現れ、途中保存・会話ログ・読了・旅の記録からの再読に対応する。全台詞を日英で実装した。新規立ち絵・キャラの戦闘能力・専用ステージは追加していない。続章は人物のいない既存背景を使い、別の少女の台詞に庭の女の肖像を重ねて新人物の絵と誤認させない。

## 主題と到達点

「役に立たなくなっても、生きていていい」。見た目が変わりにくい世界で、庭籍に記録された人格・役割・帰還先と、今日の少女の意思が食い違う。記録を全部焼くことも、優しい独裁者へ権限を集めることも結末にしない。少女を生かす配給と、その少女の進路を決める権限を切り離す。

本編で実現するのは、七人が管理していた庭と街の接続圏の配給変更と暫定的な約束である。世界全域の飢え・戦争・管理が解消したとはしない。失われたミナは戻らず、荊の魔女の記憶も病気も治らない。契生石の儀式は未実施のまま。生存分を確保するため、管理者の優先設備・飾り灯・遠征の規模を削り、供給路を守る人手は維持する。資源が無限になったわけではない。

## 第1章からの伏線

序章の短い導入にも七色の封蝋と引渡要求を入れた。第1章は初回の短縮会話と再読用の全文の双方を改稿し、再読しないと設定が分からない構成にしない。既存の会話・OPのページ数と行番号は維持する。

## 四人

- トワ：削除された記録も覚える。証言を途中でやめ、話さない日を持てる。
- ウツシ：預かった記憶の手順を実行できるが、元の人格や好みそのものにはならない。貸す側の意思も尋ねる。
- アシタ：身体が変化する。観測への参加を拒み、普通に服の寸法を測り直す。
- 旅の少女（既存の `guest`）：庭籍の欄が翌日には空く。本人や周囲の記憶まで消えるとはしない。第5章の宿泊先の選択を維持する。

欲望の扉の実態、主人公の生還理由、リオラが膝をつく反応の原因は、この続章では断定しない。 後続の転生裏ルート（1.30）で、当人たちの証言と古い台帳から明かす。詳細は [転生仕様](reincarnation.md) を参照。主人公の引渡照会は扉の生還者への関心として描き、第五の例外個体だとは決めない。

四人を揃えることで万能の装置が作動する結末にはしない。アシタが拒否したため、突破実験を断念し、遠征の予備管を戻して灯を救う別案へ移る。三人も、それぞれの範囲で手を貸す。ゲームの編成・スキルとして実装した能力ではない。

## 進行・互換性

新しい `WorldStoryNode.continuation` は、章をまたいで読める一回分の著者付き続章を表す。既存の7章・ダンジョン・会話のID、前提、行番号は変更していない。追加シーンはoptional・ambientとして既存の保存契約を使い、`storyNext` と地図の人物選択で未読の続章を優先する。ただし進行中の事件・救出・必要な道具の製作は本編を優先し、続章を挟んで目的地を逸らさない。全16場面の読了後は元の「仲間たちのところへ帰る」に戻る。

引き継いだ章は既存の本編前提を満たすが、新しい続章まで読んだことにはしない。直前の続章は実際の読了が必要。旅の記録では「七管理者編」の区画へ読了した場面だけを並べ、未来の場面名や未読内容を露出しない。

1.27から1.28への移行は記録・旅程・会話位置・戦闘・乱数・資産を保持する。配給管や管理印は物語上の描写であり、工房の灯力・操作権・報酬・装備に新しい制約を課すシステムではない。

## 検証手順

- `npm test -- --maxWorkers=2`：全体回帰。新規ケースでは全7章と16場面を通る進行、旧章引き継ぎ、途中保存、早期終了拒否、会話を閉じた場合の未読保持、読了後の再読を検査する。
- `npm run build`：型、コンテンツ、共通UI、翻訳、製品ビルド。
- `npx playwright test e2e/seven-administrators.spec.ts --workers=1`：新規話者、途中再開、日英、スマホ、第7章後の導線、旅の記録からの再読。
- WebKitでも同じ新規2シナリオを実行。Linuxの実ブラウザであり、実機iPhoneの確認ではない。

進行テストのダンジョン踏破・工房在庫はグラフ検査用フィクスチャ。新規の戦闘攻略・敵AI・難度を実証したという意味ではない。

## 確認結果

- 最新mainの所持品レイアウト修正 #168 を取り込み、115ファイル・926件の単体テストが成功。
- 製品ビルド、型・コンテンツ・共通UI・翻訳チェックが成功。
- 新規3シナリオをChromium・WebKitの両方で確認。第1章の初回短縮会話、320/390pxの本文と操作ボタン、途中再開、英語の話者名、続章の推奨、第7章後の進行、旅の記録からの再読を含む。
- 追加された未読場面が、進行中の事件で必要な工房製作より先に案内される問題を全体テストで検出した。事件中は本編を優先し、人物の表示順も同じ方針へ揃えて修正した。既存の工房・物語テストを変更せず通過した。
- 最初の全体実行で既存の音声生成テストが5秒制限に達したため、全体を1ワーカーで再実行した。制限時間は変更していない。
- 英語切替後のブラウザテストは、日本語ラベル専用の起動ヘルパーを使わず共通起動コントロールを操作する。ゲームの起動処理や翻訳をテストの都合で変更していない。
- WebKitの実行環境で不足したliblzo2/libGLESv2は一時ディレクトリのライブラリを参照した。ldconfigのみを見るホスト事前検出だけを除外し、実際のブラウザと全アサーションを実行した。実機iPhone、およびリポジトリ全体のE2E成功は主張しない。
- 背景を人物のいない既存画像へ調整した後、製品ビルドと両ブラウザの3シナリオを再確認した。
