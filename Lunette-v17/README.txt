今回の修正
1. ゲームの共通カットインへ、時計の光輪・動く刻み・小さい星・一度走る斜めの光を追加。原画と既存タイトルは維持。演出時計に同期し、速度変更やスキップへ対応。軽減モーションとデータ節約では装飾を表示しない。
2. 射撃音を作り直し。長い高いレーザー音程の下降を短くし、乾いた電気的な破裂、低中域の圧力、中域の倍音を含む強い着弾、最後の爆発を重ねる。金属のベルやUI音は足していない。飛翔とHPへの同期は維持。
3. プレイ紹介をPV用の埋め込みレイアウトへ変更。オリジナルのクリーム／紺／薄紫／ミントの矩形背景。上部へ実際の必殺技名と「機巧うさぎ召喚 → 16連射 → 集中砲撃」。左の映像枠に実ゲーム、右下に既存の透過ルネットを配置。追加説明はPVだけで、ゲームの戦闘UIには入れていない。
4. 全体のホワイトアウトから次のルネットのアニメへつなぐ。既存の1・2・3・Fire!と23秒構成は維持。
