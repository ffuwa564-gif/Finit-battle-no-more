STILLVEIL — 星時計・ルネット キャラクターPV v11
縦型20秒 / Twinkle Soda / FUJINEQo / 追加の声・ナレーションなし。

プレイ映像をルネットの必殺技1回だけに絞りました。
Fire! → カットイン → うさぎビット4体召喚・チャージ → 4体×4巡の連射 → 短い間 → 締め撃ち → 2回のディレイ残響。
敵セレネの必殺技はこのPVには入りません。
ゲーム側にも分割された召喚円、集まる光粒、銃口の光、着弾の光と破片、衝撃波を追加。
1/2/3に追加していたタップ・確認音を削除。名前の登場・Fire!のバフ音も削除し、バフ音はビット召喚の1回だけに整理。
ゲームの必殺技開始音と専用連射・締め撃ち・ディレイ音も入り、着弾時のBGMを短く下げています。
バフ音は演出上のアクセントで、追加のバフ効果をゲームに付与するものではありません。

独立した撮影用デモセーブで実際のゲームを動かして収録。
moonshield-rehearsal、覚醒ルネットが味方、セレネが敵。
所持キャラ・HP・攻撃・素早さ・クールダウン・ゲージを撮影向けに調整。
実際の既存必殺技とダメージ判定・画面の揺れを使用。
カットイン・召喚・連射で再生速度を変え、着弾を曲の拍へ合わせています。
CDPのDOM時刻と映像に差があるため、実際の24fps映像を確認して編集境界を補正しました。
収録時はミュートし、ゲーム内の同じ合成処理で書き出した効果音を再配置。
バフ音はゲームのcreateCombatSynthをTone.Offline内で呼び出して生成。専用の連射音はゲームのrenderUltimateSoundから書き出し、映像の再生速度に合わせてピッチを維持して時間伸長しています。

画像・動画の追加生成なし、Runway消費0。
