# STILLVEIL — 静謐の残響

静謐で少し退廃的な廃都を巡る、ブラウザー向けのダンジョンRPGです。初期実装では、作戦・道具を指示してWaveを進め、クリア時に素材を確定し、敵を仲間にできます。

## 起動

Node.js 22以上を推奨します。

```sh
npm ci
npm run dev
```

起動時はタイトル画面を表示し、「タップしてはじめる」で音楽を開始してゲームへ入ります。BGM・効果音の音量設定を引き継ぎ、探索再開時はタップするまで戦闘の自動送りを停止します。ホーム画面に追加したiPhoneでも同じ起動操作です。

進行はブラウザーのIndexedDBへ自動保存します。セーブを削除すると復元できません。本番とプレビュー、別ドメインの保存領域は別です。

## 実装済み

- 3つの作戦、6役割、素早さ順で1ラウンド1回の行動、リーダースキル
- 通常10種・祈願石周回3種・葛葉イベント5難度のデータ定義ダンジョン、ボス会話、素材落下・カバン収納演出
- 全滅・撤退で仮素材を喪失、クリア後の確認操作で確定
- 仲間化、素材合成・分解、ゴールドによる薬購入
- ガチャ専用キャラ、石5個で1回、初回のみ2回目SSR保証、その後90回天井・74回目から確率上昇、重複は石を一部還元
- 共通UI、顔グラ、キャラのフレーバーテキスト、スマートフォン対応
- WebGLシェーダーの月光・薄霧とGPUパーティクル、GSAPの戦闘演出、Tone.jsの生成SE
- 動き軽減・GPU非対応時の静的表示、セーブ競合・破損時の安全停止
- データ・UIの検証と、Cloudflare Pages向けの不変リリース包装

初期4人・通常の敵6種・背景・メニュー原画・カバンと図鑑のアイコンはオリジナル生成画像です。アプリアイコンは世界観に合わせて新規生成した銀髪の女性の顔画像です。ガチャ専用4人も日本神話の女神を題材にした新規生成イラストへ更新しています。タイトル・数値・10ダンジョンの構成は試作用です。BGMは甘茶の音楽工房の「悲しみの曖昧な対象」「渦巻き」を同梱しています。曲・利用条件は[音楽クレジット](docs/music-credits.md)を参照してください。

## 検証

```sh
npm test               # 共通戦闘・アプリ状態・コンテンツ・配布契約
npm run build         # 型チェック・データ・共通UI検査と開発用ビルド
npx playwright install chromium
npm run test:e2e      # ブラウザーで探索・再開・確定・撤退・モバイル表示
```

動画と静止画の構図はビルド時に自動検査します。検査・書き出しにはFFmpegとffprobeが必要です。動画更新後は `npm run export:motion-posters` で表示用静止画を再生成してください。[制作手順と再発防止](docs/animation-posters.md)

## Cloudflare

連携・プロジェクト作成・公開はユーザーが行います。ここではデプロイしていません。

公開用は `npm run release` で `dist-release/` を作成し、Cloudflare Pagesへ静的配信する設計です。視聴確認の承認がない場合、このコマンドは停止します。`npm run build` の成功は公開承認を意味しません。通常の `dist/` はローカル確認用で、旧版を保持する本番起動導線を含みません。

視聴確認・版・保持リリースの扱いは [実装と公開手順](docs/implementation.md)、ゲームの正本は [設計書](docs/game-design.md) を参照してください。認証・課金・サーバー同期は導入していません。

## 画面

保存済みの[画面デザイン見本](docs/references/battle-menu-reference.png)に合わせ、原画と3列×2段アイコンを一体化したメニュー、顔アップの帯、銀・アイボリーの共通フレームを採用しています。戦闘操作盤は下記の新しいモダンな見本へ更新しています。操作は作戦と道具の戦闘仕様に合わせたもので、移動や直接攻撃は追加していません。

- [モバイルのメニュー](docs/screenshots/menu-mobile.png)
- [通常戦](docs/screenshots/battle.png)

敵は背景と一体のイラストを1枚ずつ表示します。左右ボタン・横スワイプ・左右キーでページを切り替えられます。表示の切替は攻撃対象や行動順、保存データに影響しません。ホームのメニュー画像はモノクロで統一しています。

メニューは単色ロゴ・紋章として再生成した6図案で統一しています。操作盤は[新しい見本](docs/references/modern-command-palette.png)に合わせ、横並びの作戦選択と全幅のATTACK/NEXTを持つ月光色の半透明パネルへ変更しました。ホーム下部はシンプルな線画アイコンです。パーティの名前・作戦の日本語説明・入口下の文言を表示しません。敵名とHPは最上部、Wave等は同じHUD内へまとめています。

戦闘のダメージ・回復は実HP差から対象ごとに浮遊数字で表示します。SEは大幅に増幅しピーク制御を追加、初期化中の再生漏れや薬・交換・会話等の音を補完しました。通知は生成した月光色の銀枠へ統一しています。

初期ガチャは「ゴス☆イザナミコレクション」。SSRはイザナミとアマテラス、SRはコノハナサクヤヒメ、Rはアメノウズメです。顔立ち・髪型・神話を着想にした持ち物・背景で描き分け、今回は全員静止画です。

戦闘の自動送りは通常の行動を1.8秒、Waveを2.4秒、ドロップを2.2秒、会話を4.4秒表示します。倍速でも最低1.2秒を確保します。「次の演出へ」で手動送りも可能です。敵ページは左右への0.48秒のスライドで切り替わり、動き軽減時は即時表示します。戦闘通知は敵の目元を避けてシーン中央付近に表示します。

ホーム上部の女性には、既存原画をRunwayで動画化した約10秒の無音ループを試験導入しています。停止/再生に対応し、画面外・別タブでは停止、動き軽減や読み込み失敗時は元絵を表示します。

ガチャSSRのイザナミとアマテラスも、紹介画面・獲得結果・キャラ詳細で無音ループ再生します。動き軽減・再生停止・エラー時の再読み込みはホームと共通です。

祈願は光輪・粒子・放射光から女神が現れる演出を使用し、SSRは金色の特別演出とファンファーレになります。演出中にスキップ・閉じる・再読み込みしても、抽選結果と石の消費・還元は保存済みです。SSR獲得時に天井カウントをリセットし、R/SR/SSR重複時は石1/2/3個を還元します。

常設イベント「宵宮に咲く九尾」を追加。ダンジョンのイベントタブから5難度に挑み、契りの欠片30個で葛葉、覚醒級限定の覚醒核5個で動画付きの九尾・葛葉を迎えられます。`npm run balance:events`で戦闘バランスの試算を再実行できます。

祈願石は通常ダンジョンの初踏破で3個、祈願石イベントの踏破で毎回1個獲得します。イベントは「星屑の庭」「白花の祈り路」「銀灯の守門」の短い2Waveを収録。報酬確定時だけ加算し、撤退・全滅では獲得できません。踏破済みの通常ダンジョンへの追加配布は行いません。

戦闘スキルは従来の6種に加え、貫通・吸収・継続回復・障壁・浄化の5種を使用します。初期メンバーと敵・女神に割り当て、各自2枠と通常攻撃を維持しています。リーダーは従来の能力値補正に加え、生存中のみ全体再生・瀕死追撃・攻撃時吸収・被ダメージ軽減・全体攻撃強化のいずれかを発揮します。効果・条件・再使用待ちはキャラ詳細、障壁・再生・強化・弱体化は戦闘中のバッジで確認できます。

## itch.io公開準備

タイトル・設定で日本語／Englishを切り替えられます。設定からセーブをファイルに保存・復元でき、戦闘中も撤退確認からバックアップだけ書き出せます。`npm run build:itch`でレビュー用ZIP、`npm run test:itch`で埋め込み配置の検証を行います。紹介文と配布手順は[itch.io公開準備](docs/itch-release.md)を参照してください。公開や視聴承認はまだ行っていません。
ゴス☆イザナミコレクションにSRのトヨタマヒメ・ワカヒルメ、Rのイワナガヒメ・ククリヒメを追加。2人回復・障壁破壊・強化解除で、低レアにも編成上の使い道を用意しています。

和装シリーズ「神々の装い ― 和の花宴 ―」にセレネ・アテナ（SSR）、フローラ・イリス（SR）を追加。2回目の初回SSR保証は全シリーズ共通で一度きり、使用前に確認し、結果と説明欄に使用済みを表示します。[仕様](docs/flower-banquet.md)

通常ルートに「薄明の剣と、約束の朝」を追加。通常タブの「追憶・覚醒」から、関係者4人の記憶と覚醒、セリスの覚醒条件を確認できます。リゼットの仲間化、関係者の覚醒、新規原画6点、覚醒セリスの10秒アニメーションを含みます。

和の花宴のRにエオス（攻撃強化・障壁）とニケ（攻撃・障壁破壊）を追加。全6人、R80%／SR17%／SSR3%で、他シリーズの女神は排出しません。

ホーム左下の「ホームのキャラ」から所持キャラを選択できます。動画付きはアニメーション、それ以外は原画で表示し、次回起動やバックアップでも選択を引き継ぎます。[仕様](docs/home-characters.md)

祈願に「機巧少女 ― 無慈悲な歯車 ―」を追加。限定SSRは無表情の機械人形ノクス1体で、6秒の無音アニメーションを使います。既存の共通R/SR・共通SSR、全シリーズ共通の初回保証と天井を引き継ぎます。[仕様と生成プロンプト](docs/clockwork-maidens.md)

SSR上位のXRと専用の「星晶石」を扱う仕組みを追加しました。星晶の祈願は第10章クリア後の解禁を予定し、現在は準備中です。星晶石の入手先とXRキャラクターはまだ追加していません。[仕様](docs/xr-rarity.md)

WAVE後の3択と、探索中の痕跡の組み合わせによる共鳴は [docs/wave-omens.md](docs/wave-omens.md) を参照。

妖精リュミの操作案内は、ホーム・設定・妖精アイコンから見直せます。実装前のウェブ調査と仕様は [docs/fairy-tutorial.md](docs/fairy-tutorial.md) を参照。
