# STILLVEIL — 神話と物語から考える、次のスキル会議

ずんだもんと四国めたんが、技能・リーダー効果・記憶石を本気で考える長尺動画。複数担当による原作・神話調査と厳格な批評、修正を経て制作。

**全24案は未実装です。** 追加予定・最終性能を約束する動画ではありません。覚醒後の人物描写に一部触れます。完成版は **50分30秒・1920×1080・30fps**。詳細な長さと品質検証は Runtime.json / Validation.json を参照。
