# STILLVEIL — 静謐の残響

静謐で少し退廃的な廃都を巡る、ブラウザー向けのダンジョンRPGです。初期実装では、作戦・道具を指示してWaveを進め、クリア時に素材を確定し、敵を仲間にできます。

## 起動

Node.js 22以上を推奨します。

```sh
npm ci
npm run dev
```

進行はブラウザーのIndexedDBへ自動保存します。セーブを削除すると復元できません。本番とプレビュー、別ドメインの保存領域は別です。

## 実装済み

- 3つの作戦、6役割、素早さ順で1ラウンド1回の行動、リーダースキル
- 10のデータ定義ダンジョン、ボス会話、素材落下・カバン収納演出
- 全滅・撤退で仮素材を喪失、クリア後の確認操作で確定
- 仲間化、素材合成・分解、ゴールドによる薬購入
- ガチャ専用キャラ、石5個で1回、通算2回目SSR保証
- 共通UI、顔グラ、キャラのフレーバーテキスト、スマートフォン対応
- WebGLシェーダーの月光・薄霧とGPUパーティクル、GSAPの戦闘演出、Tone.jsの生成SE
- 動き軽減・GPU非対応時の静的表示、セーブ競合・破損時の安全停止
- データ・UIの検証と、Cloudflare Pages向けの不変リリース包装

初期4人・通常の敵6種・背景・メニュー原画・カバンと図鑑のアイコンはオリジナル生成画像です。ガチャ専用4人とアプリアイコンは、差し替え可能なオリジナルSVGの仮素材です。タイトル・数値・10ダンジョンの構成は試作用です。BGMは甘茶の音楽工房での選曲・利用条件の確認前のため未同梱です。

```sh

npx playwright install chromium

```

## Cloudflare

連携・プロジェクト作成・公開はユーザーが行います。ここではデプロイしていません。

公開用は `npm run release` で `dist-release/` を作成し、Cloudflare Pagesへ静的配信する設計です。視聴確認の承認がない場合、このコマンドは停止します。`npm run build` の成功は公開承認を意味しません。通常の `dist/` はローカル確認用で、旧版を保持する本番起動導線を含みません。

視聴確認・版・保持リリースの扱いは [実装と公開手順](docs/implementation.md)、ゲームの正本は [設計書](docs/game-design.md) を参照してください。認証・課金・サーバー同期は導入していません。

## 画面

保存済みの[画面デザイン見本](docs/references/battle-menu-reference.png)に合わせ、原画と3列×2段アイコンを一体化したメニュー、顔アップの帯、銀・アイボリーの共通フレームを採用しています。戦闘操作盤は下記の新しいモダンな見本へ更新しています。操作は作戦と道具の戦闘仕様に合わせたもので、移動や直接攻撃は追加していません。

敵は背景と一体のイラストを1枚ずつ表示します。左右ボタン・横スワイプ・左右キーでページを切り替えられます。表示の切替は攻撃対象や行動順、保存データに影響しません。ホームのメニュー画像はモノクロで統一しています。

メニューは単色ロゴ・紋章として再生成した6図案で統一しています。操作盤は[新しい見本](docs/references/modern-command-palette.png)に合わせ、横並びの作戦選択と全幅のATTACK/NEXTを持つ月光色の半透明パネルへ変更しました。ホーム下部はシンプルな線画アイコンです。パーティの名前・作戦の日本語説明・入口下の文言を表示しません。敵名とHPは最上部、Wave等は同じHUD内へまとめています。
