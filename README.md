## 開始条件と再現

基準ゲームSHA `56775d6d57f868137dc41a41d8398e66fdead6ea`。比較用の終盤セーブ、転生1回、全所持（通常入手不可XRを含む）、金貨30000、薬99、T6×4、各系統欠片270。自然進行・初見ではない。固定初期seed20261107、以後継続。操作補助付きの合法アプリケーションコマンドを実ブラウザで再生。結果のための敵改変・シード引き直しなし。別の装備案を試した開発段階の記録は `development-white-ward` として区別する。

1. 固定ゲーム版をチェックアウトし `npm ci`。本PRの `scripts/loot-diary-01` と本ディレクトリを配置する。
2. `npx tsx scripts/loot-diary-01/session.ts` で実アプリケーションの保存コマンドを実行し、開始セーブと完全な行動・結果ログを出力する。
3. Viteを4371番で起動。Xvfb540×1008・Pulse48kHzの録画環境で `node scripts/loot-diary-01/record.mjs`。補助録画コードはリポジトリの `scripts/this-girl-01/verify/native-runtime/capture.mjs` を参照する。
4. VOICEVOX0.26.0を50021番で起動。`python scripts/loot-diary-01/story.py` → `python scripts/loot-diary-01/speech.py`。慈雨は「ジウ」の読みを明示。
5. 承認済みの既存立ち絵と固定OPを Input-Hashes.json の出所から復元。音楽はゲーム内コピーか許諾された公式配布元を使う。
6. `python scripts/loot-diary-01/calibrate.py` → `python scripts/loot-diary-01/edit.py` → `python scripts/loot-diary-01/qa.py`。初回書出し後の音声補正専用再ミックスは `remix.py`。
7. `node scripts/loot-diary-01/browser-qa.mjs` でChromium／WebKit再生確認。Linuxライブラリ・フォント・FFmpeg・Python PIL/numpy/scipyが必要。

## 編集と検査の境界

会話は結果確認後の振り返り実況。戦闘の開始・中間・終盤を実際のエンジンから収録し、途中省略を常時表示。完全な戦闘コマンド列はSession-Proofsに含む。9周すべての映像を撮ったと主張しない。

録画時のX11映像とPulse音声の時計にずれがあったため、診断用の点滅と16kHz音を使い、各素材の音声の原点と速度を一次補正した。開始3回・終了3回の対応点で区分線形補正。本編は最後の開始点と最初の終了点の間にある。素材内部のすべての瞬間を診断信号で直接測定したものではない。対応点と本編区間の補正係数も保存する。補正に使った点の残差は独立した検証ではない。素材内部の独立した中間診断点がないため、元収録の全区間80ms以内を認定しない。診断の下端48pxと16kHz音は本編に含めない。

最終MP4の全デコード、各カットの9連続フレーム照合、各カット前中後の実SE波形、各話者前中後の音声波形、実ブラウザで3位置ずつ再生、実フレームの目視を行う。判定とファイルSHAはFinal-QA.json／Browser-QA.jsonに記録。素材内の独立中間同期の認定は未完了なので、配布ステータスは試作・要音声試聴とする。無音部分を同期確認済みの音の証拠として扱わない。
